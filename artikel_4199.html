Kirby Air Riders' Cancelled Halloween Event Gets A Returning Replacement

Tanggal: 2026-11-05

After cancelling its Halloween event last week thanks to some nasty performance woes, Nintendo has today revealed Kirby Air Riders' replacement event. What's more, it starts today!

This one features a returning ruleset from the Shadow Star's Revenge event (which last appeared in March 2026), though the Ghost headwear reward from the cancelled Halloween event is still in place at 1,100 points — it's never too late to get a little spooky, after all.

This event is going live later today, running from 4th November at 7pm PT (that'll be 5th Nov, for those in Europe) until 9th November at 7pm PT.

While all points redeemed in the short-lived Trick or Treat event have now been reset to zero, Nintendo is increasing the number of points earned per match to make it easier to pick up all the rewards.

Original Story: If you have been keeping up with Kirby Air Riders of late, you might have been excited to dive into the game's new Halloween event this weekend and pick up some spooky Ghost headwear while you're at it. Well, we're sorry, but that's not going to happen, as Nintendo has cancelled the event.

The event was originally scheduled to run from 28th October through until 4th November, but many players reported nasty technical difficulties when taking part in early matches, where the screen would regularly freeze — which, in a game as frantic as Air Riders, isn't going to cut it.

You can see the issue for yourself below (shared on Bluesky by TAHK0):

nintendo just canceled the kirby air riders halloween event (no, seriously) because this kept happening lol

This time, Nintendo didn't have a quick fix up its sleeve, so it decided to cancel the event instead. "We have confirmed an issue in the currently ongoing event 'Trick or Treat!' where the screen temporarily freezes during gameplay," a message from the Japanese Nintendo Support social media account (via machine translation) read this morning. "For this reason, we will be cancelling this event."

While Nintendo went on to apologise for the cancellation, it claimed that there are plans to hold the event again in the future, so everyone can get in on the themed reward. There's no official news on when it will return at the moment, but we have to imagine it will be sooner rather than later.
