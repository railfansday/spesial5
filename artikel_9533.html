How we made a sled game whose leaderboard cannot be faked

Tanggal: 2026-11-18

Posted on Nov 18 • Originally published at cybermaxtools.com

Free game of the week: Sled Volt. It is a 3D downhill sled runner that runs in a browser tab. This is how it is built, and the one design decision that matters most if you ever want a leaderboard that people cannot fake.

If the game posts "I scored 90,000" to a server, anyone with dev tools can post 9,000,000. We did not want to ship a board full of impossible runs.

Sled Volt's whole simulation runs on a fixed 60 Hz tick and uses only addition, subtraction, multiplication and division, so the same inputs give the same run on every device. The game records the inputs (lane changes, jumps, tucks, boosts) and posts those with the score. The server re-plays the run from its inputs and only ranks the score it gets itself. A made-up score fails because the re-play does not reach it.

The same rule is also why the Daily Run works: the course comes from the date, so every player gets the same mountain, and a friend's run can be re-played as a ghost beside yours.

Replaying on the server costs CPU, and a long run costs more. We cap run length and do the re-play where the time limit is generous. If you build the same thing, design the cap in from day one.
