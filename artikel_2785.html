Did USC football team fly to Indiana before nationwide ground stop?

Tanggal: 2026-11-13

USC football will need its air attack to be effective against the Indiana Hoosiers, but before the game starts, the Trojans need to get to the game site. You might be wondering if USC's team plane left Los Angeles before the nationwide ground stop ordered by the Federal Aviation Administration on Friday. USA TODAY has updates. So does Chris Vannini of The Athletic.

Vannini reports that USC's plane did leave LA before the ground stop, so USC-Indiana will go on as scheduled on Saturday. Other teams weren't as lucky, and it raises real questions about Saturday's college football schedule. This has become a nationwide story given that the ground stop has nationwide reach. The USC-Indiana game is scheduled for a mid-afternoon kickoff in Bloomington, Indiana, at 3:30 p.m. Eastern time on CBS. That's 12:30 p.m. Pacific time. Had USC not gotten off the ground before the stop, this game might have been subject to a reschedule and a night kickoff to accommodate a later arrival by the visiting team.

Texas did not get off the ground before the stop. The "USC Bowl" between Steve Sarkisian and Lane Kiffin now has another plot point to account for. That game is a scheduled night game, so Horns-Tigers might not be delayed.

Minnesota didn't get out before the ground stop, but the Gophers' game at Penn State is also a night game, so it might not be rescheduled.

This one is interesting. Tennessee did not get out of Knoxville before the ground stop. This game is scheduled for a 3 p.m. Eastern, 2 p.m. local time kickoff on Saturday. This game could get shoved several hours back into a night slot in College Station, Texas.

Ole Miss did not get out of Oxford before the ground stop. This is a 4:15 p.m. Eastern, 3:15 p.m. local time kickoff in Norman, Oklahoma (Central time zone). This game might be pushed back, too.

This is a 1:30 p.m. local kick from Provo in the Mountain time zone. This game could be moved into a night slot. Remember that BYU can't play on Sundays, either, so the Big 12 will want to get this game in by Saturday night.

This is a 3:30 p.m. kickoff in Orlando on Saturday. Arizona State has a long plane flight to deal with, from Tempe (or Phoenix) to Orlando. This game could easily be moved back several hours.

Michigan made it to Oregon. Northwestern made it to Ohio State. Washington did not yet get to East Lansing for the Michigan State game. Purdue will take a bus to get to Iowa City for the game against the Iowa Hawkeyes. Nebraska's plane left before the ground stop and will make it to Rutgers in New Jersey. Illinois plays UCLA Friday night, so the Illini had no problem getting to Los Angeles.
