XRP Ledger Activates New Amendment to Strengthen Network

Tanggal: 2026-11-09

The XRP Ledger (XRPL) network recently activated a new amendment that helps secure the network by resolving potential security weaknesses and making some existing functionalities more robust and reliable.

This latest amendment, called fixCleanup3_4_0, was activated on Nov. 4, bringing a series of technical updates that include fixes for token issuance, automated market makers (AMMs), lending functionalities, and other parts of the XRP Ledger network.

A fix for a potential security weak point related to token issuance on the XRP Ledger network is a critical aspect of the latest amendment.

As explained in the official documentation of the XRP Ledger network, this update addresses a potential weakness related to delegated permissions that could allow some accounts to issue tokens when they are only allowed to destroy them.

On the XRP Ledger, token issuers can grant permissions to other accounts to perform certain tasks. For example, a stablecoin issuer could delegate permission to burn tokens to another account when customers want to redeem them.

With the latest amendment, the XRP Ledger network addresses this security weakness by preventing a zero-balance, burn-only delegated payment from resulting in the issuance of new tokens.

On top of addressing token issuance permissions, there's more to the fixCleanup3_4_0 amendment.

As explained in the official XRP Ledger network documentation, the fixCleanup3_4_0 update brings several fixes to decentralized trading, asset management, and transaction processing.

For automated market makers (AMMs), this latest update prevents some invalid auction bids and makes some improvements to how liquidity withdrawals and token clawbacks work.

It also brings some fixes for potential unexpected calculation errors or rounding issues that could occur in some cases.

These changes are supposed to make things more predictable when it comes to liquidity pools and avoid potential failures that could happen in some cases.

Another significant aspect of these changes concerns Single Asset Vaults and the proposed native lending infrastructure on the XRP Ledger.

As explained, this amendment brings some improvements to how rounding is handled when assets enter or exit vaults.

The idea is to ensure that transactions do not result in more or fewer assets being transferred than they should.
