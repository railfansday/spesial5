1Password says a hacker stole customer names and email addresses after gaining access to its backend systems. The breach didn’t expose passwords or other information stored in customer vaults, but could put users at risk of phishing attempts, according to a post disclosing the incident. It’s unclear how many users are affected.

The password manager began investigating the incident on November 19th, after an attacker gained access to an employee’s corporate GitHub account. Using the compromised account, the hacker accessed 1Password’s source code and pushed malicious code to backend services to download customer data. Along with customer names and emails, the leaked data included public keys, as well as account and user identifiers.

It also included tokens from certain emailed invitation or account recovery links. According to 1Password, attackers can’t use tokens alone to gain access to an account, as they would need to pair them with a single-sign-on method or a six-digit numeric code sent to a user’s email. 1Password has since lengthened the codes it sends to users to 10 alphanumeric characters to make them harder to guess.

The password manager also disabled the affected GitHub account, rotated internal credentials compromised by the breach, and added a new detection system for similar attacks. It warns customers about potential phishing attempts as well, saying phony emails, texts, or calls may reference 1Password invitations or account recovery attempts. The company says it will never ask customers for their account password or Secret Key, and that users should only enter this information into the official 1Password app or website.
