Waze may soon be able to show cyclists using Garmin smartwatches

Tanggal: 2026-11-12

Waze and Garmin appear to be teaming up on a new integration that could allow cyclists to show up within navigation.

The Garmin Connect app hints in its latest update (v5.31) that you’ll be able to “Share your rides with Waze” through a new “Waze Location Sharing” feature.

While the details are still a bit fuzzy at this point, Gadgets and Wearables notes that the early code suggests that Waze will be able to leverage Garmin’s LiveTrack location data to show nearby drivers where cyclists are, presumably to help drivers look out for cyclists along their route.

Cyclists would need to manually opt in for this feature. How they might show up is unclear, though. Waze already lists road hazards, so it stands to reason that an alert might appear if a driver is approaching an intersection or area with a nearby cyclist.

As for a timeline or release, it’s hard to say. Features that show up in app code are often in early days and, seeing as Garmin’s Connect app isn’t monitored frequently, there’s no track record to look at to estimate the usual time between code appearance and release.
