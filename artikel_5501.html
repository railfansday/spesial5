SiMa.ai’s Palette 3.0 runs many AI models on one chip and lifts throughput up to 3.5 times

Tanggal: 2026-11-18

Physical artificial intelligence chip startup SiMa Technologies Inc. today released Palette 3.0, a new version of its Palette software suite intended to allow many AI models to run concurrently on one chip.

According to the company, the release, which builds on the Palette Neat agentic development environment launched in June, can raise model throughput by as much as 3.5 times.

Developers building drones, robots and other autonomous machines, which need to run AI models on the device rather than in a data center, are a primary focus of the release. SiMa.ai argues that while industry incumbents rely on adapting legacy data center technology, it builds its software and silicon exclusively for physical AI.

Leading the new capabilities in Palette 3.0 is improved concurrent model execution on SiMa.ai’s Modalix MLSoC. Maintaining what the company describes as a low-power profile, a single chip can handle complex reasoning and multimodel workloads at the same time. The platform can also run separate Docker containers on the chip. Supported workloads include large language models and vision-language models.

Perception, depth and reasoning models used by drones and robots are also said to run faster on the new version. Working with ecosystem partners, SiMa.ai has added unified sensor fusion, dense neural depth fields and closed-loop digital twin simulation to the platform. The goal of the additions, SiMa.ai says, is to remove the integration and validation bottlenecks that slow down autonomous development.

Performance figures for those models are published in a new Model Registry, which SiMa.ai says measures every result within real-world power constraints. The company is offering competitive benchmarking details on request.

Also new in the release is a set of open-source capabilities for generative AI application development. Behind the 3.5-times throughput figure is speculative decoding, using the EAGLE3, DFlash and Gemma 4 MTP algorithms. Support has also been added for large mixture-of-experts models such as OpenAI Group PBC’s GPT-OSS-20B, which can now run on the Modalix MLSoC 16GB system-on-module.

Developers are free to adapt the open-source code, which is available on GitHub. Documentation for Palette 3.0 is provided through SiMa.ai’s Developer Center.

Founded in 2018 by Chief Executive Krishna Rangasayee, SiMa.ai offers a platform that combines purpose-built silicon with software for AI on physical devices. Notable customers and partners include Robert Bosch GmbH, Emerson Electric Co. and Synopsys Inc.

SiMa.ai raised $150 million in a Series C round at a $1.45 billion valuation in September. Fidelity Management & Research Co. and Amplify Partners co-led the round. The company has raised $500 million to date.
