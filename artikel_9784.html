Back to my cybersecurity project after 4 months. Looking for honest feedback

Tanggal: 2026-11-04

About 4 months ago, I stopped working on SentinelForge, an open-source security analysis tool I've been building on my own.

I spent some of that time procrastinating, but I also learned quite a bit about software architecture, code quality and the problems with AI-generated code.

Recently I picked it back up and started working on a new update.

Added a placeholder for a future local AI assistant

Fixed around 10 bugs, including 2 race conditions

Started reviewing the codebase to clean up AI-generated mess and improve code quality

My goal is to make SentinelForge simple enough for students and beginners, but still useful for bug bounty hunters.

The idea is to bring scanning, vulnerability findings, evidence and correlations into one workspace, without overwhelming users with complicated interfaces or raw output.

But before I spend another few months building features, I'd really like to hear what people actually want.

What would make you give a tool like this a try?

What's missing or frustrating about the tools you currently use?

Would a local AI assistant that helps explain and investigate findings be useful?

I'm developing this independently and I'm open to any criticism or suggestions. Even if you think the project is pointless, I'd like to hear why.

GitHub: https://github.com/Sa1tama228/SentinelForge
