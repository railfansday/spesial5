There are currently a handful of GloryBound codes available, offering regular and lucky spins to unlock new Blessings. To use these, enter The Rift from the main lobby area, then approach the big blue Crystal of Fortuna and interact with it. Previous promos have given cash to spend, and chests you can open from your inventory to unlock new gear.

To redeem GloryBound codes, you need to complete the tutorial including your first visit to the arena, which will then unlock new options on the main lobby screen. Tap the Present icon in the top left of the screen to access the Daily Rewards menu, then select the Codes tab before using the Enter a code text box to type a promo. Codes for GloryBound automatically convert to all caps when entered, so you just need to use the right spelling.

There are already some expired GloryBound codes, as the initial promos have been replaced with more recent ones. This process is likely to continue as the game develops, so make sure you've grabbed any active codes when they're available.
