Prices are still high, but these are the cheapest kits we could find.

When you purchase through links on our site, we may earn an affiliate commission. Here’s how it works.

Memory prices keep going up. Despite leveling off after a peak earlier in the year, DDR5 prices are back up, with many 32GB kits selling for above $500, as you can see in our RAM price tracker. Thankfully, there are some decent Black Friday deals on RAM, with 32GB kits starting at $420. The five kits we've rounded up here are all less than $450.

Of course, these aren't deals compared to prices a year ago, but it seems we're a long way from prices returning to that point. If you're also looking for a motherboard and/or CPU, you can generally save more on memory by picking up a RAM bundle. You can look at our roundup of the best Black Friday RAM bundle deals if you're interested in that.

Team Group T-Force Delta RGB 32GB (2 x 16GB)

Team Group T-Force Vulcan Eco 32GB (2 x 16GB)

The Patriot Viper Venom DDR5 memory kit here goes up to 6000 MT/s with a CAS latency of CL36. It supports one-click overclocking through AMD's EXPO. $40 off w/ promo code BFEF202

The cheapest kit we could find, and the headline deal so far, is $40 off the Patriot Viper Venom DDR5-6000 CL36 kit. This kit continually pops up as one of the cheaper options, so we don't expect to see any 32GB kits with similar specs for less. Of course, that can always change as we move through Black Friday.

At DDR5-6000 CL36, this is squarely in the sweet spot for most rigs. It ships with one-click overclocking through AMD EXPO. The kit itself isn't on sale, so make sure you apply the BFEF202 discount code at checkout to save the $40.

RGB memory from V-Color with CAS and latency timings of 30-38-38-96. Two 16GB modules form 32GB of DDR5 RAM with speeds of 6,000 MT/s.

If you're after slightly tighter timings, you can spring for the V-Color Mantra XSky DDR5-6000 CL30 kit, which is only $10 more expensive. These DIMMs use SK hynix ICs, come with one-click overclocking via AMD EXPO, and feature RGB lighting.

Although the discounts apply to multiple different 32GB kits from V-Color, this is the only version we could still find in stock (there's a white version, for instance). In addition, we've seen this particular kit go out of stock and come back in stock over the past few days. If you're planning on picking it up, it's a good idea to do it early.

Get a great deal on standalone RAM from Newegg. This deal is currently the lowest priced DDR5-6000 available. The T-Force Delta RGB not only adds flair to your chassis, but does so with decent speeds.

This Team Group T-Force Delta RGB kit has the largest discount that we could find at 20% off its list price, though it's $20 more expensive than the Patriot Viper Venom kit. Similar to the V-Color kit, Team Group justifies the extra cost with the additional RGB lighting and tighter timings.

This is the first kit on our list that comes with both AMD EXPO and Intel XMP 3.0. Although you can use the same memory on either platform, the extra seal of approval is never a bad thing. Newegg has this kit marked down by 7%, so make sure to use code BFF465 at checkout to save an additional $70 and get the full sale price.

The next, best 32GB DDR5 RAM kit, also from Team Group, with much faster speeds of 6,400 MT/s. CAS and memory timings are 38-46-46-84. Probably the better option if your budget can stretch to get it.

Coming in right at our limit of $450 is another Team Group kit that ditches the RGB lighting for a silver heatspreader, and features a faster transfer rate at 6,400 MT/s. It features the same timings as the Delta kit linked above while maintaining that faster transfer rate.

This kit also comes with EXPO and XMP certifications, so you shouldn't have issues with one-click overclocking on AMD and Intel platforms. Newegg doesn't have this kit on sale, so use code BFEF133 to save $100 at checkout.
