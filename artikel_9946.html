Introducing Project Steadfast

Tanggal: 2026-11-08

Recently I wrote about an idea that’s been floating around in my mind for a long time - the ability to do metaprogramming in Ruby by manipulating Ruby ASTs, similar to the macro capabilities of languages such as Lisp or Elixir. The use of eval (in its different variations) is a common metaprogramming technique in Ruby that consists of generating code at runtime from dynamically constructed strings. This is often done for performance reasons: ERB compiles templates into optimized code by generating pieces of Ruby source code then putting them together and calling eval; In Rails, the same technique is used for implementing features such as associations, or scaffolding. With eval, we can avoid paying the performance overhead that’s often associated with using DSLs in Ruby.

But using eval in a highly-dynamic context may also be error-prone, limited, and potentially vulnerable to injection attacks. Having to painstakingly construct strings containing Ruby source code can be an arduous task, especially if you want to compile a DSL into efficient code, as in the case of ERB, or my own Papercraft.

I’m not particularly proud of the Papercraft compiler code, which complexity stems from the fact that the kind of optimized code is generated dnyamically, and has to be put together from many small pieces. That’s why I’ve long been thinking about how to simplify it.

It eventually occurred to me that a tool for generating code using a general-purpose macro expansion technique, such as the quote/unquote mechanisms in languages such as Lisp or Elixir, might be a perfect fit for solving problems such as this. Such a tool may not only be used for generating new code at runtime, but can also be used for manipulating and mutating existing code at runtime.

In my article Unrolled Code, I’ve explored how this technique could be applied to many different problems. Which leads us to project Steadfast.

I’m excited to announce that I’ve been selected as the recipient of a Ruby Association grant for working on developing a general-purpose macro tool for Ruby using the quote/unquote technique, with Matz as my mentor.

The scope of the project includes the development of the quote/unquote tools, as well as additional tools for generating and manipulating Prism ASTs, converting ASTs to source code, etc. The project will also explore the use of those tools in popular gems such as ERB, ActiveRecord, Roda etc. I’d like to see how far I can take those ideas, how can they be integrated into the Ruby runtime, and what are the limitations and drawbacks of this technique.

I’ll do this work in a new repository that I created called Steadfast. If you wish, you can look at some sketches I made that show possible usages for quote/unquote. Steadfast is a continuation of my work on Sirop, a tool I built for converting Prism ASTs to source code, and which is currently used by the Papercraft compiler.

Steadfast is dedicated to the courageous people of the land who persevere in the face of unimaginable violence, persecution, callousness and indifference.

Over the next four months, I’ll be sharing news of my progress on this project, which should be completed by late March 2027. I think the new techniques introduced in this project can lead to a new way of doing metaprogramming in Ruby. Hopefully, other people will find this work useful and will come up with new uses for Steadfast.
