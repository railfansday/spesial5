Omaxian takes the Omarchy look down a different Linux backstreet

Tanggal: 2026-11-17

Devuan-based distro swaps Wayland for XLibre and i3, with Xfce waiting if the tiling gets tiresome

Omaxian OS is only at version 0.1, but it already takes a distinctly unconventional route through the Linux desktop.

The brand-new Linux desktop distro describes itself as "the Omarchy desktop on X11 — as a shell for your Debian, or as a whole OS." That's not quite the impression that we came away with, though.

Like most distros, Omaxian is available as an ISO file you can install and use. Alternatively, Omaxian Shell can be installed on an existing Debian-family distro without replacing the underlying operating system.

The OS release is codenamed "Trans-Siberian Shaman," and the GitHub project repository shows work going back just a few weeks. No LLM coding assistant is credited on the project page, but we looked inside some of the test scripts, and as well as being verbose and hard to read, they also credit "Grok Bot." Omarchy itself is of course built with LLM assistance, and as we reported last month, so is the new Daemonarchy FreeBSD-based desktop project.

Omaxian is styled after Omarchy, and it includes some of the same tools – and optional support for LLMs – but it's not based on the same tech. Instead of Arch, it's based on Devuan 6, the current version of the systemd-free fork of Debian. Omaxian eschews Hyprland, and indeed Wayland altogether: it opts for an X11 tiling window manager – in this case, i3. i3  first appeared in 2009, so it's been around much longer than Hyprland. Omaxian's configuration also understands familiar keystrokes such as Alt+F4 to close a window. For us, that's a significant usability win.

The window manager isn't running on top of X.org. Omaxian uses the 2025 fork, the new XLibre X11 server. This is a controversial project led by a controversial developer, which will be enough for some people to want to avoid Omaxian as a whole. The latest release of GhostBSD uses XLibre too, though.

Way back in 2021, The Register reported on Omarchy creator David Heinemeier Hansson's company banning political discussions, and things have only got more vexed since. Just as DHH has attracted some notoriety for his now right-wing views, his Linux is similarly opinionated. If the associations surrounding Omarchy and XLibre put you off, Omaxian's combination of the two probably won't win you over.

The flipside is that if you don't care about the political views, but are interested in the idea of a tiling environment set up for power users who embrace LLM coding assistance, then you might like Omaxian. The full distro trades Arch, Wayland, and systemd for a Devuan base, X11, and sysvinit, with APT handling conventional packages. Flatpaks and AppImages are available too.

We tried Omaxian in VirtualBox, but we experienced frequent display corruption. We must give it this: the interface is slightly easier to navigate than Hyprland. One touch that we did like is that if you get tired of the tiling stuff and want to switch back to something more conventional, then Xfce is also installed in the background. Xfce provides Omaxian with a file manager and other accessories, but you can just choose Xfce from the login screen and find yourself back in a simple, familiar, classic desktop environment.

Omaxian is not the sort of environment we're looking for. This vulture isn't a developer and doesn't use LLMs for anything at all. However, lots of people are looking for something like that, as demonstrated by Omarchy's sponsorship. But it's bold, colorful, and significantly different from the mainstream, and that is the sort of thing we do like to see. ®
