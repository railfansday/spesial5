Mandatory Nier: Automata Update Accidentally Requires 366GB: ‘I Just Need To Delete 90 Percent Of My Computer To Install This’

Tanggal: 2026-11-07

Some people who tried to play Nier: Automata this week on Steam ran into an unusual problem. The game required a new update and it was asking to take over people’s hard drives. A game that usually had an installation footprint of less than 50GB ballooned to 366GB. It’s still unclear why.

“Thanks to the latest update, fresh install of the game is now whooping 366GB,” read one angry review on Steam from someone with over 100 hours played of the sci-fi action-RPG. “Why? Because each DLC from YoRHa Edition is now the same size as the main game is. EVERY. SINGLE. ONE.”

Another, responding to the idea that the massive size was because the core install now included every one of the game’s optional language packs, wrote, “Like, can you leave perfectly functional games alone and add a ‘Language pack DLC’ ??? Repair your mistakes.” A third was more succinct: “366gb for 2b’s big butt I guess.”
