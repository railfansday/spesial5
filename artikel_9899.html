Final release for the 7.2 stable series

Tanggal: 2026-11-04

Greg Kroah-Hartman has announced the release of the 7.2.15 kernel, with a handful of updates.

Note, this is the LAST 7.2.y kernel release. After this one the 7.2.y kernel tree is end-of-life. Please move to 7.3.y at this time.

And yes, you aren't imagining things, this one went "end-of-life" a bit sooner than normal. But based on the release cycle at the moment, and the number of pending cc: stable patches in the queue, I figured it was better this way so we can focus on the latest 7.3.y release as it would require us to keep 8 different branches alive at the same moment, a taxing task under the best of times.
