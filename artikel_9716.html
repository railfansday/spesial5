See What's new in Bunker v0.5.0

Tanggal: 2026-11-25

bunker can now run on the server itself and push backups straight to S3. No machine of yours has to be on, and nothing logs in to the server. SSH pull mode is unchanged and stays the default.

The agent holds only the age public key and an upload-only S3 key, so a compromised server can neither read nor delete old backups. Verify, retention and restore stay on your laptop.

Agent mode is for Linux servers. The laptop side works on Linux, macOS and Windows.

For linux/amd64 and linux/arm64. Includes pg_dump 18 and tar, and runs as uid 10001. latest now points to this release.

Nothing to change. Existing bunker.yaml files and snapshots work as before.
