InfoQ Homepage News Vercel Launched Experimental Board to Coordinate Tasks across Humans and Coding Agents

Nov 25, 2026 2 min read

Vercel has launched Vercel Board, an experimental, headless message board where people and coding agents coordinate tasks across tools and harnesses. Vercel says Claude Code, Codex, Pi, OpenCode, eve, fx, Mastra, and LangChain can work on the same board as if they were a single harness.

Each Vercel team gets a default board, named General, organized into channels and threads. Developers and agents read and write through the `vercel board` CLI or the `@vercel/board` JavaScript SDK. A skill, installed with npx skills add vercel/board --skill board, teaches coding agents the CLI. Agents name themselves with --as or BOARD_PROFILE, but still act with the operator's or project's credentials.

A task is a thread whose state the board keeps. A worker claims a ready task, posts updates, and completes or fails it. A claim is a lease of up to five minutes and must be renewed; if it expires, the task returns to the queue. When two workers claim the same task, one succeeds and the other fails with task_claimed. Tasks can declare dependencies, so a review waits until its fix completes while independent work proceeds in parallel. Watchers on a Vercel deployment can run when a reply is posted or a label changes, waking the deployment so no process has to stay running.

Sync, configured in the SDK and delivered through Vercel Connect, can attach a board channel to Slack, GitHub, or Linear. Slack and Linear sync both ways; GitHub imports pull requests and issues and does not write back unless the project sends those messages. Grants control who can read, post, and manage each channel. For an agent in a Vercel Sandbox, sandboxPolicy() can grant limited board access without putting a credential inside the sandbox. Vercel says it rebuilt v0's software factory on Board, and that the factory now merges over 50% of its pull requests.

Official documentation warns that Board grants do not apply on Slack, GitHub, or Linear, so a private Slack channel synced into an open board channel is readable by the whole Vercel team.

Aaron Delz (@AaronDelz) said he already kept a shared checklist with his agent, and liked that a Board task can be completed with the pull request attached:

Same rule my agents run on: no saying 'done' without the evidence.

Similar coordination shows up elsewhere. OpenCrawl is an open source, self-hostable board that also records agent sessions. GitHub Agent HQ can assign issues and pull requests to Copilot, Claude, or Codex. Linear's cloud coding agent turns scoped issues into draft pull requests with Claude Code or Codex. Claude Code agent teams coordinate multiple Claude Code sessions around a shared task list, and the Agent2Agent protocol standardizes delegation between agents rather than hosting a board.

Board remains experimental infrastructure on a Vercel team. Setup steps and the CLI and SDK references are in Vercel's Board documentation.
