Microsoft's last non-security preview of 2026 packs a punch

Tanggal: 2026-11-23

Windows Search gets a makeover, while Hello lights up dim rooms

Microsoft has delivered its final scheduled non-security preview update of 2026 for Windows 11 25H2 and 26H2, with an updated Windows Search experience and a brighter Windows Hello for users who prefer darker rooms.

The optional KB5132057 update arrived on November 19, after this month's Patch Tuesday. Microsoft is skipping December's non-security preview because of reduced holiday operations, though that doesn't cancel the monthly security release. This last preview is quite a doozy.

The big-ticket item is the "new Windows Search Experience." We saw a preview of this last month, and Microsoft has gone well beyond the "just make it work" request of many Windows users. Results appear faster with less clutter, the tool uses memory better, and files can be previewed directly in Windows Search.

We're less convinced by inline actions, which let users perform common tasks directly through Windows Search without opening Settings. In our testing, "turn on dark mode" worked, but "switch on dark mode" did not, thus highlighting the limitations of the tool. In addition, we remain unconvinced that Windows Search is the place to run actions.

That said, anything that makes Windows Search less of a punchline for unkind jokes about performance and accuracy is welcome, as are other features, including an optional screen-brightening feature for Windows Hello facial recognition in dim rooms, and the PowerToys-esque Run dialog, which users can enable in Settings.

While some of the new features won't be enabled immediately, Microsoft has included fixes that will be available right away. One addresses an issue where Windows Fax and Scan could fail to connect to a fax server. Handy for those occasions when email falls over into a heap.

There are also fixes for Windows IoT Enterprise LTSC activation failures and the misleading "Something went wrong" message shown on Android devices during cross-device passkey authentication. At the time of writing, Microsoft still lists the problem as something for which "we are working on a resolution to be released in a future Windows update."

Sadly, not everything has been pushed off the naughty step. SQL Server queries using OLE DB providers can still leave connections to external databases open after they've finished. Microsoft is working on that one and "will provide an update in an upcoming release." ®
