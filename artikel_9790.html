How to give your AI agent live SEC insider-trading data (Form 4) via MCP

Tanggal: 2026-11-23

Ask a chat model "Which Nvidia insiders sold stock in the last 3 months, and for how much?" and you usually get one of two answers: a polite refusal ("I don't have real-time data") or, worse, a confident paragraph with made-up names and numbers.

The real answer is public. Every time an officer, director or 10% owner of a US-listed company buys or sells, they must file a Form 4 with the SEC, usually within two business days. The problem is getting that data into your agent in a shape it can actually reason over.

This post shows how to wire SEC Form 4 data into Claude Desktop, Cursor (or any MCP client) and into plain Python, with one tool call per question.

Disclosure: I built this actor (HenryCrawl). I'll also show the free, official route so you can decide which one fits.

Insider filings are useful context for an agent doing company research: did the CFO just sell? Was it a planned 10b5-1 sale or an open-market purchase? Did a director buy with their own money?

An LLM can't do that crawl inside a chat turn. It needs a tool that returns one clean row per trade.

If you want zero cost and full control, go straight to SEC EDGAR:

This is a good weekend project and the data is free. If you only need one ticker once, do this. Where it hurts is when you want it as a reliable agent tool across many tickers without maintaining a parser.

The SEC Insider Trades actor on Apify does steps 1 to 5 and returns flat JSON rows. Because Apify exposes actors through a hosted MCP server, any MCP client can call it as a tool.

Pricing is pay-per-result: $1.50 per 1,000 transaction rows, no start fee, and error rows (unknown ticker, no match) are free. maxResults caps your spend per run.
