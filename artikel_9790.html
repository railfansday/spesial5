I re-ran a rival's memory benchmark. It tied mine. Here is the interesting part.

Tanggal: 2026-11-20

I build Monomem, shared memory for AI coding agents. It records which app wrote each note and holds suspicious writes until a person looks.

On LongMemEval-S, a standard long-term-memory test, a well-known memory project (agentmemory) publishes 84.7%. I re-ran its own evaluation on the same data file and got 84.7% back, exactly.

Why post a tie? Because memory search is turning into a commodity. What I think still matters is trust: who wrote a note, whether an outside web page could have poisoned it, and whether you can undo it. Monomem's own attack check (monomem check --attacks) replays 26 known poisoning attacks on a copy of your store. Two are known misses (a reworded override, and self-poisoning), and the README lists them next to the headline number. It is pattern matching, so a reworded attack it does not know can get through.

Everything runs on your computer in one file: no cloud, no account. MIT licence. Beta, not independently security-reviewed.

Reproduce the numbers: monomem bench --longmemeval ... --per-question out.ndjson (instructions in docs/BENCHMARK.md). If you can beat or break it, tell me.
