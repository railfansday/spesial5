CVE-2026-62284: CVE-2026-62284: Remote Code Execution and SSRF via Unsanitized Kubeconfig in OSAC Operator

Tanggal: 2026-11-07

Posted on Nov 7 • Originally published at cvereports.com

Vulnerability ID: CVE-2026-62284 CVSS Score: 8.6 Published: 2026-11-06

CVE-2026-62284 (GHSA-5w5g-j6hw-6p8f) is a code injection and server-side request forgery vulnerability in the console-proxy component of the OSAC Operator. The RemoteConfigResolver parses Kubernetes Secrets containing kubeconfig files via clientcmd.RESTConfigFromKubeConfig without sanitizing execution-related fields. An attacker with RBAC permissions to create or modify labeled Secrets in monitored namespaces can supply a malicious exec credential plugin, resulting in arbitrary command execution within the console-proxy pod.

The OSAC Operator console-proxy fails to strip ExecProvider and AuthProvider configurations when parsing kubeconfig files from Kubernetes Secrets. Attackers with Secret write privileges in monitored namespaces can execute arbitrary commands as the proxy service account and induce SSRF by modifying the target cluster server URL.

Merge commit for PR #321: Harden kubeconfig parsing in console-proxy config resolver
