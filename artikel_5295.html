According to longtime SHIB community member Mazrael, since the SHIB deployer wallet went silent in October 2021, at least 137 scam tokens have falsely claimed that the SHIB deployer sent them the coins. The intent of scammers is to 'fake' Shiba Inu's pseudonymous founder, "Ryoshi," and the reason behind this is to appear legitimate: If "Ryoshi" sent it, people trust it.

Mazrael explains how this trick works: a token is just a program, and it keeps its own record of transfers. The scammer can write any address into that record as the sender. So these scammers write the SHIB deployer's address, and on Etherscan it looks like "Ryoshi" sent the token. However, the real SHIB deployer (0xB8f2…FA08) hasn't sent a single transaction since October 2021.

'The SHIB deployer never signed anything,' Mazrael stated, urging the crypto community to click on related token transactions and examine the "From" address, saying this is the wallet that sent it and was never the SHIB deployer.

Mazrael shared the numbers, outlining over 9,131 fake transfers, over 2,500 wallets hit, and zero signed by the SHIB deployer. He went on to name some of these fake tokens, adding that some of these tokens got promoted as "Ryoshi-backed" to make them look legitimate.

This disclosure warns crypto users to always check who signed the transaction, not what the token says.

In a separate post, Mazrael explained that nothing links the SHIB deployer address to any person.

The SHIB deployer (0xB8f2…FA08) only deployed one contract: SHIB, and it hasn't sent a single transaction since October 2021. It has no public signed message on record, either on-chain or on Etherscan.

LEASH, BONE, and TREAT each came from different deployers. Mazrael indicated that BONE's deployer is shiba-swap.eth, whereas LEASH came from '0xA221…1494,' the same key that deployed StarLink, whose own site names Woof Decentra as LEASH's developer. That key kept LEASH's rebase oracle, an admin key, for five years.
