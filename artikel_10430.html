Latest Gemini design comes to all Android devices, app upgrades file generation

Tanggal: 2026-11-04

A pair of Gemini app updates today brings the latest design to all Android devices, while file generation sees a big upgrade.

The latest Gemini overlay design applies a heavy blur effect over the bar. It’s hard to make out the boundaries of the pill, while there are way more tiny specks and swirls of color. Once the animations complete, you can see how the pill-shaped bar is translucent at the perimeter instead of a solid shape.

This updated design was first introduced on phones with Gemini Intelligence (Pixel 11) and is now available on all other devices we checked today. Make sure to Force stop the Google app if you’re not seeing it yet.

Meanwhile, the Gemini app now lets you “generate, preview, and edit files right within” chats. You can have Gemini create a text document, presentation, or spreadsheet about a specific topic and then view it inline. Highlight sections to make edits or ask questions.

PDF preview and editing are supported on gemini.google.com and the mobile apps, while Google Docs, Google Sheets, Google Slides, Markdown files, TXT files, and code are web-only.

File creation and editing are live for “users in all languages where the Gemini app is available.”
