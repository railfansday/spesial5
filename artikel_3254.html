iOS 27.2.1 has fixes for security issues in Messages, AirPlay, and more

Tanggal: 2026-11-10

Today Apple released iOS 27.2.1 for iPhone with bug fixes and security updates, alongside a variety of related software updates on other platforms. Here are the security fix details for each update.

Apple has just detailed all the latest security fixes included in today’s new software updates.

iOS 27.2.1 and many other updates include fixes that relate to Messages, AirPlay, Bluetooth, and more. In Messages, a remote attacker could have potentially been able to join an iMessage group chat uninvited. With AirPlay, an attacker in Bluetooth range might have been able to bypass the rate limit on pairing code attempts.
