Switch 2 Supposedly Jailbroken Via Software-Only Exploit

Tanggal: 2026-11-11

Update: It's apparently been patched in the latest update

Update [Tue 10th Nov 2026, 2am]: Following the Switch 2 firmware update today (Version 23.5.0), it seems this jailbreak has now been patched. As OatmealDome explains on social media:

The OS exploit used in the recent jailbreak has been patched in version 23.5.0.

"Dumping and modding games will be impossible again from this point forward, with the exception of some cartridge games (and maybe game updates) that are released in the near future.

"While game exploits like SmileBASIC and Civilization VII still exist, it is no longer possible to "escape" the game starting with 23.5.0. This effectively means that the capabilities of homebrew are locked to whatever the game can do already (i.e. not much)."

Original Story: [Fri 23rd Oct, 2026 03:55 BST]: Nintendo appears to have removed the programming software SmileBASIC 4 from the eShop following the supposed discovery of a Switch 2 jailbreak.

The "software-only" tethered jailbreak 'ns2jb' was apparently created by Sammy 'pepsipu' Hajhamid, with the help of OpenAI's Codex.

It allows arbitrary native code to run, and can supposedly be used to "run homebrew, reverse engineer and mod Switch 2 games" as well as back up save files. It uses the Switch 2's latest firmware 23.0.1 and requires access to the now-delisted Switch title.

The security researcher and modder believes this is the "first such exploit for the Switch 2" and claims to have successfully added the characters "cinnamoroll, peter griffin, hatsune miku, and more" into Mario Kart World to demonstrate its capabilities.

"This lets us run homebrew, reverse engineer and mod Switch 2 games, back up save files off the Switch, and access most of the Switch 2’s peripherals through MMIO. To my knowledge, it’s the first such exploit for the Switch 2. To demonstrate the capabilities of this jailbreak, Codex modded a Switch 2 exclusive, Mario Kart World."

As this is a "software-only" exploit, it means the minute the Switch 2 is powered off, you're back at square one.

Although the Switch game SmileBASIC 4 has seemingly vanished, Nintendo hasn't openly acknowledged this exploit. However, the creator behind this jailbreak says they're "excited to see all the upcoming Switch 2 homebrew, emulation, and modding".

This isn't the first time something like this has been discovered, either. SmileBASIC was also used for homebrew exploits during the 3DS generation.
