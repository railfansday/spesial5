Trails In The Sky Switch 2 Updates Add 30fps Lock Option In Graphics Mode

Tanggal: 2026-11-20

Trails in the Sky 1st Chapter has rolled out a new update this week, bumping it up to Version 1.0.8 on the Switch and Switch 2.

It comes with several fixes and improvements for both versions of the game. As noted on the official patch notes page, in the graphics and performance settings, there's now to lock the graphics mode at 30fps on the Switch 2.

Here's the full rundown from the official game site:

Version 1.08 has been released. This patch contains the following fixes and improvements:

This follows an update for Trails in the Sky 2nd Chapter last week (Version 1.05), which added the same feature to the second game on Switch 2. Here are the full patch notes for this title:

Version 1.05 has been released. This patch contains the following fixes and improvements:
