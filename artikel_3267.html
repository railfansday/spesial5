Apple releases iOS 27.2.1 for iPhone, here’s what’s new

Tanggal: 2026-11-11

Apple has released a minor new software update for iPhone users today: iOS 27.2.1. Here’s what’s new.

iOS 27.2 launched late in October as a major update packed with new features.

Today, Apple has another new iPhone software update rolling out: iOS 27.2.1.

As often happens when a big update arrives, Apple has followed up with a minor release that addresses some bugs in the last update and adds the latest security fixes too.

This update provides bug fixes and security updates for your iPhone.

For information on the security content of Apple software updates, please visit: https://support.apple.com/100100

Apple’s webpage linked above hasn’t yet received details on the new security updates, but it should be updated in the coming hours with those specifics.

If you own an iPad, iPadOS 27.2.1 has also been released with similar fixes.

The next big update that will offer new features is iOS 27.3, which is currently available in beta. It includes major Siri AI upgrades including Siri Recap, plus new Apple Music features, and a lot more.
