How to build a daily "new remote jobs" feed from public job-board APIs

Tanggal: 2026-11-17

You want a daily list of new remote jobs for yourself, a newsletter or a small job board. Several boards publish a JSON API or an RSS feed for exactly this. Each one comes with attribution rules and polling limits, though, and the same job often shows up on two boards.

I called two of these for this post and read the terms of the rest on 2026-11-11. Re-read each board's page before you ship anything.

Terms differ enough to matter. At least one board with an open API, Himalayas, forbids passing its jobs on to third parties, so I left it out.

We Work Remotely puts "Company: Title" in one field, so the script splits on the first ": ". Dates arrive in different formats; normalise them before you sort.

Save the first script as boards.py. This one builds a key from company and title, merges matches across boards, and remembers keys between runs.

The first run printed all 122 postings. I then removed five keys from seen.json and ran it again, so those five came out as new:

The first line is a real cross-post. Two different listings from the same board with the same company and title also turned up, and the script keeps those apart: two postings on one board are usually separate openings, one per region for example. Only a match across different boards is treated as a duplicate.

Disclosure: I'm the developer of an Apify Actor, Remote Jobs Scraper, published under Cedarfetch Labs. It reads seven boards (Remote OK, We Work Remotely, Remotive, Jobicy, 4dayweek.io, Remote First Jobs and Arbeitnow) through their official feeds and returns one schema with the location restriction parsed into countries and regions. It merges cross-posts and lists the other boards in alsoOn, puts each board's attribution terms on every row, and with change tracking on a daily schedule it can return only new jobs.
