I Built 23 Free Browser File Tools with Zero Backend Servers (Astro 6 + WASM)

Tanggal: 2026-11-21

Every time I needed to merge two PDFs, convert an iPhone HEIC photo, check video loudness (LUFS) before uploading to YouTube, or inspect C2PA metadata, I felt uneasy uploading personal or work files to random online converters.

So I built GlowPunch, a collection of free browser utilities designed around one principle: if a browser can process the file locally, it should never leave your device.

I recently refreshed the UI and launched English versions for the first 8 tools:

Many local web tools claim "zero network traffic" or "100% risk-free." I intentionally avoid those claims on GlowPunch.

While your target files are processed locally without uploading to our servers, normal page loading, first-run CDN downloads for AI/WASM models, and optional analytics still make network requests. Large videos are also bounded by your browser's RAM and codec support. Documenting those limits clearly right next to each tool has been a big part of the design.

If you try any of the tools at glowpunch.net/en, I'd love to hear your feedback or which local-first browser tools you'd like to see next!
