Run SolonCode Without Installing It: Double-Click Into the Web UI

Tanggal: 2026-11-16

You don't have to install SolonCode to use it.

In v2026.11.15, SolonCode added a no-install "direct run" mode: drop the release folder anywhere — a USB stick, a network share, a scratch directory on a borrowed machine — and double-click one of the bundled launchers. It starts the full Web interface on http://localhost:4808/ and opens your browser. No PATH registration, no installer, no admin prompt.

That's the whole point of the feature. Let's look at what it actually does and where its limits sit.

The release package ships three launchers, one per platform:

Each launcher does exactly one thing: invoke Java against the bin/soloncode-cli.jar that sits in the same folder, in web mode. The run.sh entry point is self-contained:

On macOS, run.mac.command exists because Finder opens a .sh file with a text editor, not Terminal — so it opens Terminal and hands off to run.sh. On Windows, run.window.cmd holds the window open after the program exits so the start message doesn't just vanish.

The folder is portable. Move it to a machine that has Java 8 or newer and it runs. The launchers take no arguments and do no port probing or instance takeover: if 4808 is already in use, they report the conflict and stop — close the previous window, then start.

This is the scenario I'd reach for: you need to show someone what a coding agent does, or trial it in an environment where you shouldn't be touching PATH or the system install — a shared network build folder, a CI runner image, an air-gapped box, a customer's laptop for a 20-minute walkthrough. You bring a folder; they double-click; the Web console is up.

Because it's the same JAR as the installed product, whatever you do in the Web UI works identically — it's not a reduced "demo build."
