Generate printable kennel run cards and vaccine expiry audits with pdf-lib

Tanggal: 2026-11-27

Juno checks in January 10 and leaves January 13. The recorded rabies expiry is January 13, so it covers the visit under this facility's sample policy. The recorded bordetella expiry is January 11, so the run card flags it for review. Check the full stay before printing the card that goes on the kennel door.

The example checks the vaccines configured by the facility. Each expiry is the last day the facility accepts the record, so an expiry equal to checkout passes. Store arrival, checkout, and expiry as property-local YYYY-MM-DD dates. Validate them before comparing strings. The UTC round-trip below detects impossible inputs such as February 29, 2027 without converting a booking date to a local timestamp.

Keep missing and malformed dates separate from dates that expire before arrival or during the stay. The same decision rows feed a JSON audit and the printable card. The card fixture includes the dog, run assignment, dates, and feeding instruction. Staff can act on the record status at a glance, and the front desk can review the exact date in the audit.

US Letter is 612 by 792 PDF points. Give each card 348 points of height inside 36-point margins with a 24-point gap. Measure each text line with the embedded font before drawing. This sample rejects overflow so long input cannot disappear off a card. The fixtures use characters covered by standard Helvetica. For multilingual data, embed a font that covers the input and wrap text within the card's bounds. pdf-lib PDFDocument API · Font measurements

Save the block as kennel.mts. In the same directory, run npm install pdf-lib@1.17.1 and then node kennel.mts using Node.js 24. Three bookings produce a two-page kennel-run-cards.pdf and vaccine-audit.json. Node.js TypeScript documentation

Print a proof at actual size to check the run labels and spacing. Use the same booking ID on the run card and the staff schedule so revised assignments can be traced to the right animal. For a boarding intake workflow with run card PDFs and a schedule workbook, see PetBoardPack.
