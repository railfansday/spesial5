Tanggal: 2026-11-18

Optimizely Hack Hijacked Ledger, BBC and 176 Other Sites to Swap Crypto Wallet Addresses

An attacker hijacked Optimizely, a platform widely used by companies to run experiments on their websites, to serve malware that swapped visitors' crypto wallet addresses for their own, on sites including hardware wallet maker Ledger.

Optimizely said in a status update on Monday evening that an unauthorized party had exploited a vulnerability in its Experimentation product to add malicious JavaScript to some customer projects. The company said it had fixed the flaw, removed the injected code, secured affected user accounts and added protections to stop unauthorized code being delivered.

Earlier today, Optimizely identified and contained a security incident affecting some Optimizely Web Experimentation customers. The vulnerable path is blocked, the injected code was removed, and customers have been contacted directly.

— Optimizely (@Optimizely) November 17, 2026

Researchers at security firm Report URI, which sells tools to detect malicious website scripts, found the malicious code in 188 of the 1,611 Optimizely scripts they examined, belonging to 178 organizations, according to a blog post by founder Scott Helme. The affected sites included Zoom, the BBC, CNN, Salesforce, GitLab, IKEA and HSBC, as well as crypto and trading firms such as Ledger, IG and OANDA.

Because the code was served from Optimizely's own trusted servers, affected websites loaded it without their own systems being breached.

The malware's main purpose was to steal crypto. The script scanned web pages for valid wallet addresses on networks including Bitcoin, Ethereum, Tron, Solana and TON, and replaced them with addresses controlled by the attacker, according to Report URI. It also swapped addresses copied to a user's clipboard, meaning anyone who copied an address while an affected page was open could have pasted the attacker's instead.

The attacker's wallets received about $7,150 in crypto, mostly in Bitcoin, Litecoin and USDT, according to Report URI's update on Tuesday. The attacker emptied the wallets early on Tuesday. One Tron address used to cash out had also been used in earlier operations in March and on November 3, allowing Report URI to link the attacker to other attacks, the firm said.

The script also skimmed card details typed into some sites' own payment forms, though not those entered into hosted payment fields such as Stripe's, and on iPhones and iPads it attempted to load exploit kits known as Coruna and DarkSword, which target older versions of iOS. Report URI said it could not see how many card numbers were stolen or how many devices were compromised.

The injected code first appeared early on November 16 UTC, and had been removed from all of the scripts Report URI could find by late that evening.

Optimizely spokesperson Victoria Johnson told Gizmodo that an unauthorized party had "exploited a vulnerability in the Experimentation account signup flow," and that the company had blocked access to the vulnerable path, deployed a fix and notified all affected customers. The company has not said how the attacker gained access to other customers' projects.

Helme said visitors to affected sites on November 16 should check any crypto transfers they made, update their iPhones and iPads, and watch their card statements. Website operators should review custom code in their Optimizely projects and rotate credentials, he added.
