Apple’s new HomeView to add two major features not yet announced, per leaks

Tanggal: 2026-11-14

Apple’s HomeView arrives this Friday (pre-order here), but leaks indicate there are already two major new features in the works that haven’t been announced. Here’s what to expect.

It’s been a busy product launch season for Apple, and the company isn’t done quite yet.

Two new Home products arrive in stores this Friday, November 13: Apple HomeView and the new Apple TV 4K.

Yet despite the HomeView still being days away from launch, leaks in Apple code have already revealed two unannounced features that are in the works.

Leaker pdfu discovered evidence in HomeView 27.2 software that Apple is preparing for the product to add security camera functionality.

Based on pdfu’s findings, much of the work has already been done for HomeView to integrate with HomeKit Secure Video.

However, Apple hasn’t announced any sort of security camera functionality, so there’s clearly still more work to be done and it’s always possible the feature is never enabled.

Additionally, pdfu found a key change in iOS 27.3’s beta that reveals support for third-party AI apps is coming to HomeView.

HomeView has a unique third-party app story. There’s no App Store, but the product can run CarPlay-compatible apps from your iPhone automatically. At launch, only audio and video apps will be supported.

But iOS 27.3’s beta code adds “conversational apps” as a third category of supported apps. That’s what AI chatbots like ChatGPT and Claude are classified as in CarPlay.

Nobody should buy a HomeView in the hope of these two features being added. But if you are interested in HomeView, it sounds like Apple has an ambitious set of software updates planned for its new product.
