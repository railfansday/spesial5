You need a YouTube API key the moment your app has to read anything from YouTube: a video's length, its view count, a channel's latest uploads. Getting one takes about five minutes. Using it well takes a little longer, because YouTube changed how its quota works in June 2026, and plenty of guides still describe the old rules.

In this guide we'll get a key, lock it down and test it. Then we'll use it from Node.js for three real jobs: adding up the length of a playlist, listing a channel's videos without spending a search, and estimating what a video earned. Along the way we'll cover what the YouTube API costs (nothing), how the 2026 quota works, and the errors you're most likely to hit.

A YouTube API key identifies your project to the YouTube Data API v3. With just a key, you can read public data:

A key isn't enough for anything that touches someone's account. Uploading videos, editing playlists or reading private data needs OAuth 2.0, where the user signs in and grants your app access.

You'll need a Google account. The YouTube Data API is free, so there's nothing to pay for.

The restrictions matter more than they look. A key is just a string in a URL, and anyone who copies an unrestricted one can spend your daily quota for you. With an API restriction, the key is useless for other Google APIs. With an application restriction, it only works from your server or your site. Changes to restrictions can take up to five minutes to apply, so don't panic if a request fails straight after you save.

That request cost 1 unit of your daily quota, which brings us to the question everyone asks.

Yes. There's no charge per request and no paid plan. Instead you get a daily quota, and since June 1, 2026 it's split into separate buckets:

Google's quota calculator lists the cost of every method. Quotas reset at midnight Pacific Time. Every request costs at least 1 unit, including requests that fail, so a retry loop around a broken call can use up a day's quota on its own.

If you've read older guides, search is the big change. A search used to cost 100 units out of the same 10,000, so 100 searches emptied your whole day. Uploads were worse still, at about 1,600 units each until December 2025. Now both have their own buckets, and the 10,000 units are left for everything else.

You can't pay for more. To go above the defaults, fill in the YouTube API Services Audit and Quota Extension Form, which is linked from Google's page on quota and compliance audits. YouTube first audits your project to check it follows the YouTube API Services Terms of Service, then someone from the API team gets back to you. Google doesn't give a timeline, so apply well before you need the extra quota.

Most projects never need to. The rest of this guide is about getting a lot done with very few units.
