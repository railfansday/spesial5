Indie web browser Ladybird enters alpha testing

Tanggal: 2026-11-27

Upstart engine gets downloadable macOS and Linux builds, but no security guarantees

The independent Ladybird web browser has reached an important milestone: an alpha test version. What's more, it works well. These may not be the criteria by which some will judge it, though.

Earlier this week, the developer behind the Ladybird web browser announced that Ladybird is now in alpha. We've given it a brief test, and it performed very well. It's more stable and works better than its alpha label would suggest.

There are downloads available, covering macOS on Apple Silicon, as well as for Linux on x86-64; for the latter, there's a Flatpak package, as well as native Ubuntu and Fedora packages.

It's an open source project, so you can download the source code from the GitHub repository and compile it yourself, but in an unusual move, back in June the project announced that the developers would no longer accept public code contributions.

We first mentioned Ladybird as part of our early 2022 look at its original parent project – SerenityOS: Remarkable project with its own JS-capable web browser. Both the name and the date are significant: the former is a nod to the Serenity prayer, recited at the end of Alcoholics Anonymous meetings. The date of the article is because it's well before the launch of ChatGPT at the end of 2022.

About a year and a half later, we reported that Serenity OS turns five and emits first offspring, Ladybird. Both the OS and the browser were still hand-coded, but now the browser could be compiled and run on other OSes. That freed it up to call upon external libraries which didn't exist for SerenityOS.

Earlier this year, we wrote Ladybird flutters toward Rust with a little help from AI. At one point, developer Andreas Kling used Apple's Swift language, but this year, he changed course and adopted Rust instead, using LLM tools to convert some existing code. Some will dismiss Ladybird because of this, but as our first coverage shows, the browser and its original host OS were established projects before the current wave of AI-assisted development.

Kling does use LLMs, but Ladybird is not some sloppy vibe-coded effort. The macOS download is 68.4 MB in size, which in 2026 is remarkably small. The Flatpak is larger – about 111 MB – but it also pulls in some KDE dependencies which increase its size.

We tested it on Pop!_OS. It handles sites such as The Register and Hacker News and everything else we tried perfectly, and took just 6 percent of our Dell XPS13's CPU to play full-screen HD video from YouTube smoothly. In our short testing, we saw no crashes, hesitation, or any other problems at all.

The developers nevertheless warn that the alpha can crash, some websites will not work, and they make no security guarantees at this stage.

The use of LLMs will put some people off. However, this is not the only controversial thing about the project. As we have noted in our previous coverage, Ladybird belongs to the same political wing of the FOSS movement as Omarchy, XLibre, and other right-wing projects. If the LLM use doesn't put you off, the political views may. On the other hand, as we've seen from our earlier coverage of Omarchy and XLibre, the same factors also attract others.

The modern Web is an entire complex compute platform in its own right, and currently, only three tools support it – and two of those are interrelated. The dominant engines are Google's Blink, used by Chrome and other Chromium browsers; Apple's WebKit, used by Safari; and Mozilla's Gecko, used by Firefox. Blink was forked from WebKit.

Some day, when the Servo project matures some more, it may be another. Even so, today, the first preliminary release of Ladybird means that there are now four competitive modern browser engines. That's a significant step. ®
