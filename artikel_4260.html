Kirby Air Riders For Switch 2 Receives Another Small Update

Tanggal: 2026-11-05

Alongside the latest event for Kirby Air Riders, Nintendo has this week rolled out a new update for the racing title.

This bumps the Switch 2 release up to Version 1.3.4. Apart from the new event, which has now replaced the Halloween one, the latest patch comes loaded with a bunch of bug fixes, including several other "miscellaneous gameplay fixes".

As usual, the latest version may not be compatible with the existing replays. Here's the full rundown, courtesy of Nintendo's official support page:

No changes impacting rider or machine performance have been made.

Note: Ver. 1.3.4 may not be compatible with replays from Ver. 1.3.3 to Ver. 1.3.0. Ver. 1.3.4 is not compatible with replays from Ver. 1.2.0 and earlier. Convert replays you want to keep to video files by selecting Record on the playback-settings screen within Cached Data and Data Replay before downloading the update. (Note: A microSD Express card is required to use this function.)

If you haven't already seen our previous post, the latest event includes a ruleset from the Shadow Star's Revenge event (which last appeared in March 2026). It will run from now until 9th November 2026.
