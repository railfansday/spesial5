iOS 28 to ‘revamp’ iPhone notifications, per report

Tanggal: 2026-11-28

iOS 28 is coming next year, and a new rumor says the update will “revamp the iPhone’s notification system.” This comes as Android has introduced features like “Notification Organizer” to help users sort notifications into different categories.

The report cites “multiple sources” and comes from MacRumors. There aren’t any specific details about what changes iOS 28 will introduce for notifications. “The sources said iOS 28 will include significant changes to Notification Center, but we do not have any specific details,” the report says.

The iOS notifications system is overdue for an update. While Apple has added features like Apple Intelligence-based priority notifications and notification summaries, the system still lacks other organization and sorting settings.

Android 16 introduced several significant notification changes, focused primarily on reducing clutter and prioritizing important information. For Pixel devices, the update also introduced Notification Organizer, a feature that automatically groups and silences low-priority alerts, including promotions, news, and social media notifications.

As Abner explained on 9to5Google last year:

The Notification Organizer will sort your alerts into the following categories: Promotions, News, Social, and Suggested. The first two are already on, but you must enable the remaining ones. There’s also an option to “Always expand bundles.”

I’d love for Apple to adopt a similar system on iPhone, iPad, and Mac. Even with the recent Apple Intelligence additions, the iOS notifications system is still far too basic.
