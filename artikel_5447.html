Advantech Powers High-Density Edge Infrastructure with the Intel Atom P6900 Processor-Based SOM-5994 Module

Tanggal: 2026-11-11

TAIPEI, Nov. 10, 2026 /PRNewswire/ -- Advantech, a global leader in embedded computing and edge AI solutions, has announced the launch of the SOM-5994, a COM Express Basic Type 7 module powered by Intel Atom P6900 processors. Designed for compute-intensive edge networking, 5G infrastructure, and next-generation telecommunication applications, the SOM-5994 delivers high-core-density processing, advanced networking connectivity, and flexible expansion capabilities in a standardized COM Express form factor. The module supports up to 24 server class efficient- cores, PCIe Gen4 expansion, DDR5 SODIMM memory, and integrated Intel Ethernet technology supporting 10GBASE-KR connectivity. Optimized for High-Performance Networking Workloads

Powered by Intel Atom P6900 processors specifically designed for networking and telecommunications applications, the SOM-5994 combines high core density, advanced I/O connectivity, and flexible scalability within a compact COM Express Basic Type 7 module.

When compared to the Intel Xeon D-1700 processor family, the SOM-5994 with Intel Atom P6900 processors delivers higher overall performance. Offerings range from efficient 8-core to 24-core SoCs with thermal design power (TDP) spanning 50W to 86W, enabling system designers to balance compute density, power consumption, and thermal budgets to meet specific application requirements.

The module supports up to 128GB of DDR5-5600 memory and provides up to 16 PCIe Gen4 lanes and 16 PCIe Gen3/Gen2 lanes, delivering the bandwidth required for virtualization, packet inspection, software-defined networking (SDN), network security, and other data-intensive networking workloads. For networking connectivity, the SOM-5994 integrates four 10GBASE-KR Ethernet interfaces for backplane applications alongside an integrated Ethernet controller supporting up to 2.5GbE, enabling flexible deployment across a wide range of networking architectures.

Comprehensive Software and Design-In Support

Beyond hardware performance, the SOM-5994 is backed by Advantech's comprehensive Embedded Solutions and Design-In Services, helping customers accelerate product development and reduce engineering risks. These services include carrier board design support, BIOS customization, thermal solution consultation, Linux development resources, system validation, and long-term lifecycle management. Together, they enable OEMs to streamline development while ensuring platform reliability across the entire operating lifespan.

The module also supports Advantech SUSI APIs, Yocto project integration, and customizable BIOS features, providing developers with a flexible software framework for hardware monitoring, system management, and Linux deployment.
