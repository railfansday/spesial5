MiniMax-H3-Image by MiniMaxAI is a unified text-to-image and image-editing model in the MiniMax H3 family. It supports reference-image editing and generates images at high resolutions, with a typical target around 16 megapixels.

Generate images from text prompts; edit one or more reference images; create images at varied aspect ratios, including square, portrait, landscape, and ultrawide formats. The model documentation describes support for up to 16 reference images.

Prompts are truncated at 4096 tokens. Negative prompts are unsupported; inference steps must be 6 and guidance scale must be 1 (or omitted), otherwise requests are rejected. The model's listed repository size is 68.65 GB, and its separate MiniMax-H3 text encoder is also required. The supplied sources provide no independent benchmark results for image quality or performance.

The related MiniMax-H3 is the broader H3 model; this checkpoint removes its audio branch and is specifically for image generation and editing. The optional prompt-expander is a separate model version and is not required for the core image model. No supported performance comparison with alternatives is provided.

The diffusion transformer has 33.1B parameters, 50 layers, hidden size 5376, 56 attention heads, and FFN size 14336. It is a dense single-stream transformer with 3D multimodal RoPE. Transformer weights are BF16, while embedding, timestep, and output layers are FP32. The image VAE has a CNN encoder and 24-layer 2D ViT decoder, 16× spatial downsampling, and 24 latent channels. The model uses the MiniMax-H3 Qwen3-VL text encoder unchanged; that encoder is not included in this repository. Sampling is distilled to 6 steps without classifier-free guidance. The effective image range is about 4–20 MP, with results generally targeted around 16 MP. Listed model size is 68.65 GB; the text encoder is listed separately at 66.7 GB. Supported serving frameworks named in the source include SGLang, vLLM-Omni, diffusers, and ComfyUI. Hardware examples include NVIDIA H200, RTX PRO 6000 Blackwell, and AMD Instinct MI350X; no minimum hardware requirement is specified.

Text-to-image and editing both require a prompt and a WIDTHxHEIGHT size. Editing accepts one or more reference-image files; upload order maps to Picture 1, Picture 2, and so on in the prompt. An integer seed is recommended, and CPU is the recommended generator device for consistent initial noise across machines. The optional min_generation_area ranges from 1024 to 16777216 pixels and defaults to 4194304; smaller requested sizes are generated on a larger same-aspect-ratio canvas and resized with LANCZOS unless this behavior is disabled by setting the minimum to 1024.

The documented serving API returns PNG image data in data[0].b64_json. The requested WIDTHxHEIGHT is the exact returned image size. Common approximately 16 MP sizes include 4096x4096, 4736x3552, 5024x3360, 5472x3072, and 6272x2688, with corresponding portrait orientations where listed.

Q: Can this model edit images as well as generate them?

A: Yes. The same checkpoint supports text-to-image generation and editing one or more reference images.

Q: How many reference images can I provide?

A: The model documentation states support for up to 16 reference images.

A: The documented effective range is about 4–20 megapixels, with results generally targeted around 16 megapixels. The requested width and height determine the exact returned dimensions.

Q: Can I use a negative prompt or change the sampling steps?

A: No. Negative prompts are rejected, and the supported inference-step setting is 6; other values return an error.

Q: Is the text encoder included in this repository?

A: No. The model loads the MiniMax-H3 text encoder separately; the supplied download command retrieves it into the Hugging Face cache.

Q: Does the model require a prompt expander?

A: No. The prompt expander is listed as an optional, separate model version; it is not required for the image checkpoint.
