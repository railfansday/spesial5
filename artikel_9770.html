Superpowers Plus Thomas Ricouard's Swarm Skills: 31 Agent Skills for Disciplined Coding

Tanggal: 2026-11-17

Two builders' skill sets make AI coding agents work like disciplined engineers. Jesse Vincent's Superpowers adds 15 skills that make the agent brainstorm, plan, test and verify before it calls anything done. Thomas Ricouard's Skills adds 16 that run parallel review and bug-hunt swarms and cover Swift, SwiftUI and macOS work.

All 31 are MIT-licensed and installable from Cuttlefish.MD, HackerNoon's license-checked skills marketplace. They follow the open Agent Skills standard, so they work in Claude Code, Codex CLI and 30+ other tools. Each is indexed in HackerNoon's SKILL.md Library.

Superpowers is a full workflow: it starts every session by finding the right skill, and it won't let the agent claim success without running the checks.

Finds out what you actually want before any feature or component gets built

Explains why a session went wrong: repeated work, ignored plans, stumbles

Splits two or more independent tasks across parallel agents

Works through an implementation plan step by step in the current session

Decides how to merge finished, tested work

Checks review feedback for technical merit before acting on it

Gets work reviewed against requirements before merging

Hands each task in a plan to a fresh subagent

Finds the root cause of a bug or failing test before proposing a fix

Writes the failing test first, then the code

Isolates feature work in its own git worktree

Teaches the agent to find and use skills at the start of every conversation

Runs the checks before the agent claims anything is fixed or passing

Writes a step-by-step plan from a spec before touching code

Creates and tests new skills before they're deployed

Ricouard's set runs read-only agent swarms for review and debugging, and goes deep on Swift, SwiftUI and macOS.

Writes App Store release notes from every user-facing change since the last tag

Runs parallel read-only agents to find a bug's root cause

Builds, runs and debugs the iOS project on a simulator with XcodeBuildMCP

Builds and reviews macOS menubar apps that use Tuist and SwiftUI

Scaffolds and packages SwiftPM macOS apps without an Xcode project

Plans and runs large refactors with parallel agents

Reviews past sessions and memory files to recommend the skills worth writing

Fixes slow renders, re-render thrash and laggy lists in React

Reviews a diff for reuse, quality and clarity, then simplifies it

Runs parallel read-only agents over a diff to catch regressions

Builds and reviews SwiftUI features with the iOS 26 Liquid Glass API

Audits and improves SwiftUI runtime performance

Example-driven patterns for SwiftUI views, navigation and modifiers

Refactors SwiftUI views into small subviews with MV-over-MVVM data flow

In Claude Code, add the marketplace and install the Dev Workflow plugin, which holds 28 of the 31. The last three sit in QA & Testing (test-driven-development), Writing & Blogging (writing-skills) and Design & UI (swiftui-ui-patterns).

For Codex CLI, Cursor or another agent that supports the standard, clone the repo and copy the skill folders you want into your agent's skills directory, such as .agents/skills/. Superpowers also ships its own marketplace from Jesse Vincent's repo.

Each skill keeps its MIT license and an ATTRIBUTION.md naming its author and source commit. Browse the full library at hackernoon.com/skills, and star Cuttlefish.MD on GitHub if these make your agent less reckless.
