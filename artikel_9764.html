Most "find the best chess move" websites work the same way: you send a position to their server, an engine analyses it there, and they pay for every second of CPU. That's why so many of them cap free analysis per day or fill the page with ads.

When I built Chess Move Finder, I went the other way. Stockfish 17.1 runs entirely in the user's browser. The server only serves static files. Analysis costs me nothing per user, so the tool can stay free with no account, no ads and no daily limit.

Here's how it works and the tradeoffs I ran into.

Stockfish's WebAssembly builds come in a few flavours, and the choice matters more than I expected.

Multi-threaded builds need SharedArrayBuffer. That means the page must be cross-origin isolated: you have to send Cross-Origin-Opener-Policy and Cross-Origin-Embedder-Policy headers. That's fine for a single-page app, but it breaks a lot of normal things on a content site: third-party embeds, some analytics, images from other origins. My site has a blog and other tools alongside the engine, so I didn't want those headers everywhere.

The single-threaded build needs none of that. It works on any page, in any modern browser, on any phone.

"Lite" means a smaller neural network (NNUE) file. The full network is large; the lite one is a fraction of the size. It plays slightly weaker, but it's still far stronger than any human, and the first analysis starts much faster, especially on mobile data. For a "what's the best move here?" tool, a fast first answer matters more than the last few Elo points.

Fixed depth sounds cleaner, but depth 20 takes wildly different times on a desktop and a budget phone. A time budget keeps the experience predictable, and the engine simply reaches a deeper depth on faster hardware.

The UCI score is always from the side to move's perspective, so you have to flip the sign when it's Black to move to show a consistent White-relative evaluation. It's a classic first bug.

Most users arrive with a position from somewhere else: a game on Chess.com or Lichess, a puzzle, a book. So the tool accepts a FEN string and also lets you set up the board by hand. Every position can also be shared with a link, so you can send it to a friend and ask "what would you play here?"
