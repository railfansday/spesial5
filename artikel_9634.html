From Brython to React + TypeScript: How I Built 42+ Math & File Utilities 100% in the Browser 🛠️🚀

Tanggal: 2026-11-26

In 2021, I just wanted to stop wasting time on repetitive calculations and broken files at work.

I didn't want to spin up a server, configure a database, or pay for hosting. I just wanted to open a browser tab and solve the problem on the spot.

Five years later, that simple page turned into Ahtools, a suite of over 42 mathematical calculators, file parsers, and cryptography utilities running 100% client-side.

Spoiler: the codebase has been rewritten three times—moving from client-side Python in the browser, to vanilla JavaScript, and most recently to a full TypeScript and React refactor with the help of AI.

Grab a coffee and let me walk you through how this architecture evolved. ☕👇

When you deal with corporate spreadsheets, system logs, and sensitive records, sending files to an external API is always a liability.

That's why Ahtools was designed from day one around Zero Backend Storage. Everything runs inside the user's browser sandbox:

Instead of juggling massive spreadsheets or scattered terminal scripts, I built dedicated calculation and data-processing engines straight into the app:

Fisher-Yates shuffle randomizer that outputs SHA-256 sealed PDF receipts for auditable draws.

Parsers & File Engineering: fixed-width positional file auditing (such as 240-column batch layouts with cent-level control totals), bidirectional JSON ⇄ CSV conversion with nested object flattening, invisible UTF-8 BOM stripping, local OCR powered by Tesseract.js, lossless PNG merging, PDF concatenation, and network latency/jitter diagnostics.

I've been working on Ahtools since 2021, adding and refining features almost every single day. Looking back, the project's architecture ended up documenting my own growth as a developer:

Each phase solved the bottleneck of its time. Starting with Brython let me ship a working tool fast using a language I already loved, while migrating to strict TypeScript eliminated silent type bugs in complex math formulas and made maintaining 42+ tools in a single SPA sustainable.

The Ahtools repository remains private, as it started out as a personal toolbox built to solve real day-to-day support and operational bottlenecks.

Even so, the live application is deployed, open, and completely free for anyone to test or use in their workflow:

👉 Try Ahtools live: https://delean-mafra.github.io/Ahtools/

If there's one thing working on this project daily since 2021 has taught me, it's that you don't need the perfect stack to build something useful. You just need to solve a real problem today and make it 1% better tomorrow.
