Keep in mind it’s OK to do nothing at all, too.

Just bought a new computer and I am using it as an excuse to finally move entirely off Windows, so I am setting up Arch and figuring out how to get games working and all that.

Trying to find Europe-based partnerships for Uruky and investors for a different product (not under the same company because it'll require machine learning), which needs a good amount of cash investment upfront. Also trying to find some part-time work to help fund the lack of a paying job.

I am working on a PDF-merging program. This is to merge several pages from different PDF-files into one big page (not just concatenating the pages after each other). This is to align several maps produced from AutoCAD into one big map while removing overlapping sections.

While it's a small project I have learned some new things already about MuPDF and I'm using Raylib for the simple UI.

I've been building a DST platform (similar to Antithesis) and I'm onboarding a couple of friends so they can test their own systems.

Working to perfect mddog, a terminal tool that lets you preview Markdown in the terminal as if you're on GitHub or Obsidian: headings at the correct sizes, images rendered, etc.

I look at Markdown files a lot for work and prefer to just stay inside the terminal without switching out of it so this has been a game changer.

It basically works by building out the Markdown into its real format using macOS built-in engines like CoreText and CoreGraphics, then send the outputs to the terminal as image strips. I'm enjoying learning about the terminal, Rust, and the kitty graphics protocol throughout this process.

If you give it a try, let me know how you like it!

Inspired by previous comments, was working on a new kind of terminal:

Programs output one of two binary formats, one being pure structured object data based on CBOR and the other being a kind of XML markup (the latter is what you see in the top screenshot: charts and a table nested within flex layouts). Then end goal is a PowerShell/nushell-like environment where external programs, not just builtin commands, can output structured data and, uh, nicely formatted markdown documents without resorting to sixels or custom terminal protocols for things like drawing borders on cells.

Still a lot to work out, but I'm hoping to have a writeup soon which I might post here.
