Why Stale CLAUDE.md and AGENTS.md Files Override Working Code in 90.1% of Runs (And the One-Sentence Fix)

Tanggal: 2026-11-10

Instruction files like CLAUDE.md and AGENTS.md are usually written once when a repository sets up a coding agent and rarely touched again. Across 441 company repositories analyzed by Denisov-Blanch et al. (2026), 73.8% of AI configuration files were committed once and never modified. In a separate study of 356 public repositories by Treude and Baltes (2026), 23.0% of instruction files referenced code elements that no longer existed.

When the codebase moves on while the instruction file stays frozen, coding agents receive two contradictory sources of truth. A study by Xiaonan Xu and Wenjing Wu from Georgia Tech and UC Boulder (arXiv:2610.30571) measured what Claude Code and OpenAI Codex CLI do when CLAUDE.md or AGENTS.md disagrees with the existing code across 320 runs on 40 Python projects.

Each of the 40 Python projects in the study had working modules, a passing test suite, and an instruction file asking for one convention while the existing code used another across 16 convention categories (for example, print() versus logging, os.path versus pathlib, or string constants versus Enum). Claude Code (v2.1.302 on Claude Sonnet 5.5) and Codex CLI (v0.163.0 on GPT-6 Sol) were asked to add a feature in 320 unattended runs totaling 720 convention choices.
