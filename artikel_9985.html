Maxanti - A logic puzzle

Tanggal: 2026-11-17

I vibecoded a puzzle game for a math professor friend of mine as a birthday present. He seemed to like it, so I am sharing it with all you guys as well. My friend enjoy figuring things out by himself, for him it's part of the puzzle, so the manual link provided below was not initially given to him.

The game has no ads, no cookies, no analytics - the server doesn't even write an access log. That being said, I have really no idea of what's going on inside the code, I have not read any of it or done any proper review. The model used was Fable 5.2 on high effort, and the project was done in an afternoon and ended up using about 11m tokens. It was designed as a mobile first PWA project using a Bauhaus inspired theme. The size of the download is about 200KB.

The game: https://maxanti.com

The manual: https://maxanti.com/help
