Nineteen open-licensed agent skills let an AI agent test a web app the way a person would: write the test first, open a real browser, click through the flows and report what broke. They come from Vercel Labs' agent-browser, Tech Leads Club, Anthropic, Matt Pocock, Jesse Vincent and lackeyjb.

All 19 are packaged as the QA & Testing plugin in Cuttlefish.MD, HackerNoon's license-checked skills marketplace. They follow the open Agent Skills standard, so they run in Claude Code, Codex CLI and 30+ other tools, and each is indexed in HackerNoon's SKILL.md Library.

A browser automation CLI built for AI agents

Runs agent-browser on AWS Bedrock AgentCore cloud browsers

Debugs, profiles and automates the browser through the Chrome DevTools MCP server

Records a demo video of a feature on a real desktop with a real cursor

Records browser traffic to reverse-engineer a site's internal API and generate a client

Explores a web app systematically to find bugs and UX problems

Automates Electron desktop apps such as VS Code, Slack and Figma

Tech Leads Club's packaging of Playwright browser automation

Tests Vercel deployments behind SSO or Deployment Protection

Works in Slack workspaces through browser automation

Grades how completely an implementation meets its PRD, case by case

Builds features and fixes bugs test-first, red-green-refactor

Writes the failing test before any implementation code

Plans and builds features in four phases: specify, design, tasks, execute

Runs agent-browser and Chrome inside Vercel Sandbox microVMs

Builds and validates experimental WebMCP tools for a page

For Codex CLI, Cursor or another agent that supports the standard, clone the repo and copy plugins/qa-testing/skills/ into your agent's skills folder, such as .agents/skills/. The agent-browser skills need Vercel's agent-browser CLI installed.

Each skill keeps its license and an ATTRIBUTION.md naming its author and source commit. Browse the full library at hackernoon.com/skills, and star Cuttlefish.MD on GitHub.
