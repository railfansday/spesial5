One Prompt, 18 Visual Styles: How I Proved My Short-Video Identities Are Actually Different

Tanggal: 2026-11-21

I run a few faceless short-video channels (TikTok, Reels, Shorts), and they all had the same problem: they looked like everyone else's. Same template, same captions, same stock motion. So I asked an AI agent to explore the opposite: how many genuinely different visual identities can you build for vertical shorts, entirely in code — and can you prove they're different?

The result is an open-source repo with 18 identities, each proven by 2–3 real shorts rendered by code (45 in total), and a single prompt that turns any of them into your own studio.

18 identités visuelles pour vos vidéos courtes, prouvées par 45 vraies vidéos. Un prompt suffit pour donner son style à votre chaîne. Open source.

Ask an agent for "a cool visual style for my channel" and you get one style, described in adjectives, with nothing to check it against. What I wanted was a menu with evidence: several identities side by side, each one documented in the same format and backed by real renders, so the choice is made by looking, not by vibes.

Yes, the tooling talks French — the project started for French channels. Note the warning on the borrowed template: a blend keeps one identity's signature and only borrows structure from the other. Mixing two signatures is exactly how you end up generic again.

Here's the part that surprised me. To check that the 18 styles really are different, the repo has a measured test: a colour histogram in Lab space (Bhattacharyya distance) plus an edge histogram (χ²), 8 frames per short, and for each short, "is its nearest neighbour a short of the same identity?"

Taken at face value, that says liquid-chrome isn't a coherent style at all. So I ran a second test the way a viewer would: a fresh agent with no context got 72 anonymised frames — 2 shorts × 2 frames for each of the 18 identities, random file names, the key kept out of its reach — and one instruction: make 18 groups of 4 by style, not by subject.

It made 18 pure groups out of 18, 72/72 frames. Its own notes put the finger on why the metric failed: the liquid-chrome group "joins two quite different scenes (test tubes vs Newton's cradle), linked by the shared glossy iridescent 3D rendering and black ground", and the dark identities (neon lab, cosmos, topo relief, pixel arcade) "are neighbours in palette but separated cleanly by type and rendering technique".

That's the lesson. A colour-and-edges metric sees palettes. A style is mostly geometry and type: the chrome reflections, the pixel grid, the perspective of a 3D flyover. Two shorts of the same style on different subjects can have very different palettes (a blue ocean and a green mountain, for the pixel flyover), and two different styles can share a black background. I kept the metric — it's cheap and catches regressions — but the blind judge is now the evidence that counts.

It's a style menu and a production toolkit, not a channel in a box. Topic writing, fact-checking, review, publishing and scheduling are still yours (my own channels run those in a separate private template piloted from Notion; this repo only feeds it the style). And the agent can't hear: it measures loudness and checks timings, but someone still has to watch and listen to every episode.

Rendering is CPU-bound and uneven: from under 5 s per 100 frames (cut paper, single-line drawing) to around 3 minutes for the three.js space documentary, and over 5 minutes for one Manim chalkboard short — measured with several renders sharing a 4-core machine.

Everything is open source — the 18 design systems, the 45 shorts and their code, the render/voice/QA tools, and a Claude Code skill (fabrique-identites) that runs the whole "scout → adversarial challenge → studio → review" loop to add new identities.

If you build a studio from it, I'd love to see which style you picked.
