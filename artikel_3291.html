Microsoft declares a Code Red in response to worst ever outage

Tanggal: 2026-11-27

The recent Microsoft 365 outage was the worst the service had ever experienced, with more than 80% of the company’s servers unresponsive at the worst point. The company has now declared a Code Red to address the way it prevents and responds to major failures in future.

Microsoft has explained more about why it took so long to resolve the issue and said that it’s urgently working on new approaches to resolve any future incidents in less than an hour …

Code Red is a common term used to describe the highest priority response to a major problem, pulling a significant number of engineers off their current tasks in order to maximize the resources applied to fixing it.

The senior execs responsible for the service told staff that it was the most customer-impacting incident ever experienced, and has acknowledged that not only was the problem itself unacceptable, but so too was the time taken to resolve it. Reuters got sight of a memo sent to the team.

Never before had so many customers been without email for so long, he said. “Code Red means that this is the highest priority work for our team,” Henderson added.

Charles Lamanna, Microsoft’s executive vice president of Copilot, Agents and Platform, told a Code Red review that the affected component had experienced “roughly ten years’ worth of acceptable failures,” according to Silver’s memo.

One reason it took so long to work out what had happened was because the diagnostic data needed was “scattered across fragmented internal systems.” The memo says 11 separate Teams chats exchanged more than 11,000 messages as they struggled to work out what exactly had gone wrong.

Microsoft is now working on five interrelated approaches to achieve a target resolution time of less than an hour for any future incidents of this nature.
