Old-school Linux desktops find fresh routes to Wayland

Tanggal: 2026-11-25

Xfce lines up 4.22 for 2027, while MATE gains an Ubuntu-based distro and a compositor of its own

Xfce's next release is taking shape for 2027, while MATE users have fresh options for moving their familiar desktop onto Wayland.

One of the oldest surviving Linux desktops has a relatively slow release schedule: new stable releases of Xfce tend to appear every two years. The project just updated its release engineering roadmap for the forthcoming Xfce 4.22, and it looks like the next version won't arrive until early next year.

We covered the release of Xfce 4.20 in December 2024, but 4.22 is still incubating. The roadmap schedules its first prerelease and feature freeze for December 15, 2026, followed by a second prerelease on January 15, 2027. A third prerelease is optional, and neither that nor the final release has a date. February or March might be plausible, but that's our guess, not the project's promise. The Xfce developers tend not to rush into things.

Wayland development continues in 4.22, building on the preliminary support in 4.20. The team is also working on its own compositor, xfwl4, although the roadmap doesn't promise feature parity with X11. (In Wayland terminology, the "compositor" is the combined display server and window manager.) The compositor has its own development roadmap. The name is a nod to the current Xfce X11 window manager, which is called xfwm4.

The main developer of the new xfwl4 compositor is Brian Tarricone, who has been working on other parts of Xfce since 2004. Back in July, he shared a blog post about his use of generative-AI coding assistants called LLMs and xfwl4.

He says: "So yes, I use Claude quite a bit while developing xfwl4. I don't vibe-code, ever, and I probably use the LLM to generate less code than most people do. After all, building things with code is my hobby and passion (and I'm lucky I got to do it professionally for a quarter century), and driving an LLM is kinda boring."

We find this somewhat reassuring, but any really passionate anti-LLM Xfce users reading this may be glad that the release schedules of Ubuntu LTS versions and Xfce stable releases are so far out of sync – sticking with Xubuntu 26.04 means there's no immediate need to adopt the new LLM-assisted compositor. Or, of course, simply keep using X11 instead of Wayland – although that might eventually mean choosing a distro that maintains X11 support, perhaps through XLibre, which has other drawbacks for some.

There are other options, too. We've also seen an independent fork of xfwm4 called xfwm4-gl. It's in active development and uses OpenGL to perform window compositing directly, while the current version uses the now rather old Xrender extension.

Last year, when we looked at the release candidate of openSUSE Leap 16.0, we found that it ran Xfce on Wayland by replacing Xfwm4 with the labwc compositor that we first saw in PiOS 5.2. This worked well – about the only difference we could find was the absence of some window-management shortcuts.

(Saying that, this vulture is still happy with X11. There is only one Wayland feature we want: the ability to set different dots-per-inch ratios on different screens. We can approximate that on X11 by scaling individual outputs. This works well enough – it just makes one of the screens look a little fuzzy.)

Labwc is one of the more flexible, and X11-like, compositors out there, and can be found in other projects. Scott Sturrock recently wrote to us to tell us about his new MATE Wayland Desktop project. This is an independent distro, combining an Ubuntu 26.04 base, the latest MATE 1.29, and version 0.9 of the labwc compositor. (That's from labwc's older 0.9 series; the latest release is 0.20.3. The numbering jumped to align with the version of wlroots it uses, while 0.9 remains a maintenance branch.)

MATE is a continuing fork of GNOME 2.32, the final release of GNOME 2. GNOME 2 used the Metacity X11 window manager – indeed, the Windows-like GNOME Flashback session still uses Metacity, which is currently at version 3.56.0. MATE's fork of Metacity is called Marco.

There is already a way to run MATE using Wayland: the MATE Wayland Session uses the Wayfire compositor. Wayfire was inspired by Compiz, the 3D compositing window manager remembered for its "wobbly windows" effect, and Wayfire has lots of its own special effects, as the Wayfire wiki's tutorial demonstrates with a lot of animated images. Wayfire is quite a capable environment in its own right – so, arguably, somewhat overkill for the traditional-style MATE environment.

As yet another alternative, developer Kerem Söke recently announced a new MATE-specific compositor called Polo. Polo is intended as a direct replacement for Marco. The Polo 1.0 release notes tell some of the story. Polo aims to be as similar as it can to the familiar Marco window manager: it picks up existing configuration, keystrokes, Alt-Tab behaviour, and so on. It's already at version 1.0.2. It can do wobbly windows and so on as well, it has its own polo-tweaks program, and a roadmap for improving MATE's integration with Wayland.

Both projects went public around the same time, but MATE Wayland Desktop is already packaged up and ready to install. We suspect that if Polo is successful, it will find its way into the Ubuntu repositories, and perhaps the two projects will eventually come together.

Xfce is about a year older than KDE – however, the early releases of Xfce weren't open source. So, KDE is the oldest Linux desktop that has been open source from the start.

Xfce isn't the oldest Linux desktop of all, though. There were some proprietary commercial desktop environments around before either Xfce or KDE existed, such as IXI's X.desktop [PDF]. Most originally ran on commercial Unixes and were later ported to Linux – but they didn't stick around into the modern FOSS era. ®
