An AI coding agent, a browser, and a Mac tool found a financial firm's access key in under 6 minutes

Tanggal: 2026-11-26

No sophisticated malware or attack framework required

A Romanian hacker, armed with only an open source coding agent, a Chrome browser, and a Mac, tried multiple ways to break into a financial services firm, ultimately found an access key - luckily, it was a decoy - and carried out an entire (almost) attack in under six minutes.

It’s a stark reminder that miscreants don’t need sophisticated malware - as in the Binance heist - or AI pen-testing tools like ARTEX to carry out intrusions into critical networks. Open source coding agents, and specifically OpenCode in this case, also work just fine.

“What surprised me most was how little it took and the toolkit: a free coding agent, the curl that comes with every Mac and an ordinary Chrome, all from one laptop,” Jesta co-founder and CTO Lior Finkelshtein told The Register. “Until now I thought that we had more time until tools like OpenCode are used in offensive operations. This incident shows us that it's already in use in the field, and we will probably see more of that in the future.”

Jesta is a Tel Aviv-based security startup that builds defensive tools to detect and stop autonomous AI attacks. In a report shared exclusively with The Register, Finkelshtein documented an attempted intrusion targeting a major financial services company that’s also a Jesta customer - the security shop declined to say which one.

Jesta’s investigation into the incident determined that someone in Bucharest downloaded a free AI coding agent called OpenCode and pointed it at the financial services customer on November 16 at 4:24:57 a.m. ET.

OpenCode is an open source coding agent that lets users connect to more than 200 model providers or local models, including Anthropic’s Claude models, OpenAI’s GPTs, Google’s Gemini, DeepSeek, and Z.ai’s GLM. Jesta doesn’t know which model the attacker used, as there was nothing in the traffic that named the model. OpenCode's web fetch tool, however, did name itself, so Jesta knows the attacker used this coding agent - not a scanner - to do the dirty work.

“Nothing in OpenCode was built for hacking,” Finkelshtein said in a Tuesday report about the agent-led attack. But, he added, nothing in the coding agent “stops you from pointing it at someone else's website either. When you do, the agent goes through the site the same way it goes through code. It reads, tries something, reads the result and tries the next thing, for as long as you let it run.”

That’s what it did in this operation, which took less than six minutes and cost the human operator nothing.

The first call came from a Chrome browser on a Mac, requesting the front page of one of the financial firm’s systems. The site refused it, and six seconds later, the same IPv6 address in Bucharest, on an ordinary DIGI Romania business line, tried again. It used the same Chrome version, but said it was an Android Pixel 10 phone (it wasn’t) to see if the site would let a phone in (it didn’t).

After failing to gain access through the front page, the agent asked the system for its API definition, which was also refused. Five seconds later, it tried a different address - this one was a decoy set up by Jesta - and it answered the agent, providing the readable file defining how the API works.

The agent read the document, and 13 seconds later followed a link it contained. At 4:26:01 a.m. ET, Jesta’s defenses marked the website visitor as an AI agent, opened a case, and from here on out, everything the agent accessed was contained inside a fake environment designed to trick intruders. This included a phony key, which the attacker then used to attempt to break into the company’s systems.

“It worked like a developer,” Finkelshtein said about the coding agent. “It read the API docs and did what they said. It found a key and used it. It checked whether the lock was real, then made up a key of its own and tried that. None of the threat feeds the customer has knew the address, so a blocklist would never have stopped it. The bar for doing this is now installing an app. Think about how many people can do that.”

In addition to OpenCode, the attacker used only Chrome 157, both in desktop and mobile modes, and curl/8.7.1, a command-line tool that has shipped with every Mac since macOS 15. The agent passed information between the three tools. It included the planted key in a command-line request and then tested three scenarios – using the decoy key, no key, and a fabricated key – to determine whether what it found in the API documentation was legit.

It also tried multiple URLs using the browser. While it ultimately identified a valid endpoint, it attempted to read from one that accepts only data submissions, so its request was blocked again. Five minutes and 44 seconds after the first request, it gave up, and the logs haven’t detected any activity from this same intruder since then.

The security shop and its customer disclosed the activity to law enforcement and told us it’s “being handled.”

While the attacker wasn’t able to steal anything in this attempt, security teams still need to take note, according to Finkelshtein.

“No blocklist would have helped” detect the malicious traffic, he explained. “Most security tools still decide by asking whether an address is known to be bad, and for this one the answer was no. If that key had been real, it would have been in.”

Instead of blocklists, Finkelshtein suggests paying attention to what the visitor does. In this case, several of its actions gave it away - including following a link that only existed inside an API doc, using a desktop browser and a fake phone, then curl, all from the same address within minutes, and trying multiple keys - including one with a made up name and then no key - within seconds.

“Open source lets anyone build software without a big team,” Finkelshtein wrote in the Tuesday blog. “AI is doing the same for hacking. The skill is in the model, the model is a setting, and the person giving the instructions doesn't need to know how any of it works.” ®
