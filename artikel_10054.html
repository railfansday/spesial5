InfoQ Homepage News Qwik 2.0 RC: Replaces HTML Comment Markers for Faster Reactivity and Out-of-Order Streaming

Nov 17, 2026 2 min read

Qwik, the resumable JavaScript framework originally created at Builder.io, has released its 2.0 Release Candidate, targeting a rewrite of how the framework encodes resumable state in server-rendered HTML and introducing experimental out-of-order streaming. The RC was published on 1st October 2026 as @qwik.dev/core@2.0.0-rc.0, around two years and eight months after the initial Towards Qwik 2.0 design article.

In v1, Qwik propagated state updates by sprinkling HTML comment markers such as and throughout the rendered body to flag component boundaries and the text nodes a signal should update. That approach forced a single ordered write pass, added CPU and memory overhead, and made out-of-order streaming impossible because a slow fetch blocked everything after it.
