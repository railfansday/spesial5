Tanggal: 2026-11-10

Escape From Tarkov promo codes are used in the classic extraction shooter for all sorts of rewards. From in-game gear and weapons to currency, cosmetics, and more, redeeming as many of these Tarkov codes as you can will set you up for your next raid. Especially since these goodies don't actually require a successful extraction to obtain them.

There are two ways to redeem promo codes in Escape From Tarkov. The first is to boot up the game launcher, then click on the drop-down arrow beneath your username in the top right-hand corner. Then select activate code and type in any of the codes listed above. If successful, you'll see green text telling you the reward has been claimed.

Alternatively, you can visit the official Escape From Tarkov promo code page on the website and type in the code there. Make sure you're signed in when you do so, and if you play Tarkov through Steam, ensure your account is linked.

When redeemed, go in-game and click on the messenger tab at the bottom of the screen. You'll find your rewards for each code by selecting "get" on all the messages. If you don't have the stash space for all of it, don't fret: you can come back and retrieve the rest of the rewards later on.
