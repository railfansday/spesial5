Google lets developers add Maps to AI Studio apps for free

Tanggal: 2026-11-10

AI Studio now sets up Maps keys on its own, with 100 free calls a day per API.

A Google Maps pin badge sent to a member of Google’s Local Guides programme.

Google AI Studio can now set up Google Maps Platform for apps built by prompting Gemini, with a free demo key allowing 100 calls a day per API. Production apps still need a paid Cloud billing account, but the same key and code keep working.

Developers can now add Google Maps to apps they build in Google AI Studio without leaving it, Google said on Monday. AI Studio sets up the maps service and its key on its own, and no credit card is needed to start.

Users describe an app to Gemini, and AI Studio connects Google Maps Platform and loads a live map preview. Google’s example is a request for “an interactive 3D tour of NYC showcasing iconic landmarks.”

The free demo key allows 100 calls a day for each Maps API, resetting every 24 hours, Google’s developer blog says. Apps can use maps, place search, routes, and local data such as pollen and air quality. One sample app plans routes for a pet grooming van around fixed appointments.

There are limits. For people new to Google Cloud, the demo key covers most Maps APIs but not route optimisation, solar data or Nav Connect. Existing Cloud users get a smaller set without photos and reviews from users, Google’s documentation shows.

To launch an app, developers must add a paid billing account, which brings standard Maps pricing. The same key keeps working, so the code doesn’t change.

The free key itself isn’t new. Google launched its no-credit-card Maps Demo Key in November 2025. What’s new is that AI Studio now creates and connects it automatically.

Google has been turning AI Studio into a place where anyone can build apps by prompting. Since October, people can publish AI Studio apps to the Play Store for free, and developers can move projects to Antigravity, its agent coding tool. Apple has gone the other way, cracking down on AI-built apps.
