I Built an Open-Source Remote Console to Control Codex, Claude Code, Antigravity & Grok From My Phone

Tanggal: 2026-11-17

If you run Codex, Claude Code, Antigravity, and Grok across multiple projects (or even multiple Codex accounts), two pains hit you fast:

Existing codex-bridge scripts usually cover only one engine or require setting up Tailscale/chat bots manually. So I built Agent Control—an open-source (AGPL-3.0), self-hosted desktop & mobile remote console with a built-in 5-language UI (English, 简体中文, 繁體中文, 日本語, 한국어).

Remote-controlling local coding agents requires real trust, so Agent Control is designed around strict local boundaries:

Automatically discovers multiple local Codex accounts and displays per-account quotas side by side alongside Claude Code, Antigravity, and Grok sessions—grouped cleanly by project workspace.

Scan a QR code from your phone's browser to check live streaming output, review code diffs, approve/deny tool calls, or queue follow-up turns.

Starts with a $0 Cloudflare Quick Tunnel out of the box (QR code ready in ~5 seconds, no account needed), and lets you switch anytime to $0 Tailscale Funnel (*.ts.net), Cloudflare Named Tunnel, or a self-hosted Docker / Sealos Relay.

Includes a wake-locked VAD voice mode that announces task completions or pending approvals and lets you approve/dispatch tasks hands-free using low-latency models (Claude Sonnet, GPT, Antigravity, or Grok).
