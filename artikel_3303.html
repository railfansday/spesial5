iPadOS 27.3: Three new features coming to your iPad

Tanggal: 2026-11-22

iPadOS 27.3 is now in beta and will launch to all users next month, here are three new features it introduces for iPad.

There’s a new setting in iPadOS 27.3 that I instantly turned on and have been loving. It lets you double-tap the top of a window to resize it.

Inside Settings ⇾ Multitasking & Gestures, if ‘Windowed Apps’ is enabled there’s now a new toggle: ‘Double-tap Top of Window to Zoom.’

I’ve been using this gesture all the time in the beta, because it lets me resize my window to fullscreen then revert it to its previous size with ease. It’s an intuitive, convenient way to resize windows for different tasks.

Visual intelligence was available on iPad already, but iPadOS 27.3 adds a dedicated hub for using the feature: a new Siri mode in the Camera app.

iOS 27 brought Siri mode to the iPhone’s Camera app, but it was missing from iPad. iPadOS 27.3 corrects that oversight, letting you use your iPad’s built-in Camera app to ask Siri about any object you capture.

Baking visual intelligence into Camera should expose the feature to a lot more iPad users, since before you had to set up a custom control or shortcut for it. And with how much better visual intelligence has gotten thanks to Siri AI, the Siri mode is a valuable addition.

Freeform is gaining a variety of new features in iPadOS 27.3. They’re available in macOS and iOS too, but out of all Apple platforms, Freeform feels very much built for the iPad.
