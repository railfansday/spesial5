Agents may soon be the main workload, and most of the time they’re doing nothing

Tanggal: 2026-11-12

As AI agents take on more enterprise work, agent sandboxing has become a basic requirement rather than an afterthought. Every agent that writes code, runs tools or drives a browser needs hard walls around it. Those walls also can’t come at the cost of runaway compute bills.

Google LLC’s answer is Agent Substrate, an open-source project built on Kubernetes that the company donated to the Cloud Native Computing Foundation alongside its gVisor sandbox. Customers have raised the same problem for the past 18 months: They need to run agentic workloads securely and efficiently on the infrastructure they already have, according to Brandon Royal (pictured, left), product manager, AI agents and infrastructure, at Google Cloud.

“Any agent needs to be fully isolated,” Royal said. “Whether it’s accessing tools or using a computer or a browser, there needs to be some level of isolation, period, full stop.”

Royal and Benjamin Elder (right), staff software engineer at Google, spoke with theCUBE Research’s John Furrier and Rebecca Knight at KubeCon + CloudNativeCon NA, during an exclusive broadcast on theCUBE, SiliconANGLE Media’s livestreaming studio. They discussed how agent sandboxing is central to Google’s open-source Agent Substrate. (* Disclosure below.)

Agent Substrate starts with hardened sandbox runtimes densely packed on Kubernetes clusters. All traffic passes through a layer that applies policy and understands identity, so an agent can reach nothing it hasn’t been explicitly granted, Elder explained. The project also keeps secrets out of the agent’s hands by injecting credentials on the wire.

“Don’t expose credentials to the sandbox,” Elder said. “Don’t let the agent touch the credentials. Instead, when it requests to do something, you can make a decision about outside the sandbox.”

Security is only half the equation. Agents in a swarm spend much of their time blocked, waiting on a large language model call or on a human to follow up. Agent Substrate snapshots those idle agents out of memory and CPU, stores them offline and restores them when they’re needed, freeing resources across the cluster, according to Elder.

“Should you be holding compute while you’re getting coffee? Because you might come back in five minutes. You might come back in five hours or five days,” Royal said. “We don’t know.”

Google is already building on the project. Gemini Managed Agents now runs on Agent Substrate and gets the same density, efficiency and security guarantees, Royal noted. Google Cloud also recently introduced Agent Compute Engine to host AI agents.

“Agents are going to become the predominant workload in the future,” Royal said. “Maybe it’s six months, maybe it’s 12 months, but we see this as a really big area of growth.”
