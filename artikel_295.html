X implements parental controls for teen users

Tanggal: 2026-11-27

Elon Musk's social network X just got a new feature it never had under previous ownership.

That would be parental controls for teen users, to be exact. In a new post from the official Safety account on X, the company announced it has implemented parental controls for users aged 13 to 17. The way it works is that an account run by a parent or guardian establishes a supervisory link to the account run by a teen, which gives the parent or guardian access to a bunch of monitoring and safety features the site didn't have before.

These features include the ability to monitor usage and set daily limits for the teen, as well as the option to require new followers to be approved by the parent or guardian. Recommendations on the For You feed can be limited to accounts the teen already follows, while parents can mute specific words, control who can send direct messages, and see who the teens have chatted with in DMs without seeing the messages themselves.

As X noted, this only starts when both parties in the equation consent to it, so a teen cannot have their account limited against their will. Theoretically, anyway. A parent account can supervise as many as five teen accounts, but a teen account can only be linked to one parent account.

This is interesting because it's an acknowledgment by X that some teenagers do use the platform, but even in the Safety account's post, the company is clear that X is "not designed for or promoted to children." Indeed, one could argue that teen users should stay far away from a service that has become home to hate speech, widespread misinformation, and a Grok AI chatbot that has gotten up to plenty of unsavory business since it was introduced.

But if teens are going to use X, at least these features exist now.
