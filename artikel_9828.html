Get every new Xing job, with salaries, into a spreadsheet every morning

Tanggal: 2026-11-06

If you work with the German, Austrian or Swiss job market, whether in recruiting, HR tech, labour-market research or a job board, you have probably wanted Xing's job ads as data instead of web pages. Xing is the leading professional network in the DACH region, with around half a million active job postings at any time and thousands of new ones every day.

In this post I show how to get them as clean JSON, CSV or Excel. That includes salary ranges, remote/hybrid information and career level, and a daily feed that only returns the jobs published since yesterday. You don't need to write a scraper: we'll use a ready-made one on Apify, called from Python.

Salaries are the interesting part. Many employers don't publish one, so Xing shows its own estimate instead. The data keeps them apart with salaryIsEstimate, so you can choose whether to trust estimates.

Create a free Apify account and copy your API token from Settings → API & Integrations. The free plan includes monthly credits, and the scraper costs $1 per 1,000 jobs, so testing is basically free.

Every keyword is searched in every city you list, and a single search can return more than 1,000 jobs.

The filters run inside the scraper, so jobs that don't match are skipped and not charged. For example, English-language remote or hybrid jobs that pay at least €60k:

If you're an English speaker looking for a job in Germany, that one query already saves you an evening of scrolling.

This is the mode I use the most. Instead of searching, feed mode reads Xing's public sitemaps, which list every active job, and onlyNewJobs remembers what you already received. Schedule it once a day and each run returns only the jobs published since the previous one:

The examples repo has a complete script that appends the new jobs to a CSV, ready for cron or Windows Task Scheduler. You can also skip code entirely: create a schedule in the Apify Console and connect the results to Google Sheets, Make or n8n.

The scraper only uses pages that Xing's robots.txt allows for all crawlers. It collects job ads, not people's profiles, and it removes e-mail addresses and phone numbers from descriptions by default, so you don't end up storing recruiters' personal data. If you're in the EU, that matters for GDPR.

I built this scraper, so feedback is very welcome, especially on which fields or filters would make it more useful for you.
