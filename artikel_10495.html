One UI 9.5 Beta is out now for these Galaxy devices – how to install it

Tanggal: 2026-11-24

Samsung’s beta train has officially left the station, so to speak. One UI 9.5 is starting to roll out to these devices, and with it, some major changes to its Galaxy phones.

There are a couple of reasons the One UI 9.5 beta packs a substantial punch on your Galaxy S26. For one, it’s a halfway mark between Android versions where more useful features can be implemented. Samsung started this trend of releasing the next half-step up in One UI versions with its standard flagships. That’s why, when the Galaxy S27 becomes official, it will launch with One UI 9.5 preloaded.

Samsung details some of the key changes we’ll see in the One UI 9.5 beta, like a new journaling app and better video/camera controls.

It might be because the Galaxy S27 is the first device slated for the stable One UI 9.5 launch, but the Galaxy S26, Galaxy S26 Plus, and Galaxy S26 Ultra are the only devices that can access the beta update. The list doesn’t include the Galaxy Z Fold 8 or Fold 8 Ultra, even though they’ve become some of the best devices Samsung has to offer.

Samsung also puts limitations on regions, noting the program will only be open in Germany, India, Korea, Poland, the UK, and the US. Users on other devices outside of those regions won’t be able to download the beta.

That isn’t to say they’re locked out forever. Samsung will very likely expand the beta program before the Galaxy S27 launch, meaning more devices will get access and in wider areas.

On your Galaxy S26, S26 Plus, or S26 Ultra, you’ll need to sign up for the One UI beta program once more. This is an entirely new beta program, and it doesn’t look like participants carry over from the One UI 9 beta.

Once you finish that process, you should be all set with One UI 9.5 beta.

Once again, since it’s early access, you shouldn’t expect things to be perfect. If you find the experience is awful, you can always revert back.

Samsung published the full changelog alongside its OTA update, as outlined below.

Sports animations in Now barAnimation effects are now available for more sports. Celebrate your favorite team’s goals and victories with special visual effects. You can download these effects in Now bar settings.

Fingerprint and face recognition at the same time

Intuitive floating accessibility shortcuts

Audio brief and Moments no longer available

One UI 9.5 beta is available now for the Galaxy S26 series.
