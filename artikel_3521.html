How to hide the new macOS 27.3 menu bar indicator

Tanggal: 2026-11-21

macOS 27.3 beta 2 adds a blue menu bar indicator for apps using System & App Protection Override. Apple describes itas a transparency indicator that appears when one app is controlling another.

If you regularly use trusted automation tools and utilities, that can mean a persistent pill taking up space in your menu bar. Prefer to hide it? There’s a Terminal workaround.

I’ve tested this on macOS 27.3 beta 2 and confirmed that the indicator disappears after a restart.

Open Terminal and run these two commands:

sudo mkdir -p /Library/Preferences/FeatureFlags/Domainsudo defaults write /Library/Preferences/FeatureFlags/Domain/TCC AX_TRANSPARENCY_INDICATOR -dict Enabled -bool false

Enter your Mac administrator password when prompted, then restart your Mac.

The command disables the internal AX_TRANSPARENCY_INDICATOR feature flag. It doesn’t remove apps from your permissions list, although you’ll no longer see this activity indicator.

To restore Apple’s default behavior, run:

sudo defaults delete /Library/Preferences/FeatureFlags/Domain/TCC AX_TRANSPARENCY_INDICATOR

Restart your Mac again to apply the reversal. This removes only the indicator override, preserving any other flags you may have configured.

This is an undocumented workaround tested on the current beta, so Apple could change or remove it in a future update.
