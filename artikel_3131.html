Apple releases HomeView 27.2.1 update, here’s what’s new

Tanggal: 2026-11-19

Apple has just released its first post-launch software update for the HomeView, version 27.2.1 which includes several bug fixes. Here’s how to install it.

Last week the Apple HomeView arrived in users’ homes and immediately required a software update to version 27.2.

But now, Apple has already released its first post-launch update.

HomeView software 27.2.1 is now available for all users.

You can install the update by opening the Home app on your iPhone then tapping the three dots in the top-right corner, opening Home Settings, and going to the ‘Software Update’ section.

Apple has not yet published release notes for the update, so it’s unclear what changes it introduces.

It’s possible HomeView 27.2.1 will address some of the Siri AI issues that users have been encountering and sharing online, or other bugs. It likely also includes security updates that first shipped in iOS 27.2.1 and related builds.

We’ll report back when we have more information.
