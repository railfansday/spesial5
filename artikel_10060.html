If you are going to use someone else's content commercially, you should pay them for it. The only question should be: how much is it worth?

There is the argument that if you put it on the internet (not behind a paywall/login/etc.) then you are granting an implied license to anyone read it (you set world:read permissions on the file on your web server), but it is reasonable to require Google to pay for commercial use.

The old argument still holds that Google are exchanging value in-kind with sites by providing search indexing and directing traffic to the site, but if the AI summary uses the content, Google are providing less value than they used to do. They should pay for this difference.

It is not practical for individual sites to negotiate rates for the use of content they provide, and the balance of power would be too one-sided. It therefore falls to government to set a standardized rate for (AI) commercial use of freely provided publicly accessible information, with individual sites able to negotiate separate contracts for non-public content (things that are behind paywalls, or logins) via API, etc.

Current laws do not provide a proper framework for this, but that is something that can be fixed. The status-quo has changed, and should be rebalanced.
