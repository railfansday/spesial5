October in Servo: video captions and inert content

Tanggal: 2026-11-26

Plus WebAudio nodes, image inputs, and more!

Servo 0.8.0 contains all of the changes we landed in October, spanning 588 commits (a new record)!

We’re interested to hear how well your favourite websites run in Servo! Report successes in this Zulip thread or this Github discussion, and failures in our GitHub issues.

With respect to accessibility in Servo, we report many more ARIA roles for DOM elements (@alice, @mrobinson, #48839). These can be inspected with the Get Computed Role WebDriver command (@lolaodelola, #47339). Accessibility integration can be turned on with the accessibility_enabled preference.

WebGL2 support received lots of attention this month, with fixes to getParameter(), drawBuffers(), readBuffers(), vertexAttribIPointer(), DEPTH_STENCIL_ATTACHMENT, getUniformLocation(), vertexAttrib4x(), pixelStorei(), texStorage2D(), texStorage3D(), texImage3D(), getInternalformatParameter(), blitFramebuffer(), and texSubImage2D() (@mxmgorin, #48651, #48620, #48678, #48689, #48751, #48681, #48911, #48972, #48590, #49201, #49289, #48560, #48571). The feature remains gated behind the dom_webgl2_enabled preference.

Reading and writing mapped WebGPU buffers got a significant speed increase (@sagudev, @jdm, #48372). WebGPU can be enabled with the dom_webgpu_enabled preference.

JS script compilation can now occur off the main thread when the dom_script_asynch preference is enabled (@Gae24, #45687). Right now this only applies to non-module scripts.

Initial support for the backdrop-filter property has merged (@shubhamg13, #48829). This can be enabled with the layout_css_backdrop_filter_enabled preference.

ServiceWorkers now fire the statechange event when changing states during initialization (@gterzian, #48749). ServiceWorkerContainer can listen for message and messageerror events (@gterzian, #48680). Service Workers remain gated behind the dom_serviceworker_enabled preference.

The Geolocation API has been implemented (@webbeef, #48406). No platform-specific backends to provide the device geolocation data have merged yet, so it remains disabled behind the dom_geolocation_enabled preference.

DOM interfaces for MathML elements now exist, gated behind the mathml_core_enabled preference (@tannal, #48631). There is no MathML-specific layout implemented yet.

A new, native SVG implementation is in progress (@mu-mostafa98, @jdm, #48467). This work is still in the early stages, but is intended to replace Servo’s dependency on the resvg crate to better integrate with page styling and animations.

IndexedDB cursors now support the update() and delete() methods (@kuntal-devrat, #48402). The feature can be enabled with the dom_indexeddb_enabled preference.

Support for LargestContentfulPaint performance timing improved, with image URLs (@shubhamg13, #48668), the loadTime value (@shubhamg13, #48676), ignoring non-paintable elements (@shubhamg13, #48856, #48898), video URLs (@shubhamg13, #48931), and following containing blocks (@shubhamg13, #48551). This work is behind the largest_contentful_paint_enabled preference.

We added support for a new performance timing metric: ContainerTiming (@jasonwilliams, #46966). This can be enabled with the container_timing_enabled preference.

Our support for adoptedStylesheets improved along with a new implementation of the ObservableArray specification concept (@jerensl, @arihant2math, #48506). This is currently hidden behind the dom_adoptedstylesheet_enabled preference.

The Android Compose migration is complete, and embedders now only need to interact with the Servo library component (@veyndan, #48592, #48601, #48595, #48574, #48609, #48778, #48780, #49266). Embedders no longer need to trigger the soft keyboard display; this is controlled by a parameter to the Servo component (@veyndan, #48757).

There’s a new API method to report the network status of the embedder: NetworkManager::set_online_state (@xbwwj, #47568). This data is exposed via the onLine property of the Navigator interface in web content.

Embedders can now disable all support for developer tools, which can reduce the size of the final binary (@janeoa, #47255). This is controlled by the devtools feature and enabled by default; it is also part of the new default_tooling feature.

Users of the C API can set preferences that accept f64 and f64 array parameters (@fran6co, #49325), as well as the HiDPI scale factor for each WebView (@fran6co, #49327). WebViews can also be resized via the C API (@fran6co, #49326).

Double and triple clicking on selected text will extend the selection to the current word and line, respectively (@mrobinson, @SimonSapin, #48767).

Clicking a link with the middle mouse button now opens up the link in a new WebView (@SteveSharonSam, @mrobinson, #46000)

Range inputs can be dragged with the mouse (@webbeef, #48342).

Command+delete on macOS will delete the preceding line in a text control (@dzfrias, #48781).

We improved exception error messages related to the XMLHttpRequest, History, Range, Selection, Element, CharacterData, and DOMTokenList interfaces, and namespaces and attributes (@gabrielecabrini, #49146, #49145, #48786, #49102).

Media elements that start playing outside of a document will no longer be garbage collected until playback finishes (@sabbCodes, @jdm, #49367, #48979).

Pinch zoom operations no longer have to rebuild a full display list, making zooming complex pages much smoother (@stevennovaryo, @mrobinson, #43561).

We improved performance in many small and focused ways by doing less work during restyling and layout (@SimonSapin, @webbeef, @nicoburns, @mrobinson, #49137, #49100, #48485, #48968), reducing GC interactions (@mrobinson, @jschwe, #48984, #49140, #49195, #49425), and delaying work on disconnected trees (@SimonSapin, #49098). We also fixed instances of quadratic layout with deep nesting (@nicoburns, #49148) and missing caching (@mrobinson, @Loirooriol, #49164, #49073).

We fixed some intermittent GC panics when notifying ResizeObservers (@mrobinson, #49189), introspecting keyframes (@MohamedAli00949, #48546), setting timers (@jdm, #48548), using writable streams (@jdm, #48656), and scrolling iframes after removing them (@mrobinson, #49230).

We also fixed numerous other panics and crashes in scrollable and incremental layout (@mrobinson, #49230, #49283), moving nodes around (@mrobinson, #49226), using WebGPU from opaque origins (@gabrielecabrini, #49207), stringifying some WebIDL types (@mrobinson, #49374), using readable streams (@Narfinger, @mrobinson, #49311), clicking disabled file controls (@mrobinson, #49379), rendering giant SVGs (@sabbCodes, #49264), unminifying JS (@jdm, #48567), measuring text (@mxmgorin, #48621), rendering text tracks (@TimvdLippe, @mrobinson, #48827), preparing dialogs (@lukewarlow, #49431), and running delayed tasks in destroyed documents (@mrobinson, @jdm, #49399, #48714).

Many small-to-medium improvements to reduce allocations were merged (@yezhizhen, @Narfinger, @Taym95, @mrobinson, @Loirooriol, @CynthiaOketch, @sabbCodes, @mxmgorin, #48549, #48558, #48568, #48598, #48615, #48565, #48646, #48654, #48569, #48562, #48588, #48650, #48702, #48675, #48589, #48720, #48721, #47720, #48745, #48703, #48750, #48770, #48789, #48754, #48828, #48838, #48836, #48841, #48843, #48867, #48882, #48842, #48881, #48840, #48899, #48924, #48904, #48949, #48953, #48980, #49028, #48885, #49035, #49038, #49084, #49131, #49125, #48951, #49154, #49160, #49198, #49202, #49194, #49219, #49258, #49275, #49295, #49298, #49300, #49320, #49323, #49313, #49373, #49380, #48969, #48991). We also reduced memory usage by shrinking some types (@Narfinger, @webbeef, #48954, #48082, #48906).

Memory leaks received a lot of attention this month, covering everything from network requests, to JS modules, to timer tasks, and more (@mrobinson, @SimonSapin, @jschwe, #48952, #48957, #49032, #49049, #49092, #49134, #49139, #49132, #48747, #48752).

We continue to work towards preventing certain sources of memory leaks with static analysis and the Rust type system (@Gae24, @Narfinger, @jdm, #48147, #48360, #48832, #48887, #48913, #48903, #48965, #48905, #48834, #48855, #49083, #49082, #49081, #49096, #49135, #49130).

We fixed bugs related to the CORS preflight cache (@sabbCodes, #49055, #49252), fetch metadata (@TimvdLippe, @mrobinson, #48793), HTTP cache revalidation (@mrobinson, @jdm, #48927), image load timing (@mrobinson, @TimvdLippe, #48902, #48790, #48599), touch events (@yezhizhen, #48671, #48699, #48701), cloning and moving input elements (@skyz1, @mrobinson, #48845, #48069), the :indeterminate pseudoclass (@skyz1, #48070), stylesheet introspection (@mrobinson, #48935), mutating ranges (@gabrielecabrini, #49072), blob URLs (@rogerkorantenng, #49074, #48989, #49206), form controls (@mrobinson, @lukewarlow, @jdm, #49163, #49225, #48513), the mapping property of Gamepad (@msub2, #49381), beforeinput events (@dzfrias, #48825), image dimensions (@TimvdLippe, #49085), table appearance attributes (@Loirooriol, #49120, #49108, #49156, #49150), IME events (@dzfrias, #48690), reconnecting IntersectionObserver (@shubhamg13, #48581), and root elements (@TimvdLippe, #48514).

We also addressed layout issues related to soft wrap line breaks (@mrobinson, @Loirooriol, #48564), grid and flex layouts with indefinite dimensions (@RichardTjokroutomo, @rayguo17, @nicoburns, #48670, #48644, #49232), hanging whitespace (@mrobinson, @Loirooriol, #48591, #48753), preserve-3d (@mrobinson, #47933), inline block splits (@Loirooriol, #46445), video controls (@rayguo17, #44956), display: contents (@Loirooriol, #48784, #48785), justify-contents (@yezhizhen, #48746, #48988), absolute positioning (@mrobinson, @Loirooriol, #48846), (@Loirooriol, #49143), text-transform: capitalize (@jschwe, #48901), incremental table layout (@Loirooriol, #49176), width: stretch (@Loirooriol, #49239, #49237), backface visibility (@mrobinson, #49196), flex gaps (@yezhizhen, #49335), perspective (@mrobinson, #49174), quirks mode (@Loirooriol, #48942, #39869, #48978, #49211), SVG viewboxes (@leowatts, #48556), ISO-8859-8 documents (@TTyChud, #48444), and table borders (@adoublebarrel, @mrobinson, #47684).
