131 Agent Skills That Plan, Debug and Review Code Like a Staff Engineer

Tanggal: 2026-11-19

One command now gives a coding agent 131 open-licensed engineering skills from Tech Leads Club, Matt Pocock, Cloudflare, Thomas Ricouard, Jesse Vincent and Anthropic. They cover planning, debugging, code review, architecture, refactors and deploys, and they're packaged as the Dev Workflow plugin in Cuttlefish.MD, HackerNoon's license-checked skills marketplace.

An agent skill is a folder with a SKILL.md file of instructions, plus any scripts or references it needs. The agent loads it only when a task calls for it. The format is an open standard at agentskills.io that 32+ tools support, including Claude Code and Codex CLI.

Every skill below comes from HackerNoon's SKILL.md Library, is MIT- or Apache-licensed and links to its source. They're grouped by author so you can see whose habits you're installing.
