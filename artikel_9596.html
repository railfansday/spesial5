Splitting Network Paths with Two NICs to Get CUDA Working on RTX 5060 under WSL2 on Windows 11

Tanggal: 2026-11-08

While setting up CUDA for an RTX 5060 GPU on Windows 11 + WSL2, I ran into a somewhat unusual situation:

With WSL2's default networking (NAT mode), WSL just borrows whatever single route Windows itself is using, so there's no clean way to keep "business traffic" and "lab traffic" on two separate physical paths.
