So, can any of you plainly explain (in clear actionable terms) what this means for those of us (who maybe no longer have the patience to read thru long threads) what these means, and what practical action steps, we may need to take?
Sure. Vanguard has rolled out passkeys, that enable an authentication protocol that is resistant to phishing and some other attacks. Passkeys may be deployed to a password safe, or to a hardware security device (security key) that typically resembles a thumbdrive. Authentication does not use a password when a passkey is used.

Vanguard has been supporting a different protocol with hardware security keys that involved a password step, and then a hardware key step. It also is a good method, but Vanguard seems to be moving away from it with the new development.

There are other details, but that is the gist of it.

If you want to use the new method, you would purchase a minimum of two Yubikeys, to have backup in case one fails. You then would log in to Vanguard, and create a passkey for each hardware key. Once the login is verified using all of the keys, you apparently can disable password credentials with a new credential lock feature that Vanguard has implemented. (I’ve not used the credential lock feature, as I’m currently still using the earlier, two step method.

If you do not wish to purchase hardware keys, you instead can store the passkeys in a password safe.
