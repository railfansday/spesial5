You cannot actually really proof 2+2 = 4. Or rather it is just a very syntactic expansion of the definition of "2" and "4".

Since somebody will doubtlessly ask: Basics is "0" and "+ 1" operation. Hence "2" = 0 + 1 + 1, 4 = 0 + 1 + 1 + 1 + 1. And hence "2" + "2" = (0 + 1 + 1) + (0 + 1 + 1). This is the same as 0 + 1 + 1 + 0 + 1 + 1 and that is the same as 0 + 0 + 1 + 1 + 1 + 1, by commutativity. As (0 + 0) is 0, that is 0 + 1 + 1 + 1 + 1 and that is the expanded form of "4". QED.
