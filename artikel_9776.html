Excelize is a library written in pure Go providing a set of functions that allow you to write to and read from XLAM / XLSM / XLSX / XLTM / XLTX files. It supports reading and writing spreadsheet documents generated by Microsoft Excel™ 2007 and later. It also supports complex components by high compatibility, and provides streaming API for generating or reading data from a worksheet with huge amounts of data.
