Ask a general-purpose coding agent to "analyze this CSV" and you'll usually get pandas boilerplate, a default bar chart and a confident summary that skipped the part where you check your assumptions. The model knows statistics. What it lacks is a working analyst's habits: which library fits a 40 GB file, when a t-test is the wrong test, why the chart needs a colorblind-safe palette, and how to tell stakeholders what the numbers mean.

Agent skills supply those habits. An agent skill is a folder with a SKILL.md file of instructions, plus any scripts or references it needs, which your agent loads only when a task calls for it. The format is an open standard at agentskills.io that Claude Code, Codex CLI, Cursor and Gemini CLI all read.

These 45 skills cover the full analysis loop: load the data, query it, model it, chart it and explain it. They come from Daniel Avila's Claude Code Templates (which bundles a large set of scientific Python skills), Seth Hobson's agents collection, Supabase, Corey Haines and Pramod Dutta's QASkills. Every one is MIT or Apache 2.0 licensed and packaged in Cuttlefish.MD, HackerNoon's license-checked library of SKILL.md files.

A note on scope: the library's Data & Science plugin also holds more than 550 bioinformatics skills from GPTomics. We covered those separately in our lists on single-cell RNA-seq, CRISPR screens, chemoinformatics and whole bioinformatics pipelines. This list is for everyone else: analysts, data engineers, product teams and founders staring at a spreadsheet.

(The skills are spread across several category plugins, which is why the list is longer than you might expect.) For Codex, Cursor and other tools, clone the repo and copy the folders you want into your agent's skills directory.
