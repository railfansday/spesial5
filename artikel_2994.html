Whittaker noted Signal’s screenshot restriction isn’t perfect, saying that AI agents can still access app data through other means, “such as retrieving content already present on a user’s device via the filesystem.” Earlier this week, a Reuters investigation supported by Signal and the AI Now Institute found that Meta’s Muse AI agent was using permissions from its initial setup in unexpected ways to access apps and data that a user had not explicitly connected it to.
