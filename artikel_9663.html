There are thousands of agent skills on GitHub, and most developers find them the same way: a tweet, a star count and a leap of faith. You can't tell what a skill does without reading its SKILL.md, you often can't tell whether its license lets you reuse it, and a skill you didn't read is someone else's instructions running with your agent's permissions.

Project Cuttlefish.MD is HackerNoon's answer. It's a library of 2,908 SKILL.md files you can read in full on hackernoon.com, each credited to its author, with the license checked one repo at a time. The companion GitHub repo, hackernoon/cuttlefish-agent-skills, packages the 2,806 skills whose licenses allow redistribution into nine category plugins you can install with one command.

This guide covers how to install it in Claude Code, Codex CLI, Cursor and Gemini CLI, what's in each plugin, how the licensing works, and 21 skills worth trying first.

A cuttlefish studies its surroundings and changes its color and texture to match. A good SKILL.md does the same thing for an agent: it adapts a general-purpose model to one habitat, whether that's your codebase, your blog or your data warehouse. Cuttlefish.MD is meant to let you and your agent borrow that adaptation from any ocean.

An agent skill is a folder containing a SKILL.md file (a name, a one-line description and instructions) plus any scripts, templates or reference files it needs. The agent reads only the names and descriptions up front. When a task matches a description, it loads the full instructions. That's why you can install hundreds of skills without filling the context window: unused skills cost a line each.

The format is an open standard at agentskills.io, so the same folder works across agents. For the craft of writing one, HackerNoon has published How to Write an Agent Skill, The Right Way to Write an Agent Skill and Read This Before You Write Another Agent Skill.

The first skill written by HackerNoon is pixel-icon-library, which installs and uses HackerNoon's open-source Pixel Icon Library, the pixel-art icon set on a 24px grid that HackerNoon itself is drawn with, available as an icon font, React component or raw SVG.

Two more are in progress: write-for-hackernoon, which drafts, self-edits and submits against the HackerNoon Editing Protocol, and tech-blogging, with headline and structure patterns drawn from more than 150,000 HackerNoon stories.

Will installing a whole plugin slow my agent down? Not meaningfully. Agents load only each skill's name and description until a task matches, so an unused skill costs about a line of context. Installing a few targeted plugins is still tidier than installing all nine.

Are these skills safe? Each one is republished unchanged from its source commit, with attribution, so you can compare it with the original. Licensing is checked, but a license isn't a security review. Read a skill before you rely on it, and consider running Sentry's skill-scanner first.

Can I suggest a skill or a source repo? More source repos are being added. Watch or star the repo to follow along, and email support@hackernoon.com with suggestions.
