Anthropic lets companies run Claude’s agent service on their own servers

Tanggal: 2026-11-12

Agent data and credentials can stay in-house, but conversations still go to a model provider.

Anthropic now lets companies run Claude Managed Agents in their own cloud or data centre. Agent histories and credentials stay on their systems, but each model call still goes to an outside provider such as Anthropic or AWS.

Anthropic now lets companies run its Claude Managed Agents service on their own servers, Help Net Security reported. The self-hosted version launched on Thursday, and customers must request access through their Anthropic account team, the company said in its release notes.

Managed Agents is Anthropic’s service for running AI agents that use tools and remember past sessions. Customers could already run the agents’ tools on their own machines, but Anthropic ran the rest, including the stored history and credentials.

Now customers can run the whole service in their own cloud account or data centre. Agents, session histories and credentials stay on their systems, and every tool call can be logged.

There is a catch. Each time the agent asks Claude a question, the conversation still goes to a model provider, such as Anthropic, Amazon Bedrock, Google Cloud or Microsoft Foundry. Customers choose which one, but Claude itself does not run inside their network.

Customers also take on the work Anthropic used to do, such as securing and updating the server. Nothing moves over from Anthropic’s hosted service, so agents and saved data must be rebuilt, and some features, such as webhooks and scheduled runs, are missing.

The move gives cautious companies more control over where agent data lives. That matters in Europe, where ECB president Christine Lagarde has warned of the risk of relying on foreign AI. Rivals such as Mistral have long pitched sovereign AI as the answer.

OpenAI took a different route in September, letting companies run its agents inside Amazon’s cloud. Nvidia, meanwhile, has built hardware for safer agents.
