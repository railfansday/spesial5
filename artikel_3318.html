A developer of hacking tools is advertising a $ 1,000-per-month feature that allegedly lets bad actors have continuous access to vulnerable Gmail inboxes. The report from the cybersecurity firm Hudson Rock claims the tool can keep accessing victims' Gmail inboxes even after password changes, browser closure and session revocations.

If this is true, it means that hackers could get access to password reset links, verification codes and therefore access to other accounts.

The malware, called Remus Stealer, supposedly gives bad actors a searchable inbox directly inside a stolen dashboard.

Hudson Rock says it spoke with the developer and a customer, who used the tool and provided them with screenshots of email messages, timestamps and control for sharing an impacted mailbox with other operators.

It somehow avoids Google's anti-fraud checks, though the developer didn't give Hudson Rock any technical details, for obvious reasons. Remus did say that it interacts with browser memory. This doesn't explain how it survives password changes or session revocation though.

“The leading broad explanation is that Remus acquires or establishes reusable authorization while it has access to a signed-in browser. A remote component could then request mail after the local executable exits, for as long as the service accepts that authorization,” Hudson Rock wrote in its report.
