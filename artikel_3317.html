Nintendo Switch games running natively on Apple TV using Claude Code port

Tanggal: 2026-11-08

A Redditor has just released an open-source project allowing Switch and Switch 2 games to run natively on Apple TV.

So far, both Super Mario Odyssey and Animal Crossing: New Horizons are running, with work ongoing on The Legend of Zelda: Tears of the Kingdom …

We’ve seen people using Claude Code to do some pretty wild things, like reverse engineering Adobe’s pro apps in order to create open-source versions of them. The latest example is a Redditor who’s created an open-source project called TVport to recompile Nintendo games from the Switch and Switch 2 to Apple TV.

Redditor FloatingFalafel shared the work on GitHub. They’ve so far ported three games to Apple TV, with one of them still a work in progress.

I have been working on a fork of nxnative that recompiles your OG Switch and Switch 2 dumps for AppleTV. Currently, this only works on a game-by-game basis. Most games run essentially the same on the switch, but some load textures into memory differently and need to be diagnosed and fixed before the game will run properly. My hope is to find outliers during this beta so more fixes can be added into the program, making it a seamless experience […]

Super Mario Odyssey – Runs at 60FPS, very slight stutters on occasion, and some audio issues around waterfalls specifically.

Animal Crossing: Horizon – Runs at 30FPS, zero issues so far on my plays.

Zelda: TOTK – Still being worked on, runs at 30FPS, gets thermal throttled. I have a work around for the thermal throttle. I have a render scale selection set at 75% and I am working on adding MetalFX upscaling.

They note you’ll need the 4th-gen Apple TV with its 8GB RAM in order to support some games, though these ones run on the 3rd-gen box.

Another Redditor is working on porting Nintendo 64 games to Apple TV using an app called Nativecade. How long any of these types of projects will survive is anyone’s guess.
