There are currently a few Clover Adventure codes available, which all provide one or more types of free Spins while occasionally throwing in some Gems currency too. Bloodline and Clan Spins can be used for rerolls through the Bloodline menu option, while Grimoire Spins for a fresh grimoire are activated at any Grand Library.

To redeem Clover Adventure codes, you need to hit the Menu button on the left of the screen to bring up a further set of options, and then tap the Settings icon. You'll see a CODES section on the next menu screen, so use the CODE text box to enter a promo then press REDEEM to collect the rewards.

You must join the AQ Verse group before you can redeem codes, however if you haven't done this already then a pop up will appear when you first try to redeem a promo so you can quickly join directly from the game. Codes for Clover Adventure are not case-sensitive, so you just need to use the correct spelling.
