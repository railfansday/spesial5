Stand Out codes will provide you with some helpful items to get ahead, as you set off on a mission inspired by JoJo's Bizarre Adventure. You'll need to explore a massive open world in this action RPG, while fighting off enemies in anime-style battles with the Stands you summon.Using the promos released so far you can claim various different types of Arrows, which are used to unlock new Stands for combat as well as some Dalas currency to spend in this funky Roblox experience. At the moment there are a reasonable number of Stand Out codes, and all of these currently provide different types of Arrows that are key in summoning new Stands to help you out. Several of them also provide Dalas, the in-game currency, so you can put them towards new purchases.

To redeem Stand Out codes, you need to complete the initial tutorial that leads you to Iko Iko where you collect your phone. Once you've received that, open the phone menu then hit the green G icon to access the GIFTS menu screen. From there, use the Enter code text box to type in a promo and then hit REDEEM to unlock your rewards, which you'll then need to manually claim from the list below.

You must join the Studio Umbra: Europa community group before you can redeem codes, so if you haven't already done that then you'll need to back out to the main Roblox menu and connect with the group there. Codes for Stand Out aren't case-sensitive, so use the correct spelling and you're golden.

There are already a few expired Stand Out codes, and this list will continue to expand as more promos head this way, so get any active codes claimed as soon as you can.
