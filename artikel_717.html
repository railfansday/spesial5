Apples new iOS 27.2.1 fixes critical bugs, and you should install it now

Tanggal: 2026-11-12

Apple's new iOS 27.2.1, released on Monday, doesn't bring any new features, but that doesn't mean you should sleep on it.

In fact, you should install it right away, as it includes patches for numerous bugs, including some critical software vulnerabilities.

Apple's official release notes for this release (alongside iPadOS, which was also updated to version 27.2.1) highlight nine separate bugs, including one in which an app could be used to access sensitive user data, one in which an attacker could pair with a user's device without user interaction, and one in which a remote attacker could be able to join an iMessage group chat and receive its messages.

One particularly nasty bug was highlighted on Tuesday by cryptocurrency exchange Binance, which infamously had a massive security breach in late October.

"A vulnerability (worse_query) affecting iOS 26.7.1, 27.0.1, and 27.2 allows malicious apps to read local files from other apps, putting seed phrases, private keys, and login credentials at risk across the entire ecosystem. This is an iOS-level issue, not unique to Binance," wrote Binance in a tweet, urging users to delete apps installed from untrusted sources, and to update iOS and all apps to the latest official versions.

Apple's iOS 27.2.1 is available to iOS users through Settings -> General -> Software Update. Users who haven't switched to iOS 27 should install the latest version of their OS; namely, iOS 26.7.3 or iOS 18.7.12.
