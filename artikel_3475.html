GTA 6’s First Patch Is Rolling Out, Here’s What It Does

Tanggal: 2026-11-24

Grand Theft Auto 6 has gotten off to a relatively smooth start, which is rare for an open-world game of this scale. It looks like the first GTA 6 patch is also rolling out, and fortunately, it won’t be a mammoth download compared to grabbing the 211 GB game--internet service providers are probably breathing a sigh of relief right now.

The update will be necessary to continue playing the game, and it’s suspected that the PS5 version will be rolling out in stages due to the sheer number of people who own the game on that platform, over 33million, according to market estimates from last week.

GTA 6 Update 01.002.002 patch notes

This first patch addresses several issues in the game, like static weather, the autosave function not working correctly, and errors that resulted in game crashes. If you've had sticky wanted levels, the patch should make removing them easier, and deadlift fans can finally start doing those exercises in gyms.

  • Fixed several issues that caused the game to crash
  • Fixed an issue that resulted in the weather not changing for extended periods
  • Fixed an issue that resulted in the game not autosaving correctly
  • Fixed several issues that resulted in phone calls not triggering correctly, including those that progressed the story or unlocked mission content
  • Fixed an issue that resulted in the players being unable to lose their Wanted Level
  • Fixed an issue that resulted in the player being unable to use the deadlift bar in the Gym
  • Fixed an issue that resulted in partners not handing over bags so that players could sell them to fences
