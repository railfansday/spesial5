This was my first time upgrading NetBSD and I’m happy with how it all turned out!

NetBSD’s Guide describes two different methods for performing an upgrade: boot from NetBSD install media and use sysinst(8), or use sysupgrade(8) to do an in-place upgrade of the system. With a bit of research, I get the sense that for major version changes (i.e 10.1 -> 11.1) sysinst is the preferred method, while sysupgrade is a convenient alternative for minor version bumps.
