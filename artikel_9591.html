I built Aegis — a personal cyber defense platform that checks links, emails, files and passwords before they hurt you

Tanggal: 2026-11-11

Posted on Nov 11 • Originally published at github.com

Most people don't get hacked by nation-state attacks. They get hacked by a fake link in a text message, a convincing "verify your account" email, a malware attachment disguised as an invoice, or a password that already leaked in someone else's data breach.

So I built Aegis — one place where a non-technical person can check each of those things before it hurts them, built to the same security standard it checks for.

🔗 Live demo: https://aegis-cyber-defense-platform.onrender.com (free hosting — first load after idle can take ~ a minute) 💻 Code: https://github.com/Manoj-2424150118/aegis-cyber-defense-platform

Smart Scan is the front door: paste anything — a link, an email, a suspicious message — and Aegis detects what it is and routes it to the right analyser automatically.

Underneath are 10 tools, each answering a question a worried user actually asks:

Every finding in every report ends with a Suggested Fix — concrete next steps written for the person holding the report. A test enforces that no finding can ship without one. A report should end the problem, not just name it.

Since v2.0, a detection-engine "Signal" layer sits across the analysers, and public Trends show what people are actually checking.

A security tool has to survive its own audit:

186 automated tests, all passing, with CI and CodeQL green on every push. The canonical reference scores never drift between releases: the reference phishing link scores 85, the phishing email 100, the disguised program 40 — in every battery, on every version. A scripted QA battery (functional checks, attack suite, fuzzing, load) runs in a sandbox before deployment and against the live site after it.

FastAPI (Python) back end, React + TypeScript front end, single Docker container, Neon Postgres for storage (accounts and vault items survive redeploys — proven by test).

I'm Manoj Kumar Sharma, a cybersecurity & software professional (MCA, Manipal University Jaipur) based in Jaipur, India. I also run Scam Decoded, where I break down real Indian scams in short videos.

If you try Aegis, I'd genuinely like to hear what it got right — and what it missed.
