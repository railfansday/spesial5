Let's Meet in the Middle

Tanggal: 2026-11-24

November 17th, 2026 • ~1,000 words • 6 minute read

I like making little tools that do one thing well and thing finding clever ways to combine them. It's the ethos behind a lot of the little software projects I have over at Less Software.

One of the first ones I made was a tool called whereami. Tongue-in-cheekly, I wanted to pitch it as the natural compliment to whoami. For that tool, the thinking was nearly every modern OS provides some kind of native API for geolocation. It felt silly to me that I could run a quick command from the terminal for so many things, but I couldn't run one that taps into this capability.

In the pursuit to make that tool cross-platform, one of the things I found myself navigating were the differences between them. Consistently, macOS tended to have a lot of extra niceties baked in, particuarly when it came to imagine recognition, natural language processing and accessibility tooling.

There's another handy framework macOS makes available to your system: MapKit. It's analgous to Google Maps and their API offerings, but native to the operating system.

It turns out it's pretty straightforward to build a CLI wrapper around that framework as well, so I made nearme (macOS only).

It's three small tools, each doing one thing.

whereami started life as a CLI that asks your operating system where you are. As of 0.4 it can also act like a reverse geocoder (on macOS):

Looking up an address doesn't need location permission, because nothing is asking where you are. jq does the arithmetic. The -s flag slurps both JSON objects into an array, and the filter averages the coordinates:

nearme searches for places around a set of coordinates using MapKit, the search engine behind Apple Maps. It reads coordinates from JSON on stdin, and it only cares about latitude and longitude. It has no idea those numbers came out of jq and not out of a GPS.

Averaging two coordinates is not the "real" way to find the middle, but over a few miles trying to find a place to meet for coffee it's close enough. What does matter is that the midpoint has no idea what's actually there.
