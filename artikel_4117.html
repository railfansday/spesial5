DOOM Developer id Software Confirms It's Working On A New Game

Tanggal: 2026-11-13

id Software, the developer known for FPS hits such as DOOM and Quake, has confirmed it's got a new game in the pipeline.

Alongside the Wolfenstein 3 announcement, Xbox CEO Asha Sharma revealed how id is also "working on its next game". id Software shared some additional information, confirming the project is led by Hugo Martin and is being developed by its teams located in Texas and Frankfurt.

Just don't expect to hear about it too soon. Here's the confirmation:

id Software: "We're incredibly excited about our next project, a new game from our teams in Texas and Frankfurt, with game direction once again by Hugo Martin. It'll be some time before we're ready to share more but we can't wait for you to see what we're working on."

According to The Verge's senior correspondent Tom Warren, this project is a "new Doom game". This is what he had to say in response to the id Software news on social media:

"I reported in July that id were in the “early stages of a new Doom game” and now it’s confirmed."

This follows the news earlier this year of layoffs at id Software, which led to a statement from the studio, noting how the team was now "about the same size" as it was when making DOOM (2016).

id Software has previously released DOOM (2016) and DOOM Eternal on the Switch with the help of Panic Button. There's no mention about it bringing across the latest title, DOOM: The Dark Ages, to Nintendo's new hybrid platform.
