InfoQ Homepage News Vercel Releases UI SDK for Agents to Compose UI from Reusable Behaviors

Nov 18, 2026 2 min read

Vercel has released UI SDK, an open-source TypeScript library that treats keyboard navigation, focus, selection, popups, and drag and drop as reusable behaviors rather than details buried inside finished components. Vercel UI SDK is published on GitHub as vercel-labs/ui and is currently in beta.

The behaviors live in @ui-sdk/core. Vercel says it built more than 50 of them, including createPopup, createSelection, createTypeahead, createRovingFocus, createReorder, createResize, createViewport, createListbox, createChange, createFocusRecovery, and createVirtualizer. A developer, or more often an agent, combines those helpers inside definePrimitive, which declares a component's state, API, and slots once. Framework adapters then render the same primitive through createParts in React, Vue, Svelte, Solid, or as Web Components. The parts are unstyled and expose attributes and CSS variables. The same behaviors also back a starter library of more than 50 unstyled components, from Color Picker, Token Input, and Command to Calendar, Tree, and OTP Input, with the same part names in all five adapters.

UI SDK is meant to be used by agents, not only written by them. The ui-sdk skill, installed with npx skills add vercel-labs/ui --skill ui-sdk, points an agent at the Markdown docs shipped in the installed packages. At runtime, createAgent, imported from the matching framework package such as @ui-sdk/react/agent, exposes snapshot, act, and query so an agent can read component state and call actions through the component API, without screenshots. Apps can approve or refuse those steps, and change callbacks receive a source of "agent" and may cancel a change. registerTools can expose the same methods to a browser's built-in agent through WebMCP, when the browser provides document.modelContext.

Developers already have several headless libraries at this layer, including Radix UI, Base UI, React Aria, Ark UI and its Zag.js state machines, and Headless UI. shadcn/ui sits one level above those primitives as a copy-into-your-repo component kit. UI SDK aims lower, at composable behaviors shared across frameworks, and adds a first-class agent bridge. The changelog thanks the teams behind Radix, Base UI, React Aria, shadcn/ui, Nuxt UI, and Geist. Vercel has not said whether shadcn/ui will be rebuilt on UI SDK.

Rahim, a product engineer at Mux who built Vidstack, wrote after reading the source:

This is so genuinely cool. I love how it's been packaged up. So elegant @shadcn and @shuding! I'll be studying this for a while. 1. createAgent is an "agent bridge" which gives a snapshot, act, and query tool. It allows agents to interact with the actual UI components directly 2. Change callbacks know when the agent made the change (details.source === "agent"), and the app can refuse it with cancel (I love this)

A developer identified as Stefan looked at the repository and asked how the idea compares with existing headless libraries:

I tried looking at the repo a bit but I’m not sure I quite understand the value prop of this versus something like Base UI. Is the thought process that we should be thinking about UIs/components as combinations of behaviours?

UI SDK is in beta as 0.1.0-beta.1, licensed under the Apache License 2.0, and subject to Vercel's public beta terms; the APIs, documentation, and behavior may change before general availability. Install @ui-sdk/core plus the adapter for your framework, for example npm install @ui-sdk/react @ui-sdk/core, which requires React 19 or later. The Vue, Svelte, and Solid adapters document peer ranges of Vue 3.5, Svelte 5.33, and Solid 2 from 2.0.0-rc.14. Setup details are in the documentation.
