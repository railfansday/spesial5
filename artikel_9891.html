Searching for pedagogical materials on memory models

Tanggal: 2026-11-10

I'm working on some supplementary materials for a course I'm TAing, my university's version of operating systems, that involves students developing an OS targeting a Raspberry Pi 3B+. One of the topics I'm trying to get at is strong and weak memory models (and why ARM has so many weird data/instruction buffer synchronization things students have to do when writing an MMU), so if you have any excellent example articles/passages/blogs on memory models that have helped you, please comment them so I can take a look!

The classic is still relevant, and ties the semantics of memory models to why you may want to implement it that way in hardware quite effectively: https://shiftleft.com/mirrors/www.hpl.hp.com/techreports/Compaq-DEC/WRL-95-7.pdf

I also think that the writeups that rsc did when updating the Go memory model are quite well presented: https://research.swtch.com/mm

And, while I haven't rewatched it, I seem to remember this was also quite good: https://learning.acm.org/techtalks/multicore
