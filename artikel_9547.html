Building a floating Markdown notebook with calculations and Vim on macOS

Tanggal: 2026-11-25

I kept running into the same small interruption: I needed to capture a thought, check off a few items, or calculate something, but opening a full workspace felt like more work than the task itself. So I built Inkflit, a local-first floating notebook for macOS.

The idea is a window I can summon from the menu bar or a shortcut, use for a moment, and dismiss. Notes are stored as individual Markdown files on the Mac. Inkflit supports Vim editing, but it can be turned off in settings.

Instead of forcing every thought into a separate app, Inkflit lets a note contain independent feature blocks. A checklist can sit next to a calculation or a code block. Type / on an empty line to choose a block:

The calculations are useful for the little things that show up while writing: a rough budget, a unit conversion, or a few numbers that need adding up. The note stays editable as text; feature blocks use Inkflit's own text markers rather than pretending to be standard Markdown syntax.

Vim mode comes from CodeMirror's Vim extension. It is not Neovim and does not load a vimrc. You can switch it off if you prefer a conventional editor. There's also a command palette, search across notes, snippets, and configurable shortcuts. Inkflit keeps backups and sends deleted notes to its own Trash.

For automation, the app includes a local MCP server with tools to find and edit notes. Formatting is a preview-and-apply operation: the preview is checked against the note before applying changes, so edits made in between are not silently overwritten.

Inkflit is open source and runs on Apple Silicon Macs with macOS 13 or later. The current DMG is ad hoc signed and not notarized. There is no built-in cloud sync, so you'll want to back up the notes folder yourself. Exchange-rate lookups fetch public rates; they don't upload the note.

I'd love feedback from people who keep short working notes: which tasks would you want inside a note, and which ones should stay in a dedicated tool?
