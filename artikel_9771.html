UnrealIRCd CVE-2026-114713: how to check your server and apply the hot-patch

Tanggal: 2026-11-14

Posted on Nov 14 • Originally published at daniele-michelin.com

In short: if you run UnrealIRCd 6.0.0 to 6.2.7 (or version 5), your server is affected. Version 6.2.7.1, released on 7 November 2026, fixes it, and a hot-patch does the job without a restart. The vendor reports attack attempts, and the US agency CISA added CVE-2026-114713 to its catalog of exploited vulnerabilities on 13 November (deadline for federal agencies: 16 November).

The implementation of the IRCv3 label tag does not escape characters properly when it echoes the tag into replies. An ordinary user can therefore inject newlines and other characters into the traffic between linked servers. The injected commands run with the authority of the server, for example KILL or GLINE. The maintainer found the flaw himself in an internal audit done with the help of AI.

The CVE description mentions networks with two or more linked servers. The vendor advisory does not say so explicitly. Do not rely on it and patch a single server as well.
