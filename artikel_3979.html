The latest main branch update doesn't include The Fool or the new game modes

When you purchase through links on our site, we may earn an affiliate commission. Here’s how it works.

Slay the Spire 2's latest character, The Fool, is so overpowered that it's only a matter of time before they're hit with the nerf hammer – a point that developer Mega Crit seems to be alluding to as it notes that the latest content to hit the roguelike's beta branch is going to need "quite a bit" of polishing before it comes to the game's main branch.

Mega Crit says as much in the patch notes for Slay the Spire 2's third major main branch update, which rolled out a few hours ago, "bringing all of the content, art, balance changes, and bug fixes from v0.108.0-v0.111.0" that beta branch players have been getting stuck into already. This notably doesn't include v0.113.0 – last week's beta patch that introduced two new game modes and The Fool in the roguelike's biggest update yet.

There's a reason for that, though. "While the new character and game modes on the current beta branch are the talk of the town right now, all that stuff will need to be tested and polished up quite a bit more before it reaches the main branch," Mega Crit explains today.

If you've tried out The Fool at all yet, this, uh, isn't surprising. As our senior writer and resident Slay the Spire 2 expert Austin Wood so eloquently puts it, they're "balanced like a barbell with six plates on one end and two on the other."

To be fair, Mega Crit already hinted that nerfs were planned from the moment The Fool was introduced, saying: "We expect to make a great number of content and balance changes before the Fool is ready for the main branch." Have fun with them while it lasts, basically.

Back to today, Mega Crit notes that "we're not sure when" The Fool and those aforementioned game modes will be ready for the main branch, encouraging anyone interested to switch over to the beta to give them a go.

Slay the Spire 2 devs declare the "perfect card," and of course it's one I thought was bad.
