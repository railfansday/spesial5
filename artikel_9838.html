InfoQ Homepage News Java News Roundup: TornadoVM, A2A Java, Open Liberty, Open J Proxy, Gradle, EclipseStore

Nov 09, 2026 4 min read

This week's Java roundup for November 2nd, 2026, features news highlighting: point releases of TornadoVM, TornadoInsight, A2A for Java, Gradle and EclipseStore; the November 2026 edition of Open Liberty; the third release candidate of Open J Proxy; the second release candidates of Micrometer Metrics and Micrometer Tracing; and the third beta release of Quarkus 4.0.

Build 23 of the JDK 28 early-access builds was made available this past week featuring updates from Build 22 that include fixes for various issues. More details on this release may be found in the release notes.

For JDK 28, developers are encouraged to report bugs via the Java Bug Database.

The release of TornadoVM 8.1.0 delivers bug fixes and notable changes such as: the ability for a TornadoVM kernel read and write a device allocation owned by another library owns, in place, without copying it and without writing a TornadoVM array header into it; and a change in the overloaded initializeDeviceAsync() method, defined in the TornadoExecutionPlan class, to initialise a device during application sets up. Further details on this release may be found in the release notes.

Beehive Lab has also released version 2.1.0 of TornadoInsight, their IntelliJ IDEA plugin for TornadoVM. This release includes bug fixes, documentation improvements and new features such as: a new experimental AI-assisted transformation of a Java method into a TornadoVM kernel; and a new TornadoToolchain record that checks the TornadoVM SDK with the project JDK, builds the classpath, compiles with the project JDK, and creates a launcher. More details on this release may be found in the release notes.

The release of A2A Java SDK 1.5.0, a Java library that implements the Agent2Agent Protocol (A2A) for running agentic applications as A2AServers, ships with bug fixes, documentation improvements, dependency upgrades and new features such as: a new OpenTelemetryPushNotificationSenderDecorator class to create a CLIENT enumeration, defined in the OpenTelemetry SpanKind enum class, to reflect the actual delivery outcome of success or failure; and the ability for authorized JPA task listings to offer optional provider capabilities so that supported policies can directly filter both the database count and page queries that for reduced scan and deserialization costs. Further details on this release may be found in the release notes.

The third beta release of Quarkus 4.0.0 provides bug fixes, documentation improvements, dependency upgrades and new features such as: support for Valkey in the Quarkus Redis Client extension; and a new @CheckedTemplateParam annotation to support explicit naming of parameters in methods annotated with @CheckTemplate without the required -parameters compile flag. More details on this release may be found in the release notes.

The GA release of Open Liberty 26.0.0.11 delivers bug fixes, resolutions to numerous CVEs and new features such as: the ability to configure the timeout of the server quiesce stage, via the quiesceTimeout element, that was once fixed at 30 seconds; and improved validation that blocks form login error page redirects to external hosts unless the target host is listed in the wasReqURLRedirectDomainNames attribute of the element.

The third release candidate of Open J Proxy 1.1.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: support for PostgreSQL and MariaDB coverage in the C++ ODBC client; and a simplification of building and using the C++ ODBC drivers across all major OS platforms. Further details on this release may be found in the release notes.

The release of Gradle 9.9.0 provides notable changes such as: the ability for Kotlin DSL scripts to be incrementally compiled using the Kotlin Build Tools API for improved build performance; new test filters that may be applied to JUnit Platform tests that are not declared as methods; and improvements to the Problems API that provides a predefined hierarchy of problem groups from the Problems interface. More details on this release may be found in the release notes.

The release of EclipseStore 4.3.0 delivers bug fixes, dependency upgrades and new features such as: A refactor of the VectorIndex interface, part of the JVector Index, to handle large indices and concurrent load and crash safety; and a new, lightweight VanillaJS storage viewer for the storage REST Interface that now deprecates the existing standalone Vaadin/Spring-based client GUI. More details on this release may be found in the release notes.

The second release candidate of Micrometer Metrics 1.18.0 ships with dependency upgrades and one new feature that adds support for fractional updates in Micrometer Atlas counters that had previously truncated them to a type long. Further details on this release may be found in the release notes.

Similarly, the second release candidate of Micrometer Tracing 1.8.0 provides bug fixes, documentation improvements, dependency upgrades and new features such as: more efficient allocation of OpenTelemetry baggage reads by directly searching retained/current baggage and building the bulk results in one map; and an elimination of allocating wrappers while clearing an already empty context by reusing the NOOP function, defined in the CurrentTraceContext.Scope interface in conjunction with an instance of the Tracer.SpanInScope interface. More details on this release may be found in the release notes.
