Qwen2.5-Coder-7B-Instruct, Alibaba's 7B-parameter coding model, was downloaded 1.49M times on Hugging Face in the last 30 days. That's nearly 3x its bigger sibling Qwen2.5-Coder-32B-Instruct (518K) and about 25x DeepSeek's deepseek-coder-7b-instruct-v1.5 (60K). Below are all 85 code generation models in the TextModels directory: open weights ranked by downloads, hosted coding APIs ranked by price, the Ollama builds you can run on a laptop, and the historical models that taught machines to write code.

The 7B model's lead isn't about benchmarks. Qwen's own Qwen2.5-Coder technical report says the 32B-Instruct version matches GPT-4o on coding, after continued pretraining on more than 5.5 trillion tokens. But most developers pick the model that fits on their machine. HackerNoon's guide to running Claude Code for $0 names qwen2.5-coder:7b the best pick for an 8GB laptop, and builders keep fine-tuning on top of it: Zed's original zeta edit-prediction model started from Qwen2.5-Coder-7B, and sweep-next-edit-1.5B is built on the same architecture.

Everything comes from the TextModels directory's Code Generation filter (85 models) as of November 20, 2026. Hugging Face entries are ranked by 30-day downloads from the Hugging Face API. "Verified" means the directory fetched and confirmed that model's metrics. Hosted APIs have no public download counts, so they're ranked by input price per million tokens as listed on OpenRouter. Ollama builds are listed alphabetically by model and size, and historical models are grouped by family with a link to each paper.
