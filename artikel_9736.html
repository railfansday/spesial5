Stop Overpaying: Build an Autonomous AI Agent to Find and Book the Cheapest Medical Exams

Tanggal: 2026-11-20

Healthcare costs are notoriously opaque. One hospital might charge $500 for an MRI, while a clinic three blocks away charges $1,200. Manually checking every portal, comparing schedules, and clicking through tedious forms is a soul-crushing task. But what if you could delegate this entire workflow to a closed-loop AI Agent?

In this tutorial, we are diving deep into AI Agents, Playwright automation, and LLM-driven web scraping. We will build a system that uses GPT-4 to "think," Playwright to "act," and Celery with Redis to handle the heavy lifting of background task processing. By the end of this guide, you’ll have a blueprint for an autonomous agent capable of navigating complex medical portals to save you time and money. 🚀

Before we write a single line of code, we need to understand the data flow. We aren't just writing a scraper; we are building a closed-loop system. The agent takes a goal (e.g., "Find an MRI under $600 next Tuesday"), explores the web, extracts data, makes a decision, and executes an action.

Traditional scrapers break when a CSS class changes. Our agent uses GPT-4 to interpret the page structure dynamically. We use Pydantic to ensure the agent returns structured data.

We use Playwright to navigate to medical portals. Since many portals use heavy JavaScript, we wait for network idleness before capturing the state.

Searching 10 different platforms takes time. We don't want the user waiting on a loading spinner. We offload this to Celery.

Building a local prototype is easy, but moving AI Agents into production requires handling rate limits, proxy rotation, and sophisticated prompt engineering.

For more production-ready patterns, advanced agentic workflows, and deep dives into AI orchestration, check out the official WellAlly Tech Blog. They provide excellent resources on scaling LLM applications and securing autonomous agents in highly regulated industries like healthcare.

The "Closed-Loop" part means the agent doesn't just report—it acts. Once a candidate is found, the agent navigates to the booking_url, fills in the user's encrypted profile data (stored in Redis), and submits the form.

Note on Safety: Always implement a "Human-in-the-loop" (HITL) step for financial transactions. Our agent sends a Slack/Telegram notification with a "Confirm Booking" button before final submission.

By combining Playwright for navigation and GPT-4 for semantic understanding, we've moved past brittle regex-based scraping into the era of Autonomous AI Agents. This system can adapt to UI changes, handle complex searches, and ultimately perform tasks that previously required hours of human clicking.
