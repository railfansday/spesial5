In one week, graphify picked up 3.4K GitHub stars - more than the combined total of the five most starred document parsers. That's a clear indicator of what developers are going for - less PDF parsing, more agent memory.

Text mining used to mean one library and a bag of words. Today, it's more of a pipeline really: one tool reads the raw document, another indexes it so that a model can retrieve the right bit, and a third one maintains context across sessions. Most of the popular repos on GitHub are now in that pipeline.

Every repo below comes from TextMining.Tech, HackerNoon's directory of over 7,000 open source text mining tools, libraries and frameworks with 100+ stars each. They're grouped by the job they do, so you can see which part of the pipeline you're adding. This is part 1 of a four-part series.

These tools get text out of scans, PDFs, Office files and web pages, and hand it on in a shape a model can use. The newer ones skip plain text entirely and output markdown or JSON. For the full field, see our list of 138 open source OCR and PDF parsers.

PaddleOCR leads on stars, but it was last updated Sep 16, 2026. MinerU, docling and crawl4ai all shipped changes in the past week.

Once text is extracted, a model still has to find the right piece of it at the right moment. That is retrieval-augmented generation (RAG), and this group has grown past it: memory layers that persist between sessions, knowledge graphs built from code, and compressors that trim what reaches the model.

Self-hosted chat interface for Ollama and OpenAI-compatible models

Visual builder for designing and deploying agents and AI workflows

Turns a codebase and its docs, schemas and PDFs into a queryable knowledge graph, with no vector store

Four of these are built for agents, and they're the ones climbing: graphify, xerj, claude-mem and headroom added nearly 8K stars between them this week.

Not every popular repo is a library. These are free courses and guides, mostly notebooks you run yourself, and they collect stars long after their last commit. Two of the seven are written in Chinese, a reminder of how much of this audience reads outside English.

hello-agents added the most stars in this group this week, ahead of both Microsoft courses.

All numbers come from the TextMining.Tech snapshot of Nov 24, 2026. The directory tracks open source GitHub repos with at least 100 stars, excludes archived repos and forks, and refreshes daily. We started from the directory's top repos by stars, then sorted them into three groups by the job each does in a text pipeline. Some repos carry more than one category tag on the site; each one appears here only once, under its main job. "Added this week" is the directory's own weekly star count. Stars will have moved by the time you read this, so each repo name links to its live directory page.

The most-starred repo in the whole directory isn't on this list. huggingface/transformers has 169.2K stars, but it's a model library, not a pipeline tool, so it gets its own episode, next to LlamaFactory and the rest of the fine-tuning crowd.

Speech comes after that, and it's moving fast. VoiceStudio picked up 5.1K stars this week. Nothing above came close.

If you want the long tail, each group has its own category on TextMining.Tech: OCR & Documents has 707 repos, Search & Retrieval has 1,526, and Language Models has 1,381. Or open the full directory of 7,061 repos and sort by "Trending this week". That's how VoiceStudio showed up on our radar.
