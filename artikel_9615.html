Questions about running agent code in a microVM

Tanggal: 2026-11-26

Thanks to everyone who tried the quickstart. If you haven't yet, it's a small repo that runs code your agent wrote in a fresh Sandscale sandbox (a Firecracker microVM with its own kernel): https://github.com/sandscale/agent-quickstart. If a README step didn't work for you, or you hit an error, reply here or open an issue on the repo and I'll look at it. Sandscale is in early access and the Free plan is open: https://cloud.sandscale.dev/auth/signup.
