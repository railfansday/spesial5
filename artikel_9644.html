Tanggal: 2026-11-15

My name is Bona Hanson Junior and i study sofware engeneering at YIBS-ISSEST.Starting university as a Software Engineering student has been an exciting and challenging experience for me.

When I first entered this field, I knew I was stepping into a world full of technology, innovation, and endless possibilities. However, I quickly realized that Software Engineering is much more than just writing lines of code. It requires patience, creativity, logical thinking, and a willingness to learn.

My journey started with learning the fundamentals of programming, algorithms, computer systems, and problem-solving.

At first, some concepts seemed complicated(especially maths). Understanding how algorithms work, writing my first programs, and figuring out how different parts of a computer interact were all new experiences.

But every lecture and practical exercise introduced me to something new.

One of the most interesting parts of my journey so far has been learning C programming.

Using tools like Visual Studio Code and exploring Git and GitHub have helped me understand how developers write, manage, and share code.

Of course, it hasn't always been easy. There have been moments when my code refused to work, when I couldn't understand an error, or when I spent more time debugging than actually writing code.

Every error is an opportunity to learn something new.

I know I still have a long way to go. I'm not an expert, and I don't pretend to know everything.

I'm simply a Software Engineering student eager to learn, improve my skills, build meaningful projects, and explore the endless possibilities of technology.

My goal is to turn the knowledge I gain today into practical skills that will help me create solutions tomorrow.

I'm excited to share my progress, document my learning experiences, connect with other developers, and grow within the tech community.
