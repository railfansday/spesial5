Tanggal: 2026-11-18

One command now gives an AI agent 106 open-licensed marketing skills. They cover copywriting, SEO, pricing, cold email, launches, analytics and retention, from Corey Haines, Daniel Agrici, Tech Leads Club and Cloudflare. All of them are packaged as the Marketing & SEO plugin in Cuttlefish.MD, HackerNoon's license-checked skills marketplace.

An agent skill is a folder with a SKILL.md file of instructions that your agent loads only when the task calls for it. The format is an open standard at agentskills.io that 32+ tools support, including Claude Code and Codex CLI.

Every skill below comes from HackerNoon's SKILL.md Library, is MIT- or Apache-licensed and links to its source.
