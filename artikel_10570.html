Big Google Antigravity update brings Remote Agents, Voice Mode, and redesign

Tanggal: 2026-11-13

Google is rolling out a big update to Antigravity this week that features a new design, Voice Mode, and Remote Agents.

Version 2.29 of Google’s agentic development platform for Mac, Windows, and Linux starts with a redesigned conversation page that moves the prompt box to the bottom of the screen, while there’s now a greeting at the top, like the Gemini app. The app also now has a default Google Sans font and Onyx theme.

Additionally: “Single-repo projects combine branch and Git worktree selection into one menu, and the agent picker now lives inside the model menu.”

Next to the existing microphone, there’s a new Voice Mode that’s powered by Gemini Live. This lets you “talk to Antigravity and hand requests to the agent by voice.” Google offers various options for Antigravity’s voice, while you can customize speed from 0.75x to 2x.

We want Antigravity to be working for you all the time. We’ve been rolling out remote agents this week. Your tasks run in independent cloud virtual machines.
