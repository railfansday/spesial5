Analogue has long been good at expanding the features and functionality of its consoles through regular firmware updates, but installing those updates has always required moving files around with a memory card. That’s no longer the case with the Analogue 3D, the company’s modernized version of the Nintendo 64. Although the console has had Wi-Fi hardware since day one, it’s only now been finally activated through the last update you’ll need to install with a memory card.

Analogue on Wednesday released the version 1.6.0 firmware for the Analogue 3D, adding support for 2.4GHz, 5GHz, mixed, and hidden Wi-Fi networks. Once the update is installed, the Wi-Fi setup process will begin automatically when the console is booted, but there’s now an added Wi-Fi section in the Analogue 3D’s settings menu for updating passwords and other details later.
