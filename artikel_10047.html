In the KornShell, the alias r (``re-do'') is preset to fc -e - (equivalent to the POSIX fc -s). This is probably an easier command name to remember than fc (``fix command''), but it does not meet the Utility Syntax Guidelines. Renaming fc to hist or redo was considered, but since this description closely matches historical KornShell practice already, such a renaming was seen as gratuitous. Users are free to create aliases whenever odd historical names such as fc, awk, cat, grep, or yacc are standardized by POSIX.

I use zsh in vi mode and it's pretty capable these days. This means that going back in history can be done with j/k and then it's possible to edit the command-line as in vi(m), including typical movements (using f/F/t/T to aim for a character, b/B/w/W/e/E for word movement), visual selection, adding newlines but also copy-pasting across history entries.

This is probably not restricted to zsh in vi mode but it's an implementation that I find really satisfactory in practice.

And now I've finally added the ability to edit the current command-line in my editor using zsh' edit-command-line module for the rare cases that get too complex for the editor in zsh (and at that point, it means I should really save my stuff in a dedicated file).

Echoing some of the earlier comments, here is my setup with WezTerm terminal and fish shell:

Scrolling: WezTerm's Copy Mode (Ctrl+Shift+X), to use Vim motions or PgUp/PgDown to navigate scrollback and select text.

Editing terminal commands: readline-style shortcuts and Alt+E for fish’s edit_command_buffer, which opens the current command line in my preferred editor.

Reusing command arguments: bash's Alt+. shortcut inserts the last argument of the previous command. Pressing it repeatedly cycles through earlier commands. There are shortcuts for other arguments too.

Copying text: WezTerm's Quick Select Mode for copying strings matching certain (configurable) patterns.

You might also look into keyboard-driven web browsers. I am a happy user of qutebrowser. There are also browser extensions (tridactyl?).
