Nintendo Joins The Accessible Games Initiative, Adopting A Bunch Of New eShop Game Tags

Tanggal: 2026-11-05

Nintendo has joined the Accessible Games Initiative and, in the process, has added a collection of new accessibility tags to the eShop.

The new tags — which include various accessibility features like 'Narrated Menus', 'Full Input Remapping', and 'Playable with Buttons Only' — make it easier to sort through games based on specific requirements. Simply select a tag from the eShop Tags page, and it will bring up every game where that requirement can be applied.

A product of the Entertainment Software Association, the initiative has also been adopted by Amazon Games, EA, Google, Xbox, Riot Games and Ubisoft. "Our goal is to improve players’ gameplay experiences by providing clear information about the accessibility features available in video games," the Accessible Games Initiative website reads.
