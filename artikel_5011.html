Bitcoin’s blockchain keeps growing as its live ledger sheds 25 million entries

Tanggal: 2026-11-23

Bitcoin averaged about 669,000 confirmed transactions a day in the week through Nov. 22, as its unspent-output count sat near its February 2024 level.

Bitcoin’s set of unspent transaction outputs fell to about 164.1 million on Nov. 22, roughly 25 million fewer entries than on Dec. 22, 2024. The network was still confirming hundreds of thousands of transactions a day. A single transaction can spend several existing outputs or create several new ones, so a busy day can leave Bitcoin’s live ledger with fewer entries.

Blockchain.com’s unspent-output series last recorded 164,079,624 outputs on Nov. 22, down 13.2% from the last Dec. 22, 2024 reading of 189,085,860. Firsthand Bitcoin’s published comparison used 164,088,181 for Nov. 22 and 189,282,514 for its December 2024 series high. That pair implies a drop of 25.2 million, and Firsthand placed the November reading at its lowest since Feb. 20, 2024.

Each point is the last Blockchain.com reading of the UTC day. The count excludes OP_RETURN outputs. The source export has no reading for Nov. 15, 2025.

Source: Blockchain.com Unspent Transaction Outputs

The daily transaction series recorded 638,018 confirmed transactions on Nov. 21 and 716,530 on Nov. 22. Across the seven days through Nov. 22, Bitcoin averaged about 669,000 confirmed transactions a day.

An unspent transaction output, or UTXO, is a portion of bitcoin that a previous transaction made available to spend under specific conditions. When a full node checks a new transaction, it looks up the earlier outputs that the transaction inputs reference. If the transaction spends five existing outputs and creates one spendable output, the set loses four entries. It still counts as one confirmed transaction.

Miners collected an average of 2.84 BTC a day in transaction fees in the 30 days through Nov. 21. That is a network-wide fee total expressed as a daily average. The cost of combining small outputs in a single transaction depends on the fee rate and the size of that transaction. Each additional input generally adds size, so lower fee rates make the same consolidation cheaper. The aggregate counts leave open how much consolidation contributed to the decline.

BTC.network’s supply audit counted 162,917,807 outputs in a copy of the set taken by its own node at block 976,975 on Nov. 22. Blockchain.com’s series counts valid outputs and excludes OP_RETURN outputs, which can carry data without creating a spendable entry. An exact comparison would require a shared block reference and comparable counting methods.

A smaller set leaves full nodes with fewer spendable entries to track. Bitcoin Core’s documentation lists the number of outputs and estimated chainstate disk usage as separate measurements. Disk usage, the size of the historical blockchain, the amount of bitcoin those entries represent, and the number of wallets each require their own measure.
