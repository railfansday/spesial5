Bisq 2 desktop users must update to keep trading Bitcoin

Tanggal: 2026-11-24

Version 2.1.16 patches a flaw in the bundled Java runtime. A separate Nov. 25 network change requires nodes to run version 2.1.14 or later.

Bisq released a security update for Bisq 2, its peer-to-peer Bitcoin trading software, on Nov. 23 and urged desktop users to install version 2.1.16 as soon as possible, even if they have no trade in progress. Version 2.1.16 fixes a flaw in the app’s bundled Java software, and Bisq says desktop users need the update to keep trading. A separate network change on Nov. 25 requires nodes to run at least 2.1.14.

In the 2.1.16 release notes, Bisq identified the flaw as Java4Shell and said it could let an attacker run code on an affected system. The release also includes a Tor security update.

After the Nov. 25 change, Bisq 2 nodes running versions older than 2.1.14 can miss offers and trade messages. Bisq announced the change in October when it released version 2.1.14. Starting Nov. 25, updated nodes will require newer V2 signatures on the data they store and share. Bisq warns that versions below 2.1.14 will have trouble connecting and exchanging data, and the project will end support for them.

The project's headless node release notes warn that trades can stall if a node on 2.1.13 misses messages it needs to move a deal forward.

The official downloads page lists the desktop builds for Windows, macOS and Linux and provides PGP signatures and a public key for verifying the installers.

Version 2.1.16 also changes how the app handles a trade across a restart. It saves messages that arrive before the trade can process them, then applies them on startup if trading is enabled and the node meets the minimum trading version. In pre-release testing, a Bisq contributor reported completing test trades after upgrading Ubuntu nodes from 2.1.15 to a 2.1.16 release candidate. The test used nodes accessed through the API and covered trades that were already open during the upgrade.

For mobile traders, the version to check depends on the app. Bisq Easy Mobile runs its own node on Android. Its 0.15.0 release moved to the 2.1.14 core. Bisq says users still on 0.14.x can miss offers and messages or see trades stall after Nov. 25. Bisq urges users to install Bisq Easy 0.17.0, which uses the 2.1.15 core, to keep trading.

Bisq Connect on Android and iOS controls a separate desktop or headless Bisq 2 node. Users who rely on a node run by someone else need that operator to check the version and update it if it falls below the network minimum.
