First macOS Sequoia 15.8.3 and macOS Tahoe 26.7.3 RCs now available

Tanggal: 2026-11-04

In addition to the release of macOS 27.3 beta 1, Apple is also rolling out the first release candidates of macOS Sequoia 15.8.3 and macOS Tahoe 26.7.3. Here are the details.

Apple today released the first developer beta of macOS 27.3, which introduces several new Safari features, including Vertical Tabs, Adaptive Dark Mode, and Siri AI Custom Actions, and may also bring support for additional Siri AI languages, including Traditional Chinese, Norwegian, Turkish, and Vietnamese.

Additionally, the company rolled out the first release candidates of macOS Sequoia 15.8.3 and macOS Tahoe 26.7.3, continuing its support for older versions of macOS. Just last week, Apple released macOS Sequoia 15.8.2 and macOS Tahoe 26.7.2, which addressed more than 150 security vulnerabilities.

As usual, the release notes for both RCs only mention that “this update provides security fixes for your Mac,” with details about the specific vulnerabilities addressed expected to be published once the updates are officially released.

The release build for macOS Sequoia 15.8.3 is 24H314, while the release build for macOS Tahoe 26.7.3 is 25G416.
