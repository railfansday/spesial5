Your Googlebook just got a Chrome update – 5 new features

Tanggal: 2026-11-21

The Chrome update includes more useful vertical tabs, easier screen sharing, and some handy keyboard shortcuts.

On Monday, Google rolled out an M157 update for the Chrome web browser on Googlebook OS, with a handful of new features and performance boosts to streamline your workflow and browsing experience.

While the first Googlebooks on the market have received mixed reviews, these features could help the laptops gain more useful features in Chrome that other browsers already offer.

Here are the five new Chrome features on Googlebook OS to know about.

If you’ve ever had to share your screen on a video call, you know how irritating it can be to switch tabs without having to repeatedly start and stop sharing. This Chrome update adds a tab-sharing controls bar; when you share a browser tab in a video call, Chrome will display a persistent control bar at the top of the window so you can “Stop sharing” or “Share this tab instead” from any tab.

When you hover over a collapsed vertical tab rail with your mouse or trackpad, it will expand, so you can read full tab titles, switch tabs, or manage groups. The rail will collapse again when you move the cursor away.

This auto-expand feature is enabled by default. If you want to turn it off or on, go to Settings > Appearance > Tab position > “Auto expand tabs on hover,” or right-click the vertical tab rail.

The Chrome update allows you to manually resize your vertical tab bar to view longer page titles when needed. The browser will remember your custom tab width, even after you open a new window or restart the browser. (You’ll just need to turn “Auto expand tabs on hover” off for it to work.)

The system’s “Save As” file picker is now enabled by default for menu save actions, such as “Save link as” and “Save image as,” so you can more easily rename files and select a destination folder. This includes Google Drive or external storage.

Outside of these new features, a few of Chrome M157’s performance fixes include the ability to press Ctrl+L to reveal and select web addresses; keeping your bookmarks bar visible in fullscreen mode and while screen sharing; better media controls while using Picture-in-Picture mode; and the ability to partially translate PDFs within your browser.

If you have Chrome set up to automatically download and install updates, you won’t have to lift a finger to take advantage of the new features and performance boosts.

But if you’ve disabled automatic updates, you can manually update by selecting the three-dot menu in the top-right corner of your Chrome window and navigating to Help > About Google Chrome > Relaunch.

If the Relaunch option is greyed out or nowhere to be found, you’re running on the latest version of Chrome. And if you were working on something before the update, don’t worry: Chrome will save your open tabs and reopen them automatically when you restart.
