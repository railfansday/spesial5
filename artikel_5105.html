Zcash (ZEC) Might Become More Secure on iPhones Soon

On Zcash Community Forum, a new grant application has emerged which is aimed at making Zcash even more private on iPhone-based wallets. The author seeks a $25,000 grant in order to implement a private way of retrieving encrypted transaction memos.

Essentially, the proposal allows hiding which transactions users have been looking up, which is a potential deanonymization vector. Considering how Zcash placese itself on the market, revealing any kind of external information is a step which might shorten the distance between a random transaction and a specific user.

Zcash transactions today contain encrypted data called memos. Various wallets read those memos in order to receive information about the transaction. The message itself stays encrypted, so is retrieved data, however, the query itself is not protected by any means which enables potential tracing.

Even when using Tor, the transaction ID stay out in the open and can be read by anyone.

With the integration of private information retrieval into SDK, hiding the query itself wil be easier, messages would be decrypted locally and wallets themselves will verify the returned information.

The first tests have already shown promising results. During testing in an iOS Simulator, the modified SDK managed to retrieve a 512-byte memo through an encrypted query, without revealing the transaction ID to the wallet server.

The developer expects the implementation of the proposal by January 30, 2027, with testing on physical iPhones and a public SDK release planned for the final stage.

However, the proposal is still seeking funding, and its actual adoption will depend on individual wallet developers.
