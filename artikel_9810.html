Handoff: Trustless Escrow for the Digital Economy

Tanggal: 2026-11-08

The digital creator economy is built on "trust me bro." When you buy an API key, a piece of code, or a digital account from someone online, one person has to go first. If the buyer pays first, the seller can ghost them. If the seller delivers first, the buyer can take the files and run.

Handoff is a trustless escrow protocol on Solana that fixes this.

The "Demo Mode" Feature To allow judges to test both sides of the escrow without switching Phantom wallets, I built a Burner Wallet system into the frontend. Clicking "Seller" in the UI generates a local Keypair, airdrops SOL, and mints test USDC to it. The app then uses this burner wallet to sign the Seller's actions natively.

Challenges Wiring a Solana smart contract to a React frontend is a minefield. I had to build custom retry loops to handle RPC lag (when the blockchain node hasn't indexed a newly created account yet), manually construct transactions for Phantom to sign, and patch Vite to support Node.js Buffer polyfills.
