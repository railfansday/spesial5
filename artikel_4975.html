Solana Drops 'Mainnet Beta' After Six Years: Here's What 1.0 Is All About

Solana is officially out of beta, more than six years after launching a blockchain that has been handling real money the whole time.

The Solana Foundation on Monday retired the “mainnet beta” label and introduced Solana 1.0, a shared version number for the network's underlying rules. The change is primarily about how developers and validator operators coordinate software updates, not a fresh boost to transaction speed or any other meaningful improvement over what users already have.

Solana launched its mainnet beta on March 16, 2020, and kept the experimental-sounding name even as users traded tokens, built applications, and moved assets across the chain.

Nothing happens to those assets now. “Your SOL, accounts, assets, applications, and transaction history remain the same,” the Foundation said. Users don't need to swap tokens, move wallets or install anything to keep using the network.

Solana has two major validator clients: Agave, developed by Anza, and Firedancer, built independently by Jump Crypto. Each has its own code, release schedule and version numbers, which can make it harder to tell whether different software releases support the same network features.

Solana 1.0 creates a common reference point for the protocol itself. An Agave release and a Firedancer release can support the same protocol version without sharing a software version number.

That distinction matters as the network relies on more than one software implementation. A bug in one client need not affect every validator, although software diversity alone cannot guarantee the network will stay online.

“Announcing a protocol version does not activate every associated improvement at once,” the Foundation warned. Operators still need to check whether their particular software supports a planned upgrade and follow its activation instructions.

The Foundation said it coordinated the change with Anza and the Firedancer team. Its announcement does not describe a new voting system or a change in who governs Solana; the network's governance process for proposals remains separate.

The Foundation credits engineering work that preceded Monday's announcement, particularly Alpenglow and Firedancer. Solana's Alpenglow upgrade went live on October 21, replacing the system validators had used to reach agreement since launch.

Alpenglow targets transaction finality of roughly 150 milliseconds, compared with about 12.8 seconds previously. Finality is the point at which a transaction is considered settled; that improvement came from the October upgrade, not from calling the network 1.0.

Firedancer also reached mainnet in 2025, giving validators a separately developed alternative to Agave. That reduces dependence on a single codebase, though the extent of the protection depends on how widely different clients are actually used.

Solana has reasons to be careful with promises of reliability. Its network went offline for nearly five hours in February 2024, following an outage lasting almost 19 hours a year earlier.

Documentation and block explorers will gradually adopt the new mainnet name, according to the Foundation. Its upgrade tracker still lists Agave 4.4 as planned for November and Agave 4.5 for December, each with its own release and activation requirements.
