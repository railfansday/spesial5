macOS 27.3 public beta 2 now available, here’s everything new

Tanggal: 2026-11-21

After releasing developer beta 2 of macOS 27.3 earlier this week, the company is now rolling out the public beta for users looking to try the new features ahead of next month’s official release. Here’s what’s coming.

Those came alongside several new features and tools on macOS 27.3 beta 1, including vertical tabs and adaptive dark mode in Safari, native Live Activities support, Markdown rendering in Quick Look, additional checks for potentially harmful content shared through iCloud links, and Siri AI support for Traditional Chinese, Norwegian, Turkish, and Vietnamese.

And speaking of Siri AI, macOS 27.3 also expands the assistant’s capabilities across Apple’s own apps, allowing users to perform more complex actions in Messages, Music, Calendar, Photos, and Reminders, as well as manage files and folders. Apple is also introducing new tools for third-party developers to build more advanced Siri AI integrations using Markdown-based instructions.

While macOS 27.2 was a rather uneventful update, macOS 27.3 is shaping up to be the biggest update since the release of macOS 27, and users on the public beta can now try out these new features ahead of their official release.

The release build for macOS 27.3 public beta 2 is 26C5047e, which matches the developer build.

If you’d like to join Apple’s free public beta program, visit beta.apple.com.
