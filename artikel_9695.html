One API key for Claude, GPT, Gemini and Grok: a Python and Node quick start

Tanggal: 2026-11-25

If you build with LLMs, you probably juggle several provider accounts, keys and SDKs. Here's a shortcut: one OpenAI-compatible endpoint that serves models from Anthropic, OpenAI, Google, xAI, DeepSeek, Moonshot, Qwen and Z.ai, so you keep the SDK you already use and only change the model name.

I'm using Refract here. It's pay per token with no subscription, and prices are well below the official ones (Claude Sonnet 5.5 is $0.50 / $2.50 per 1M tokens against $2 / $10).
