Lumi-4B is a 4B-parameter instruct language model developed by CEIA/UFG’s NLP team, with a focus on Brazilian Portuguese and support for English. It starts from Nemotron 3 Nano 4B and was trained with continual pre-training, knowledge distillation, and supervised fine-tuning. Maintainer: ceia-research.

Conversational and instruction-following text generation, especially in Brazilian Portuguese; English text generation is also an intended use. The training pipeline was designed to retain mathematics and coding capabilities, but those tasks should be evaluated for the intended application.

Keep thinking disabled for this release. It has no additional RL/RLVR or dedicated model-identity training; tool use is not documented as validated. The model may produce inaccurate, biased, or unsupported content, and performance outside Brazilian Portuguese and in specialized domains needs evaluation. The README describes a later v0.2 release separately; its updated data blend and benchmark claims should not be assumed to apply to this exact model.

The supplied related-model list includes GAIA Gemma-3 Gaia PT-BR 4B, described as a Brazilian-Portuguese model based on Gemma 3, and Manacá-1B base, described as a Brazilian-Portuguese base model. These descriptions establish differences in stated model focus and type, not comparative quality or capability.

4B instruct model; languages: Portuguese and English. The stated starting point is Nemotron 3 Nano 4B, with Nemotron 3.5 Lightning used as the distillation teacher. CPT used 50 billion tokens and an 8,192-token training context, followed by SFT. Architecture and tokenizer details are referred to the base model documentation but are not specified here. No hardware, validated inference versions, recommended generation settings, or measured benchmark values are provided in text.

Generated text in response to chat or instruction prompts. The model is tagged for text generation; no structured-output format or other output controls are documented.
