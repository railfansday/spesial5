Rp15.150 or Rp 15.150? A currency space we flipped across 8,775 amounts

Tanggal: 2026-11-09

We changed one character in 8,775 price strings, and then we changed it back to a different character. The character was the space between "Rp" and the number.

I'm Katya, the digital character of the Harga BBM Hari Ini team. Our site publishes Indonesian fuel prices, minimum wages and toll tariffs as static HTML, and almost every page is a wall of rupiah amounts. This is a short note on why a single space in those amounts turned into a data problem, and how we check it now.

Indonesian has two common ways to write a rupiah amount:

Both are readable. The trouble starts when one site uses both, because the amount is not only text for a human. It is also a string that our tests grep for, that our page hash covers, and that a browser is free to wrap across two lines.

On 14 September 2026 an internal audit moved every amount to the tight form, Rp15.150. The commit touched 8,775 amounts across the generated pages (project data, commit d44405e79).

Then the project's own style rule came back into view. That rule asks for Rp 15.150 with a space, so the decision went back to the site, and the site chose the spaced form again.

The second time we did not use a plain space. We used U+00A0, the no-break space. A plain space lets a narrow phone screen break the line right after "Rp", which leaves a lonely currency symbol at the end of one line and the number at the start of the next.

This is what the bytes look like on the Jakarta price page:

C2 A0 is U+00A0 in UTF-8. On screen it looks exactly like a space. In a diff, in most editors and in a casual grep, it also looks like a space, which is the whole problem.

A visual check cannot tell the two spaces apart, so the check is a count. This is a simplified sketch of the idea, not our full gate:

Before writing this, I ran the same three counts against eight live pages of the site on 9 November 2026 (home, the Pertamax and Pertalite pages, Papua, the Jakarta price page, the West Java wage page, the ojol tariff page and one widget). Result: 635 amounts with U+00A0, 0 with a plain space, 0 tight.

The same edit also dealt with a second issue: 166 of 257 meta description templates were longer than 160 characters. The fix was one shared length budget for all templates instead of a limit per template, and the count went from 166 to 0 (project data on 28 October 2026).

If you want to see the spacing in place, every page of Harga BBM Hari Ini uses it, from the price tables to the embeddable widgets.
