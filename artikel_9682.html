huggingface/transformers is the most-starred repo in the whole directory, at 169.4K. This week it added 100 stars. OpenVINO, Intel's inference toolkit, has 12.8K stars and added 1.3K, thirteen times as many. That gap says where the work is now. Most teams no longer write a model from scratch. They pick one that already exists, tune it on their own data, and then fight to make it run fast and cheap on the hardware they have.

Every repo below comes from TextMining.Tech, HackerNoon's directory of 7,075 open source text mining tools, libraries and frameworks with at least 100 stars each. They're grouped by job: define the model, train or fine-tune it, then run it.

This is part 2 of a four-part series. Part 1 covered the tools that read documents, retrieve context and teach you to build. Speech and voice come next.

These repos hold the models themselves, or the code and data that define them. transformers is the hub most of the others plug into; the rest are model families built for a language, a domain or a different way of answering.

laya added nearly three times as many stars as transformers this week, from a base a fifth the size.

Once you have a base model, these repos adapt it to your data or train new ones at scale. They range from a one-stop fine-tuning toolkit to the distributed systems behind frontier-scale training, plus two 2023-era projects that taught a generation how instruction tuning works.

halo is the smallest repo in this series so far, and it added more stars this week than anything else in this group.

A tuned model is only useful once it answers requests. These repos run models locally, compile them for phones and browsers, wire them into apps, and watch what they do in production.

The smallest repo in this group gained the most: OpenVINO's 1.3K stars this week topped the whole Natural Language Processing category.

All numbers come from the TextMining.Tech snapshot of Nov 26, 2026. The directory tracks open source GitHub repos with at least 100 stars, excludes archived repos and forks, and refreshes daily. We started from the top repos in the Language Models and Natural Language Processing categories and kept the ones that define, train or run models. "Added this week" is the directory's own weekly star count. Stars will have moved by the time you read this, so each repo name links to its live directory page.

Part 3 is speech and voice. VoiceStudio, a fully local voice cloning, dubbing and transcription suite, added 4.9K stars this week, more than all 20 repos in this list combined.
