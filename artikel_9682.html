5 Open-Source & Free Projects for Coffee Lovers — To Support Via Kivach

Tanggal: 2026-11-10

If you can’t live without a sacred cup of coffee in the morning or even if you work directly in the industry at a professional level, you may want to know that there are many open-source projects in the field. From brewing timers and roast profiling to apps that help you find great cafés, developers are creating useful tools that coffee lovers can enjoy for free.

Given that these projects are open-source, you can check their code, explore how they work, or help improve them yourself. The community is in charge, and funding also comes from the community itself. That’s why, if one of the projects below becomes one of your favorites, you can support it with Kivach. This is an Obyte-based crypto donation platform where you can send some funds to any GitHub project you want.

Now, let’s discover some interesting coffee-centered apps.

Created by Lars Saalbach back in 2017, Beanconqueror has grown into a full coffee-tracking platform for Android and iOS. Its first application version appeared that year, followed by redesigns and integrations with Bluetooth scales, pressure sensors, and espresso equipment.

The app promises to be “Everything You Need for Brewing Perfection.” You can record beans, grinders, brewing methods, grind size, dose, brewing time, first drip, water recipes, tasting notes, and ratings. It also supports V60, AeroPress, espresso, Orea, and other preparation methods, plus live graphs from compatible Bluetooth scales and pressure devices.

Like any other app in this list, it's free, and anyone can contribute via GitHub. You can also offer suggestions and ask for compatibility with new devices. As for funding, Saalbach accepts one-time or recurring support and GitHub sponsorships, giving users several ways to help keep the project going. You can send him crypto tips via Kivach, too.

This one is more of a step-by-step style. Released in 2023 by Anton Karliner, Timer.Coffee will guide you through the preparation of different types of brews, with several methods and ingredients. As the name suggests, it includes a timer for every step, but there are more features to explore on iOS, Android, and its web app.

You can find over 40 brewing recipes with at least 20 methods and variations here, a coffee-and-water calculator, custom grind settings, a favorites section, a brew diary, bean management, step alerts, device synchronization, and recipe sharing. There’s also a live view of what other users are brewing, and the app can keep the timer running even if the phone is locked. All of this is available in 22 languages.

Timer.Coffee is user-friendly and open to everyone. As such, anyone can contribute, either with code and translations or new recipes and suggestions. If you want to support the author directly, you can donate some crypto funds through Kivach.

Especially designed for coffee roasters, Artisan Scope was released in 2009 by Marko Luther and Rafael Cobo. It was initially a simple program to control coffee roasting temperature, but over the years it’s become a complete platform for creating roasting profiles, automation, and monitoring for individual and commercial use.

Artisan records, analyzes, and can control roast profiles when connected to suitable thermocouples, data loggers, PID controllers, and roasting machines. It offers support for 50+ devices and 80+ brands, a flexible interface in 30+ languages, automated reproduction of roasts, profile design, and spider charts. Additionally, it has tools for energy and CO2 tracking, reporting, inventory management, and production planning.

You can use it at any time for free, but there’s also a premium version with some extra features —particularly for companies. The software is available on GitHub, and any kind of contribution is welcome. Their funding mostly comes from community donations, which are encouraged. To send some crypto to this project, you can use Kivach.

In case you’re not exactly a professional in the industry, there are, of course, some more lighthearted options. Like this little game. Initially "attempted" by Shamus Peveril and Gavin Anderegg in 2011, Coffee Quest ended up being released by them and Chris Whalen in 2014 as part of the MindSea Hackathon. Now, you can enjoy it as a web app about business and caffeine.

The controls are extremely easy: only the direction arrows (down, up, left, right). This way, you’ll guide a businessman who needs more caffeine to keep moving forward while earning interest from banks, making sales, paying taxes, and discovering new cafes. The challenge is to not run out of caffeine (energy) while earning or even losing some money. Each new level creates a fresh 12×12 map, and the game continues until the player's caffeine runs out.

Besides the web app, Coffee Quest is available on GitHub for developers to contribute code. This is an indie project, so funding comes entirely from the authors. Crypto donations are possible via Kivach.

As the author put it, this is “a coffee shop map that isn't Google; community vetted spots only.” Created by Poorva Nangia in 2026, this app is barely starting to help users find specialty coffee shops in a few cities. It uses Next.js, Tailwind CSS, Mapbox GL, and Supabase, with a map interface for discovering a small set of real locations.

For now, you can enter this map on a web app and find community-added cafés in San Francisco (US) and the Indian cities Bombay, Delhi, and Gurgaon. Every place includes the name, rating with stars, address, coffee quality, if it’s work-friendly (WiFi, outlets, etc.), and if it’s comfortable to stay (seating and service). You can also add notes and likes or dislikes.

Users can request new cities and add new cafés, including the above data. There’s currently no listed funding method or donation program for Find My Coffee, so supporting the developer through contributions, feedback, or code may be the most direct route. To donate crypto, you can find this project on Kivach.

Donating to a GitHub project through Kivach takes just a few steps. Enter the repository name, select the network and token you want to use, specify the amount, and just confirm the donation. That’s it! You’ll need a funded crypto wallet, such as an Obyte wallet, and the developer must be notified so they can claim the contribution.

For maintainers, claiming a donation requires a free GitHub attestation with a chatbot in the Obyte wallet. This verification links the GitHub account to the person claiming the funds. After that, the donation can be collected in full or shared with other repositories, allowing maintainers to support projects they value too.
