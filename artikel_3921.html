GTA 6 PS5 Codes Potentially Being Stolen from Physical Copies Using Flashlight Trick

Tanggal: 2026-11-14

A potentially problematic manufacturing oversight may be resulting in some GTA 6 codes being stolen from retail PS5 cases.

Some reports claim that by pointing a strong flashlight at the side of the case, it’s possible to shine light into the empty Blu-ray box in such a way that it makes the code printed on the insert visible.

Remember, GTA 6’s physical release is a code-in-box, and doesn’t have a Blu-ray disc.

There is some debate about whether the included poster insert blocks the light and makes this impossible; some say they’ve been able to replicate the issue, while others say it can’t be done with a sealed copy.

It’s also worth noting that the US release specifically has a camouflaged pattern around the code, as shown by ResetEra user Mattmo831. That means you can certainly shine light into the box, but you can’t read the code on the other side.

Some PEGI units don’t have the camouflage pattern, so technically the code is visible using this trick, although again there’s still debate over whether the poster blocks the light in sealed copies.

It’s worth pointing out that codes aren’t activated at the point of purchase like other digital vouchers, so assuming the flashlight method works, it would be perfectly possible to pilfer a working copy of the game.

I think this story will explode if it turns out to be true, but it all just depends on how many PEGI copies don’t have the camouflage pattern and whether the inserted poster blocks the light or not.

As far as I can see, there aren’t an enormous number of people who’ve complained upon buying the physical version that their code has been redeemed – but if this method works, the publicity around it will now surely see the probability increase.
