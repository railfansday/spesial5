Go Without Wires: TinyGo on ESP32

Tanggal: 2026-11-25

[edited to call out the connection to TinyFlight first thing, since the YouTube title doesn't call it out]

I originally tried to submit the URL for the Github project, https://github.com/hybridgroup/tinyflight, but was thwarted by submission system.

I wanted to call attention to the project because it is very nicely documented, full of clear (to me, an intermediate gopher) examples of TinyGo code to interact with devices, handle multicore concurrency on an MCU, and build a testable design for a microcontroller application. Started off with the architecture doc and have been reading and playing happy. I really appreciate the documentation effort.

Do folks have other small-enough-to-swallow-but-big-enough-to-be-real projects that helped them move up the learning ladder?
