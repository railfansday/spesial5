A home-built Excel spreadsheet. It works like this: there's a sheet into which I paste the CSV files downloaded from the brokerage containing name of fund, number of shares, etc. Another sheet refers to that sheet using the DGET function, and assigns each investment an asset class, type of account (tax-deferred, Roth, or taxable), and owner (me, wife, joint). That sheet also pulls the share price from real time data using Excel's built-in functions. Yet another sheet keeps track of bonds and CDs because I have my own way of doing that. And another sheet calculates the asset allocation and automatically determines how much to sell or buy of each asset class. That sheet also breaks the allocation down into account type and who owns it.

Sounds complicated, but now that I'm used to it, it's easy enough. As long as we don't have any new investments, updating it is as simple as downloading a few CSV files from the brokerage and pasting them in. If there are new investments (e.g., a new ETF), though, they have to be added manually. (One could write some code to automate this but so far I haven't bothered.) If you're relatively inexperienced with Excel and want to create your own, here's a hint: the database functions are very useful (DGET and DSUM in particular) for calculating asset allocation.

The difference between DGET and VLOOKUP is that whereas VLOOKUP searches for a single value you specify in the left-most column of a range and returns the value in a different column in the same row, DGET will return a single value that is in a row that matches any number of criteria you specify. For example, let's say you have a table of values with the following columns: fund name, account owner, account type, and number of shares. You could set up a DGET function to pull out the number of shares from just the row that matches the specific fund name, account owner, and account type criteria you specify. You couldn't really get VLOOKUP to do that easily unless you first make the left most column a concatentation of fund name, account owner, and account type.

DSUM is also useful - by specifying the criteria correctly, you can easily get it to add up just specific subsets of values (for example, only the dollar amount in tax-deferred accounts belonging to owner A).
