Super Mario Party Jamboree Updated For Switch 2 And Switch (Version 2.4.0)

Tanggal: 2026-11-10

If you're a fan of Mario Party, you might be interested to hear, Nintendo has released a new update for Super Mario Party Jamboree today.

The main part of this update is that "GameShare using GameChat" is now available in the Switch 2 version of the game. This patch (Version 2.4.0) also comes loaded with some updates for the original Switch release, fixing some issues.

Here's the full rundown via Nintendo's official support page:

The following updates have been made when playing the game on Nintendo Switch 2:

The following updates have been made when playing the game on Nintendo Switch 2 and Nintendo Switch:

Mario Party Jamboree - Nintendo Switch 2 Edition + Jamboree TV arrived in July last year. It added new modes tied to the mouse controls and microphone & USB-C camera, and also included updated resolution. You can find out more about it in our review.

Nintendo has also released a system firmware update today for the Switch & Switch 2. On the new system, it adds support for an eShop gifting feature.
