Microsoft has an image problem with November's Windows security update

Tanggal: 2026-11-14

Zero-size graphics can derail printing, while some admins also face activation failures

Printing with Windows has always been something of a choose-your-own-adventure, and November's security update has added another unwelcome plot twist: documents containing certain images might not print.

The issue affects images rendered with a height or width of zero at the selected printing resolution. These might not be visible to users, but can form part of a document's watermarking or layout.

After the update, those invisible objects can apparently make the printed document disappear too. Microsoft said: "The issue was observed when printing Microsoft Word documents using the Windows Graphics Device Interface (GDI), but printing from other applications might also be affected."

According to the notification (WI1549472), most versions of Windows are affected, from the latest Windows 11 26H2 through Windows 10 Enterprise LTSC 2016. Windows Server from 2025 to 2016 is also affected.

Users need not have added these objects themselves. Microsoft says document-generation tools can insert them even when no graphic is visible.

Printer problems aren't the only issue requiring attention. After installation of the November 2026 security update, Microsoft warned that "certain Windows activation and licensing operations performed using the Software Licensing Management Tool (SLMGR) might fail."

This one is a little more niche, but it could be a headache for affected administrators. It primarily affects organizations that use command-line tools or automated processes to manage Windows activation and licensing.

"Affected devices might encounter error 0x80041008, Invalid parameter (SWbemObjectEx), when running commands to activate Windows, configure Key Management Service (KMS), or manage product keys," Microsoft said. "The failure has been observed while executing the command 'slmgr.vbs /skms-domain' and 'slmgr.vbs /ipk'."

The notice (WI1549486) currently lists Windows 11 23H2, Windows 10 22H2 and 21H2, and Windows Server 2025, 2022, and 2019 as affected.

The printing problem remains under investigation, but Microsoft says a fix for the activation issue is due in the coming days. Administrators needing an interim workaround must contact Microsoft Support for Business. ®
