Copilot without M365, and more news you didn’t hear (but maybe should have) at Microsoft Ignite

Tanggal: 2026-11-28

by Mary Jo Foley on Nov 24, 2026 at 6:44 amNovember 24, 2026 at 6:44 am

Many Microsoft business customers are still wading through the session slide decks and “Book of News” collection of product and strategy announcements from Microsoft’s Ignite confab last week. But not all the new goodies announced there (or simultaneous with this year’s Microsoft Ignite show, which kicked off Nov. 17) might have made it onto everyone’s radar.

Microsoft’s curated Ignite keynote and session spotlights were, unsurprisingly, dedicated to Microsoft AI in all its guises — Copilot, the Microsoft IQ intelligence platforms and Agent 365. But there was some other important news last week that Microsoft customers could find equally, if not more, interesting and useful.

Among my picks for the “make sure you didn’t miss this” list:

Copilot without the M365 subscription prerequisite arrives next week: Despite a LOT of talk about Copilot, “a new OS for work,” Microsoft didn’t mention anything at all during Ignite about a new purchasing option for Copilot that is set to go live on Dec. 1. Starting then, Microsoft will offer a version of Copilot to small business and enterprise customers without the current prerequisite of having a certain paid Microsoft 365 plan.

For a flat fee of $21 per user per month for small businesses and $30 per user per month for enterprise customers (before discounts), users will be able to buy this new standalone Copilot offering, as Microsoft quietly announced back in October on its Partner Center site.

Currently, to buy Copilot, business customers need to have purchased a qualifying Microsoft 365 subscription plan before they shell out even more money for Copilot. Because of this requirement, Microsoft isn’t competitive price-wise when pitted against OpenAI’s ChatGPT or Anthropic’s Claude entry-level business tiers.

The new offer is for new customers buying through any of Microsoft’s channels, including its Cloud Solution Provider program, across commercial, education, government and nonprofit sectors.

I’ve got a lot of questions about this new offer, including where Copilot chats are stored and how/if customers will get some kind of access to the Microsoft IQ technology that underlies Copilot and is positioned as its secret sauce if they don’t have a Microsoft 365 subscription. I’ve asked Microsoft, but no word back so far.

Azure Linux 4.0 is now ready for prime time: Announced on the same day Ignite kicked off (but without a mention during the conference), Microsoft’s own commercial Linux distribution, Azure Linux 4.0, is now generally available.

The 4.0 release is interesting for a few reasons. First, it is the first release of Azure Linux — formerly known as Common Base Linux (CBL)-Mariner — designed as a general-purpose server OS for customer virtual machines, and it is based on the Fedora Linux stack. Checking off the requisite AI box, Azure Linux 4.0 is “purpose-built for cloud native and AI workloads,” as Microsoft said back in May.

Microsoft officials have said two-thirds of customer cores in Azure run Linux (not Windows Server). Microsoft has acknowledged the platforms running Microsoft 365, GitHub and OpenAI’s ChatGPT “all sit on Linux foundations.”

Microsoft has supported a wide variety of Linux distributions on Azure for years but never made its own available for commercial use by customers and partners until now.

Windows Server 2028 is in the works: Yes, another on-premises version of Windows Server is coming. Christened Windows Server 2028, the next release, likely to debut in late 2027, is now in public preview.

Microsoft mentioned Server 2028 in its Book of News and in passing in some sessions, but it was not positioned as a top-tier announcement.

The 2028 release includes some expected and a few surprise features, such as making 32-bit app support an optional component rather than installing it by default. That change, along with a hardened Server Core configuration included by default, is designed to improve the security of the platform from the get-go. But they may present potential backward-compatibility risks.

Microsoft is positioning Server 2028 similarly to the way it has been pushing Windows client lately: as a way to run AI workloads more cheaply because they can run locally. The “unmetered intelligence” pitch strikes again.

Sure, Microsoft can’t make every announcement a centerpiece in a two-plus-hour (waah!) opening keynote. But sometimes, hidden gems deserve their moments in the sun. Or pouring rain …
