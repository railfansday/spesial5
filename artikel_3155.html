Apple releases tvOS 27.2.1 and HomePod 27.2.1, here’s what’s new

Tanggal: 2026-11-14

Apple has just released tvOS 27.2.1 for Apple TV 4K and HomePod 27.2.1 for HomePod models, here’s what’s new.

Two new software updates arrived today for Apple Home devices:

tvOS 27.2.1 is the latest update for Apple TV 4K. And while the version numbering might make it appear very minor, it introduces a major new feature: Siri AI support.

Siri AI arrived as part of today’s Apple TV 4K (4th gen) launch. But as confirmed by this support document, the new Siri is also now available on select older Apple TV 4K models (2nd gen and 3rd gen) via tvOS 27.2.1.

tvOS 27.2.1 also includes a variety of security fixes.

We don’t yet have details on the changes introduced in HomePod 27.2.1. Apple’s release notes only say: “This update provides bug fixes.” When HomePod mini 2 launched late last month, Apple said Siri AI would arrive via a future software update, so today’s 27.2.1 release might be that update.

However, without any prior announcement from Apple, it seems more likely that the software simply includes bug fixes and performance updates for HomePod. We’ll keep you posted on what we find.

Update: Leaker pdfu has confirmed Siri AI is not included in HomePod 27.2.1.
