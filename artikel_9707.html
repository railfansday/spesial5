all-MiniLM-L6-v2, a 23M-parameter sentence-transformers model, was downloaded 177M times on Hugging Face in the last 30 days. That's 38% of all downloads across the 213 open-weight embedding models tracked by the TextModels directory, and more than the next four models combined. Below are all 338 embedding models in the directory: open weights ranked by downloads, then hosted APIs, Ollama builds and the historical models that started it all.

Most "best embedding model" lists rank by benchmark score, like PremAI's ranking by MTEB score, cost and self-hosting. Benchmarks tell you what's best on paper. Downloads tell you what developers actually ship, and the two lists look very different.

The sentence-transformers family's lead has a history. As HackerNoon's overview of embeddings for RAG puts it, "Simply said, the BERT model isn't the best for similarity search." SBERT fixed that by embedding each sentence separately so vectors can be computed once and compared fast, and its descendants still dominate the download charts.

Everything comes from the TextModels directory's Embedding filter (338 models) as of November 11, 2026. Hugging Face entries are ranked by 30-day downloads pulled from the Hugging Face API. "Verified" means the TextModels directory fetched and confirmed that model's metrics per model. Hosted API models have no public download counts, so they're grouped by provider, alphabetically. Some hosted entries, like OpenAI's 001-series search models, are long retired. They stay in the list because people still search for them when migrating old pipelines.

These are models you call over an API instead of downloading. The list covers current models and retired ones still found in old codebases.
