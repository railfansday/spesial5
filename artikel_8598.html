That account is also the admin account mainly for convenience. Is it a best practice? No, but we're careful and I trust our Mac OS has protections in place that help keep our computer safe.
Using an admin account only when you are doing admin tasks is one of those protections. It is not just a security issue, but also protects against inadvertent changes that may break something.

It is not hard to convert to using a non-admin account— add another account, grant it admin privileges, test that a login to it is working by logging in to it, check that it shows up in the user list as an admin account, and use the new account to downgrade the current account to a non-admin account. The last step ensures that the new account has admin privileges, because that step would fail without it.
Can you give some examples of what (pragmatically) the most vulnerable areas/vectors to attack under an Administrator account? I'd honestly like to know. I sometimes run in a normal user account on Mac too, but sometimes I hit enough friction (usually because I use developer tools which often need me to install stuff with sudo into the Unix areas), that I question that decision sometimes.

My understanding is Mac Administrator is not root, and it doesn't carry nearly the power as Administrator on Windows. From what I've been able to figure out so far, the biggest difference is write permission in /Applications. But since Mac GateKeeper requires code signing for all apps from Apple, altering apps in /Applications seems an unlikely vector of attack that is going to work.

The big vector of attack I keep seeing is regular apps spying on you, and going through your user files and sniffing through your dot directories or preferences (or now web browsers downloading local AI agents on your system and can do anything on your filesystem as you). But since admin is just a group, and all your apps run under your same user, switching away from an Administrator account doesn't seem to protect you from this.

Additionally, Mac App Store sandboxing (and those few good citizen apps that voluntarily sandbox even outside the store) protects from apps arbitrarily accessing all your files/directories because it is sandboxed to only the app's specific areas. So the Administrator vs Standard User is irrelevant in this case.

So I'm trying to figure where switching to a standard user account actually protects me. I suppose it prevents me from accidentally deleting everything in /Applications without an additional password prompt, but that's not really a problem I worry about.
