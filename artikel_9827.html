Windows 11 previews remote padlock only IT can open

Tanggal: 2026-11-18

Intune feature blocks normal sign-ins without wiping data, while another test build drops Offline Maps settings

A new experimental Windows 11 build previews security features including an Intune-controlled Remote Lock, while a beta build clears away another relic from the halcyon days of Windows Phone.

The security changes include viewing and individually removing passkeys stored on FIDO2 (Fast Identity Online 2) security keys, plus a preview of the Microsoft Pluton Cryptographic Provider. For enterprise administrators, though, Remote Lock is the main attraction.

Finding a lost Windows device has been around for years, and you can also remotely wipe a device to prevent data from falling into the wrong hands. Remote Lock lets an administrator lock a managed device through Intune without wiping it. The instruction takes effect at the device's next check-in. Windows signs out of every active session, hides every sign-in option, and shows a locked screen.

The lock survives restarts and the device going offline – only an administrator can lift it remotely. Microsoft's documentation spells out the restriction: "There is no offline or local unlock. No PIN, password, local admin, or web sign-in works on a locked device; unlock arrives only through Intune."

Once the lock is applied, even stolen credentials won't restore access through the normal sign-in screen. The user's account itself is not affected; this applies only to the specific device.

Though still in preview, the feature will allow IT teams to respond non-destructively to a report of a missing device. It doesn't erase data or isolate the device from the network (Microsoft directs admins to other Intune controls if that is required).

The lock doesn't block Safe Mode, Windows Recovery Environment, or booting from external media. Microsoft advises keeping BitLocker enabled to protect the data.

Now for the beta build, where Microsoft, in time-honored fashion, gives and takes away. The latest Windows Insider build hammers another nail into the coffin of Microsoft Maps.

The Maps app was removed from the Microsoft Store and made nonfunctional in July 2025. Now Offline Maps settings are following it out, as Microsoft retires the Windows UWP Map control and Windows Maps platform APIs.

The original Maps app dates back to Windows Phone 7 and appeared on the desktop with Windows 8. It continued through subsequent versions before Microsoft stopped preinstalling it with Windows 11 version 24H2.

For those with a nostalgic streak, it's another piece of Windows Phone disappearing off the map. ®
