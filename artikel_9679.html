Why GTM's RegEx Table Silently Drops Every Row (Unless You Clear One Checkbox)

Tanggal: 2026-11-24

GA4 has no native "content group" regex UI. The standard recipe is a Google Tag Manager RegEx Table variable feeding the content_group parameter into the GA4 Configuration tag. Simple in theory - until every row lands in "Other".

If that's you, the trap is one checkbox: Full Matches Only, which ships checked by default in every new RegEx Table variable.

Variables -> New -> RegEx Table -> Advanced Settings -> uncheck Full Matches Only (and Enable Capture Groups and Replace Functionality). Leave Ignore Case checked - GTM evaluates case-insensitively by default, while GA4 itself is case-sensitive.
