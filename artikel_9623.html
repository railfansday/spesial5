The fastest-growing category in agent tooling isn't skills that do your work. It's skills that help you build the tools: MCP servers that connect an agent to your systems, plugins that package your team's workflows, hooks that enforce your rules, and new skills that teach your agent what only your team knows.

These 48 agent skills are for the builders. They come from Anthropic, Microsoft, Sentry, Cloudflare, Tech Leads Club, Jesse Vincent's Superpowers, Matteo Collina, Addy Osmani, Thomas Ricouard, Matt Pocock, Seth Hobson, Pramod Dutta and Daniel Avila's Claude Code Templates. All are MIT or Apache 2.0 licensed and packaged in Cuttlefish.MD, HackerNoon's license-checked library of SKILL.md files.

Quick refresher: an agent skill is a folder with a SKILL.md file of instructions, plus any scripts or references it needs. The agent reads each skill's short description up front and loads the full instructions only when a task calls for it. The format is an open standard at agentskills.io, so Claude Code, Codex CLI, Cursor and Gemini CLI all read the same files. HackerNoon has published a few takes on doing this well: How to Write an Agent Skill, The Right Way to Write an Agent Skill and Read This Before You Write Another Agent Skill.

For Codex, Cursor and other tools, clone the repo and copy the folders you want into your agent's skills directory.

The Model Context Protocol (MCP) is how agents talk to outside systems: your database, your ticket tracker, your internal APIs. Six skills for building and wiring up MCP servers.

By Anthropic · Apache-2.0 · Dev Workflow plugin

Anthropic's own guide to building MCP servers, and the best place to start. It runs in four phases: research and planning, implementation, review and testing, then writing evaluations. Its design advice is the useful part: balance full API coverage against task-level workflow tools, name tools with consistent prefixes like github_create_issue, return focused data with pagination, and write error messages that tell the agent what to try next. It recommends TypeScript, with Python's FastMCP as the alternative.
