Anthropomorphic Software

Tanggal: 2026-11-15

There are some programs that I like to call anthropomorphic software. These programs have copy in the first person that is personified. A distinction I would like to make is that LLMs and other conversational AI do not count. I will, however, talk about them at the end.

A familiar example is Git. Have you ever tried to create a commit on a freshly installed system? You might have encountered this error:

Quite personal for a tool whose primary use is to track mistakes.

Start a rebase while Git finds an existing rebase in progress. It also says "run me again" and "I am stopping."

In an interactive terminal, mark a revision during bisect before starting the bisect.

My favourite. During git bisect, skip enough commits that Git cannot narrow the answer further.

Adjacently, Git changelogs too are personified:

"git fsck" learned to catch NUL byte in a commit object as potential error and warn.

CI test was taught to build documentation pages.

The Elm programming language is an extreme example.

I like this effect when used sparingly, unlike Elm.

With this option enabled, sudo will insult you if you enter an incorrect password:

If you have ever attempted Linux From Scratch, you will know that Bash can say "I have no name!" in the prompt.

On September 1, running Nmap with -v makes it wish itself happy birthday.

It also wishes users a merry Christmas on December 25.

If you are aware of any more examples, I would be glad to list them here.

LLM agents are the ultimate version of anthropomorphic software. But agents do not have to sound human. I force my agents to not speak like humans for my own sanity. Agents might become the default paradigm of computer user interface in the future. I will miss anthropomorphic software then.

Most usage of this effect is purely for whimsy and isn't intended to improve the user experience. Apple's user interface guidelines prescribe avoiding error messages that contain "uh-oh!"s and "oops"es.
