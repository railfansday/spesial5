Searching for pedagogical materials on memory models

Tanggal: 2026-11-11

I'm working on some supplementary materials for a course I'm TAing, my university's version of operating systems, that involves students developing an OS targeting a Raspberry Pi 3B+. One of the topics I'm trying to get at is strong and weak memory models (and why ARM has so many weird data/instruction buffer synchronization things students have to do when writing an MMU), so if you have any excellent example articles/passages/blogs on memory models that have helped you, please comment them so I can take a look!

The classic is still relevant, and ties the semantics of memory models to why you may want to implement it that way in hardware quite effectively: https://shiftleft.com/mirrors/www.hpl.hp.com/techreports/Compaq-DEC/WRL-95-7.pdf

I also think that the writeups that rsc did when updating the Go memory model are quite well presented: https://research.swtch.com/mm

And, while I haven't rewatched it, I seem to remember this was also quite good: https://learning.acm.org/techtalks/multicore

unfortunately all the material i learned from that would be most relevant is locked behind a university login wall now :( if you'd take related things as inspiration instead:

i wrote a short blog series that is tangentially related (about mutexes, which ends up talking about memory models) while that knowledge was still fresh, with a beginner-ish audience in mind: https://wolfgirl.dev/blog/2064554/ https://wolfgirl.dev/blog/2091838/

https://faultlore.com/blah/tower-of-weakenings/ (and prior article https://faultlore.com/blah/fix-rust-pointers/) helped me understand that memory models don't just affect hardware, but legal transformations in software too

https://www.cs.umd.edu/~pugh/java/memoryModel/AlphaReordering.html and the wikipedia page https://en.wikipedia.org/wiki/Consistency_model#Relaxing_read_and_read_to_write_program_orders:_Alpha,_RMO,_and_PowerPC are full of very cursed examples of memory models, not great as introductory material tho

UNSW's Adv. Operating Systems Course has a lecture on memory models: https://cgi.cse.unsw.edu.au/~cs9242/26/lectures.shtml (Week 4 Tuesday). Wk 8 Thu/Wk9 Tue night also be relevant.

The slides and notes from the University of Cambridge's master-level course, and also slides from MPI-SWS's course.

It is beyond the scope of all existing lecture materials that I am aware of. It only appears in the ESOP paper http://arxiv.org/abs/2203.00642 and the casemate paper of EuroSys'27.
