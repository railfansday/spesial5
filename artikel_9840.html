How to Scrape Reddit Posts and Comments Without the Reddit API (with Python)

Tanggal: 2026-11-10

To scrape Reddit without the official API, read Reddit's public pages the way a logged-out visitor does: subreddit feeds, search results, user profiles and post threads. This guide shows how to do that with one API call and get posts, full comment threads, communities and users as clean JSON, with no API key, no OAuth app and no developer account.

This is part 4 of "How my fun projects turned into APIs". Each post takes one side project, explains how it works, and ends with something you can call from your own code. Part 1 covered finding TikTok creator emails, part 2 video transcripts, and part 3 recipes from cooking videos.

Reddit used to be the easiest site on the internet to get data from: add .json to a URL, or register a free API app. That changed:

After three side projects, I had a different problem: I didn't know what to build next. The best ideas usually come from people describing a real problem in their own words, and the place they do that most is Reddit. Posts like "is there a tool that...", "alternative to X" and "I'd pay for something that...".

My plan was simple: search Reddit for those phrases across a few niches, read the threads, and make a list of problems people would pay to solve. Doing that by hand took an evening per niche, and the official API route meant applying for access and waiting.

So I wrote a scraper that reads the same public pages any logged-out visitor sees. First subreddit feeds, then keyword search, then full comment threads, because the best details are always in the replies. Then I added keyword filters to cut the noise, and finally AI tags that mark each post with its pain point, whether the person asks for a recommendation, and whether they say they'd pay.

The list of ideas was useful. The scraper was more useful, so I made it a public API.

The tool is an Apify Actor called Reddit Scraper. It reads Reddit as a logged-out visitor, so it needs no login, no Reddit API key and no OAuth app.

Keyword searches can also return comments, communities and users. Every post can bring its comments, with reply depth and parent ID, so you can rebuild the whole thread.

Reddit's Data API needs an approved app, has strict rate limits, and charges for commercial use. Self-service keys were closed in 2025. Scraping public pages avoids the approval process, and you pay only for the posts and comments you collect.
