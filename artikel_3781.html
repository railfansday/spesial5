What is Captain’s Day in Fortnite Treasure Hunters? – All event changes and details explained

Tanggal: 2026-11-10

The Treasure Hunters mini-season is quite a busy time in Fortnite, with loads to discover around the island and lots of mini events unfolding on a regular basis to shake things up. One such event is Captain’s Day.

The specifics of what this event is and how it affects key aspects like drop rates and gameplay aren’t displayed, so you might be unsure what to expect from it. To help you make the most of it, here’s what Captain’s Day is and all the changes, buffs, and other key details you need to know about this special event in Fortnite.

Captain’s Day is a special, weekly event in Fortnite Treasure Hunters. For the full duration of the season, this event occurs every Sunday. This event is essentially a weekly update for Fortnite, as each run of the event brings a wave of fresh additions to the island.
