Eighteen open-licensed agent skills give an AI agent design judgment: distinctive frontends, brand-consistent themes, Figma-to-code translation, accessibility audits, SwiftUI patterns and generative art. Seven come from Anthropic, including its frontend-design skill. Nine come from Tech Leads Club, and Matt Pocock and Thomas Ricouard contribute one each.

All 18 are packaged as the Design & UI plugin in Cuttlefish.MD, HackerNoon's license-checked skills marketplace. They follow the open Agent Skills standard, so they run in Claude Code, Codex CLI and 30+ other tools, and each is indexed in HackerNoon's SKILL.md Library.

Audits and fixes accessibility against WCAG 2.1

Creates generative art in p5.js with seeded randomness and tunable parameters

Applies Anthropic's brand colors and typography; a template for encoding your own brand

Creates visual art as PNG and PDF from a design philosophy

Shared vocabulary for designing deep modules and clean interfaces

Pulls design context, variables and assets from Figma through its MCP server

Turns Figma frames into production code with 1:1 visual fidelity

Runs a design discovery process before generating any frontend code

Brings distinctive, intentional visual design to new or existing UI

Builds production-grade frontends with high design quality

Guidance on boundaries, composability and explicit contracts in modular systems

Designs new skills through a structured conversation

Creates animated GIFs sized and optimized for Slack

Example-driven patterns for SwiftUI views, navigation and modifiers

Writes technical design documents through interactive discovery

Applies ready-made or custom themes to slides, docs and pages

Builds multi-component HTML artifacts with React and Tailwind

Reviews UI code against the Web Interface Guidelines

For Codex CLI, Cursor or another agent that supports the standard, clone the repo and copy plugins/design-ui/skills/ into your agent's skills folder, such as .agents/skills/. The two frontend-design skills install under different folder names, so both can sit side by side.

Prefer pixel art? The same marketplace ships HackerNoon's own Pixel Icon Library skill: /plugin install hackernoon-originals@cuttlefish. Each skill keeps its license and an ATTRIBUTION.md naming its author and source commit. Browse the full library at hackernoon.com/skills, and star Cuttlefish.MD on GitHub.
