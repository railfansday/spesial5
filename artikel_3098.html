You can change Windows settings directly from a search now – how to try it

The latest Windows 11 Insiders Preview enhances the Search feature so that you can access specific settings right from a search window.

Microsoft has been on a kick lately trying to improve and enhance Windows 11, including sprucing up Search, which is now simpler, cleaner, and friendlier. And there’s another cool trick that Search has up its sleeve: Available in the Beta channel of the latest Windows 11 Insiders Preview, Search will give you access to specific Windows settings and commands. Known as inline actions, this latest skill is designed to help you directly complete certain tasks. That means you no longer need to know exactly where or how to find the setting you need.

Curious about built-in features such as Dark mode, Bluetooth, screen brightness, Remote Desktop, the Windows clipboard, or Windows Update? Just type the name or phrase in the Search field. The results then display an Open button that you can select to go directly to the related setting.

“A new Windows Search experience built on WinUI 3 is beginning to roll out,” Microsoft said on a web page announcing the latest Insiders build. “It’s faster, more efficient, and features a streamlined design that makes results easier to scan. Inline actions let you quickly complete tasks directly. Turn on dark mode or Bluetooth, adjust your screen brightness, mute your device, or arrange windows from Windows Search.”

I tried this with several different Windows settings, and the results window pointed me to the right screens for tweaking them. Though I know where most Windows settings are located by now, there are still times when I forget how to reach certain ones. This new skill promises to be a time saver whenever I face that challenge.

Here’s another handy enhancement. How often do you type a word or term in Windows Search only to misspell it? With the latest update, Search will now better understand what you actually mean and match you with the correct results. Type “drak” instead of “dark,” for example, and you’ll still see the results for Dark mode.

Microsoft promises these latest improvements to Windows Search will continue to be fine-tuned over the next few weeks. And there’s more in the new Preview build.

Ever run into trouble using Windows Hello facial recognition in a dark area? Now, your screen will temporarily brighten up to help you sign in under those conditions. To enable this option, head to Settings, select Account, select Sign-in options, and then click Facial recognition. Turn on the switch for “Automatically adjust screen brightness during face recognition.”

The latest Insiders build also tweaks features such as Live captions, Gaming, File Explorer, and Microsoft 365 cloud storage.

To grab this update, you’ll have to join the Windows Insiders Program if you’re not already registered. You can then sign up for the Beta or Experimental channel, either of which will give you access to the new Search skills and other features. Make sure you’re running the Beta Preview Build 26320.9876 or higher. To check, go to Settings, select System, and then click About. The Windows Info section will indicate the build number.

As for regular Windows users not enrolled in the Insiders Program, the new changes should reach you relatively soon. I’d expect them to roll out with the December Patch Tuesday update arriving on December 8, so that Microsoft can squeeze them in before the end of the year.
