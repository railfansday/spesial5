MemTensor Releases and Open-Sources MemT-1.0-Pro, a 554B Memory-Native Model

Tanggal: 2026-11-24

SAN FRANCISCO, Nov. 23, 2026 /PRNewswire/ -- MemTensor today released and open-sourced MemT-1.0-Pro, a memory-native model jointly developed with NVIDIA.

Built on NVIDIA Nemotron 3 Ultra and trained using NVIDIA's Megatron-Core and Megatron Bridge distributed training infrastructure, MemT-1.0-Pro extends MemTensor's memory-native approach to 554 billion total parameters, with 59 billion active parameters. Following Nano and Flash, the release advances this exploration on a new backbone and at a larger model scale.

MemT-1.0-Pro integrates memory into model computation, making the storage, updating and retrieval of historical information capabilities that can be learned through training.

The collaboration with NVIDIA included model adaptation, operator optimization, training-method discussions and experimental review.

Extending MemTensor's Memory-Native Approach to Nemotron

MemT-1.0-Pro uses NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16 as its backbone. Its architecture combines dynamic local memory, which stores information acquired during interaction, with trainable hyper-memory components that learn how to write and read that information.

During online interaction, the backbone and trained memory-processing weights remain fixed. The model accesses historical information through dynamic memory states, without requiring the original historical text to remain in the query context. After each completed interaction, a storage procedure updates those states using a stabilized token-level mechanism based on Gated DeltaNet-2.

Continued pre-training establishes language modeling capabilities that use native memory. Post-training then uses distillation from a full-context teacher to improve memory-based responses.

Measurable Progress in Long-History Memory

In the technical report, MemT-1.0-Pro scores 41.80 on BEAM-1M, compared with 37.04 for MemT-1.0-Flash, an improvement of 4.76 points. On MemoryAgentBench, its score rises to 23.87 from 17.36, a gain of 6.51 points.

BEAM-1M evaluates ten long-history memory abilities, including information extraction, contradiction resolution, updating, preference following and temporal reasoning. MemoryAgentBench evaluates retrieval, test-time learning, long-range understanding and selective forgetting.

Pro also achieves an average score of 53.08 across 11 memory benchmarks, the highest among the parametric-memory methods evaluated in the report.

These results demonstrate progress within the MemT family, although Flash and Pro use different backbones and configurations, and improvements vary across benchmarks. Strong textual-memory systems remain ahead on some evaluations.

Toward Agents That Can Use Their Experience

For agents supporting extended workflows, useful memory involves more than recalling isolated facts. Following an ongoing project or service request may require retaining earlier requirements, recognizing updated decisions and applying information accumulated across multiple interactions.

These needs motivate MemTensor's exploration of native memory for persistent agent workflows. Further application testing will be needed to establish how the benchmark gains translate into end-to-end task performance.

Fixed-size memory introduces trade-offs between preserving earlier details and incorporating new information. Improving memory fidelity, selective retention and query-dependent readout remains central to further research.

Developers and researchers are welcome to explore MemT-1.0-Pro on Hugging Face.
