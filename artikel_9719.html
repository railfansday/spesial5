A free stock news API with sentiment and topic tags (no API key)

Tanggal: 2026-11-22

Most "stock news API" tutorials start the same way: sign up, verify your email, paste a key into an env var, then find out the free tier gives you 100 calls a day. For a side project — a watchlist digest, a Discord bot, a dashboard widget — that's a lot of ceremony.

I run Quotelinks, a free stock research site, and I built a small news API for it that skips all of that: plain JSON over HTTPS, no key, CORS enabled. This post shows what it returns and three small things you can build with it.

It's for personal, non-commercial use, and it returns headlines and links, not article text. Full docs and a live preview: Quotelinks Stock News API.

Duplicate stories from several feeds appear once, and templated junk (law-firm solicitations, promotional press releases) is filtered out before it gets to you.

There are no server-side filters for date, topic or sentiment. You get the list and filter it yourself, which is what the examples below do.

Fetch a few tickers, drop anything older than 24 hours, deduplicate by id, and group by topic. Standard library only.

Run it from cron at 7 a.m. and pipe it into an email, and you have a free news digest.

Responses are cached for up to five minutes, so polling more often than that just returns the same data. Poll every five minutes and use id to show only new headlines:

The same news shows up on the site — for example the NVIDIA news page and the market-wide news feed — next to quotes and charts on each stock page like NVDA.

The Stock News API docs have the full field reference, the tag list, a live preview where you can type a ticker and see the cards, and PHP examples. The other free APIs (SEC fundamentals, exchange rates, credit market data) are on the Quotelinks API page.

Feedback is welcome — especially headlines that got the wrong tag or a sentiment label that's clearly off. It's in beta and that's exactly what I'm tuning.
