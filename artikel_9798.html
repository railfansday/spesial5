Building an Image-Wash Pipeline: Gemini Vision Analysis, Detail LoRA and 2K Output

Tanggal: 2026-11-16

Posted on Nov 16 • Originally published at huggingface.co

"Wash" is the local term for a specific operation: take an image, analyse what is actually in it, then re-render it at higher quality without changing the content. Done badly it is just an upscale. Done well it recovers detail the source never had.

This episode builds that pipeline with Qwen Image 2.1 and documents fifteen test sets.

1. Vision analysis (Gemini). The source image is described in structured terms — subject, composition, materials, lighting. This is not captioning for a human; it is producing a specification the generator can follow.

The quality of this stage bounds everything after it. A vague description produces a generic re-render.

2. Qwen Image 2.1 re-render with Detail LoRA. The image is regenerated from the specification at target resolution. The Detail LoRA is what makes the re-render add structure rather than just resolution — it biases the model toward plausible fine detail (fabric weave, surface texture) instead of smooth gradients.

3. 2K output. The final upscale. Done last, because upscaling before the re-render means the model works from interpolated pixels rather than from the specification.
