Calculate construction progress draws and retainage in TypeScript

Tanggal: 2026-11-27

A subcontractor installs $6,000 of electrical materials that appeared on the last draw as stored stock. Move the $6,000 from stored to installed work. That transfer alone adds zero to the gross earned amount. It can still change the net amount when the contract holds different percentages on work and stored materials. In the example below, two schedule-of-values lines roll up to $17,850 due on the current draw.

Each line carries the approved scheduled value, prior installed work, and materials still stored from the previous application. This period adds newly performed work, transfers stock into installed work, and records newly stored materials. In the electrical line, the transfer brings stored stock from $10,000 down to $4,000 before $2,000 of new stock arrives. The current stored balance is $6,000.

The sample uses 10% retainage on work and 5% on stored materials. It rounds each retainage amount per line, half up, and adds the rounded amounts for the cover total. The current request is cumulative earned less cumulative retainage and prior certified net. Use the prior certificate number and amount as inputs so a delayed cash receipt does not change the next request. Confirm the contract's rounding, rate, and release rules before using the math in a draw. AIA subcontractor payment application · Continuation sheet

Save the block as draw.mts and run node draw.mts with Node.js 24. The assertions cover the stock transfer, rounding, overbilling, and the prior certificate reconciliation. Node.js TypeScript documentation
