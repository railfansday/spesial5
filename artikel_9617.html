Reconcile consignment splits and post-payout returns in TypeScript

Tanggal: 2026-11-27

A booth item sells for $100.01 under a 60/40 agreement. The consignor receives $60.01 and the shop keeps $40.00. After payout, the customer returns $25.01 of the sale. The next statement posts a $15.01 debit against the consignor's $12.00 in new earnings. That run pays $0 and carries a $3.01 debit forward.

Use the original sale line as the settlement record. The POS adapter supplies the amount eligible for splitting after it applies the agreement's rules for tax, fees, and discounts. This example rounds the consignor's share half up and gives the shop the residual cent. The two shares always add to the eligible amount.

A return inherits the original sale's allocations. Compute the consignor's cumulative reversal from the original allocation and the cumulative refunded cents. Subtract the already reversed amount to get the new debit, then assign the remainder of this refund to the shop. For a three-cent sale that paid two cents to the consignor, three successive one-cent refunds reverse one cent, zero cents, and one cent. The final return closes both shares exactly.

Freeze settled statements and emit a new row keyed by return ID. The sample policy offsets the debit against the same consignor's future earnings. It pays out positive balances and carries a negative balance into the next period. The refund to the customer is separate from the settlement entries shown here.

Save the block as settlement.mts and run node settlement.mts with Node.js 24. The output shows the original payout, the first open run after the return, and the run that clears the debit. Node.js TypeScript documentation

In a database-backed POS, make return IDs unique per source and store the return entry and cumulative refunded amount in the same transaction. Assign each ledger entry to one completed settlement so a retried export reads the same statement. The per-consignor PDF and XLSX should show the opening carry, itemized activity, payout, and closing carry from that settlement. ConsignPack
