WhatsApp announces travel eSIMs, tests view-once texts and a cleaner interface

Tanggal: 2026-11-28

In addition to officially announcing support for in-app travel eSIM purchases, WhatsApp is now reportedly testing two new features on iOS. Here are the details.

WhatsApp yesterday announced that iPhone and Android users will soon be able to purchase and install travel eSIMs directly from the app.

According to the company, the feature will allow users to get a mobile data plan for international travel with just a few taps, without having to leave WhatsApp, while continuing to use the messaging service with their existing phone number.

To make this possible, we’re working with e-SIM providers and telco partners including Jio, Smart Axiata, Smart Communications, Verizon and others, and we’ll begin rolling this out in select countries soon. You’ll see it right in the app when it’s available for you.

Additionally, WABetaInfo reported this week that users running WhatsApp’s TestFlight beta are starting to see the option to send view-once text messages, extending a feature that is already available for photos, videos, and voice messages.

WABetaInfo noted that after long-pressing the send button, users who have access to the new feature can select between scheduling the message and sending it as a view-once message.

Recipients can then tap the message to read it in a separate interface, with WhatsApp blocking screenshots, screen recordings, copying, and forwarding. Once the recipient closes the message, neither party can access its contents again.

In another test rolling out to iPhone beta users, WhatsApp is making a slight change to the app’s tab bar, removing the text labels that appear below each icon while preserving its existing Liquid Glass design.

With the latest update, the text labels within the tab bar are no longer visible. The tab bar now shows icons for Updates, Calls, Contacts, Chats, and You without any labels. This makes the tab bar more compact since the app no longer needs to reserve more space for its labels. WhatsApp makes icons with the tab bar clear and recognizable, so users can still identify every tab immediately.

As is usually the case with WhatsApp beta features, there is no telling when (or if) these two changes will make their way to the public version of the app.
