I built a small daily digest of trending GitHub repos. I'd love your feedback

Tanggal: 2026-11-04

I check GitHub Trending most mornings, and I kept losing track of what I'd seen the day before. So I started a small side project to keep a dated record for myself: Northline Signal.

It's a solo project and still pretty rough. I'm posting here mostly to learn from people who follow open source more closely than I do.

Each day gets its own page with the repos that were trending that morning. Today's page, for example, is November 4, 2026. It has 13 projects, from thedotmack/claude-mem to vercel-labs/agent-desktop and floci-io/floci.

Every project also has its own page, like vercel-labs/agent-desktop. That page has the main language, a link to the repo, the dates it showed up, and a short note on what a developer might actually take from it. There's also an Explore page where you can search across past days and filter by category or language, which helps when you're trying to find "that Rust CLI from last week".

There's also a Chinese version, since a lot of my friends read in Chinese.

No database, no server. The content is just files in the repo, so adding a new day means pushing a new JSON file.

If you have a minute to look around, I'd be grateful for any thoughts, especially:

I'm sure there are better ways to do parts of this, and I'd like to hear about them. Thanks for reading.
