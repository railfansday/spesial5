Nier Automata’s File Size Now Reflects How Good It Is

Tanggal: 2026-11-09

Nier Automata is my favorite game of all time, and I've been telling everyone I know to play it for nearly a decade. On PC, however, Square Enix accidentally made that a little bit more difficult, because the game's latest patch ballooned the game's file size by more than 600%.

The update, tested by RPG Site, takes what was a pretty reasonable 50GB file size and raises it to 366GB. It appears to be incorrectly assigning a file size of more than 40GB to each piece of DLC. The patch itself was supposed to simply add three new languages to the Steam version: Simplified Chinese, Traditional Chinese, and Korean.

"We are currently investigating the cause and working to resolve the issue. We apologize for the inconvenience," Square Enix said in a post on Steam.

Because the giant file size is linked to the different pieces of DLC, you can temporarily resolve the issue by going to "Properties" and "DLC" on Steam and unselecting them. Of course, this also means you won't be able to enjoy that DLC, so if you mostly want to fight the former CEO of Square Enix in the game, you're going to have to wait.

As for what's next for the Nier series, Square Enix and director Yoko Taro have been pretty hush-hush, but Automata has been an immense success. As of February 2026, it had sold more than 10 million units. An anime adaptation is also available now on Crunchyroll.
