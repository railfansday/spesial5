Microsoft Outlook experiencing widespread outage

Tanggal: 2026-11-13

Everybody’s working for the weekend, but Microsoft Outlook clocked out early. The mission-critical email service is facing a widespread outage.

The outage appears to have started about an hour ago. Based on status checks with the service, the issue is widespread and ongoing.

Downdetector reports over a hundred thousand Outlook outage reports today.

If you’re having trouble with Microsoft Outage, err.. Outlook, you’re not alone.

Usually you can check the latest Outlook outage status here, although it appears to maybe be down as well.

Update: Here’s a status update from Microsoft:

We’re aggressively pursuing all pathways to reduce impact. As a precaution, we’ve paused all deployments and configuration changes while we review recent changes for any correlation to this event. We’ve determined that the elevated load isn’t driven by an overall increase in traffic, but by a large number of servers being unexpectedly unavailable, which is shifting load onto the remaining infrastructure. We’re investigating what’s causing these servers to become unavailable while we work to safely return them to service.
