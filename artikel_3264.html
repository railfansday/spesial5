WhatsApp’s AI-powered photo expansion tool starts rolling out on iOS

Tanggal: 2026-11-06

Select WhatsApp users on TestFlight and in the main app are now seeing the option to expand an image in the app’s photo editor. Here are the details.

iPhone users with access to Apple Intelligence have a native AI-powered photo expansion tool called Extend, which lets users pinch or drag to expand an image beyond its original borders.

This feature, which is also present on AI chatbots such as ChatGPT and image-editing platforms like Photoshop, is now also making its way into WhatsApp.

According to WABetaInfo, the platform is rolling out a Meta AI-powered image expansion tool, though it is currently limited to select users, primarily those in WhatsApp’s beta program via TestFlight.

When users select a photo in their chats, WhatsApp opens the drawing editor. Here, they can choose to apply some AI effect to improve it. Among these, users can find a new option to expand their photos. Once users select this option, Meta AI takes a few seconds to analyze the photo and generate the expanded version. Once the process is complete, WhatsApp shows the expanded photo in the drawing editor, and users can choose to send it. Note that this feature is also compatible with status updates.

The site notes that if the user isn’t happy with the result, they can tap an undo button to revert to the original and then try using the tool again to generate a different result.

As is usually the case with beta features on WhatsApp, there is no telling when it might become widely available.

That said, given that it has also rolled out to users in the Android beta and some users on the public iOS version already have access, a broader rollout might not be too far off.
