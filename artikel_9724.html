Introducing Dioptra: A Zero-Config, Pure-Go Interactive UI Engine for AI Agents

Tanggal: 2026-11-22

Hey everyone! I'm Bryan, a software engineer. Over the past few months, I've been reflecting a lot on where our profession is heading and how our daily workflows are evolving alongside AI. Because I genuinely love software engineering and building for builders, I started creating open-source tools to give back to the community—and today, I'd love to share my latest contribution with you.

Meet Dioptra: a local-first, zero-config interactive reporting and UI engine built for developers and AI agents.

Tired of reading raw Markdown walls, ehh 😏? A fast single-binary Go MCP viewer that turns AI agent outputs into slick local UI reports & clickable approvals.

A fast, local, single-binary technical report viewer and MCP server for AI coding agents — written in pure Go, with zero API keys and near-zero token overhead.

AI coding agents (Claude Code, Cursor, Codex, OpenCode, Antigravity, Gentle Shell, etc.) generate rich audits, architecture plans, code reviews, diffs, and postmortems that get buried in terminal scrollback. Dioptra moves those long deliverables out of the terminal into an interactive local web workspace (http://127.0.0.1:7474) backed by SQLite FTS5, live SSE updates, bidirectional human-in-the-loop checklists, a multi-role agent board, and an E2E test observer.

When working with CLI coding agents or automated workflows, reading massive walls of terminal Markdown or managing human-in-the-loop approvals quickly gets messy. Dioptra solves this by turning standard Markdown into rich, interactive local dashboards in milliseconds—with zero external dependencies or API keys required.

Dioptra is completely open-source and MIT licensed. If you work with MCP agents, CLI tools, or local automation workflows, I'd love for you to give it a spin:

Repository: github.com/JbryanH187/Dioptra

Feedback, ideas, issues, and stars are hugely appreciated. Let me know in the comments what you think or what kind of workflows you'd plug this into!
