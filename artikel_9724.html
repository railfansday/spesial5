Qwen4-Max costs about 7x less than GPT-6.2 Astra per agent run: a two-tier router

Tanggal: 2026-11-22

Posted on Nov 22 • Originally published at tokenlean.wordpress.com

TL;DR: Alibaba's Qwen4-Max (Nov 16, 2026) lists at $1.50 input, $4.50 output and $0.075 cached input per 1M tokens in the Singapore region. The same 40-step coding-agent run that costs about $2.72 on GPT-6.2 Astra costs about $0.39 on Qwen4-Max. The smart move is not to switch everything, but to route the easy steps to the cheap model.

Source: DataStudios weekly API price roundup, which checked the vendors' pricing pages on Nov 20. Confirm on the vendors' own pages before budgeting. Qwen4-Max also has a 1M-token free quota for 90 days, and global-region prices differ slightly.

Assumptions: each step resends a 30K-token cached prefix, adds 2K fresh input tokens and produces 1K output tokens.

About 7x cheaper. Cheaper does not mean equal quality: use it where mistakes are cheap (file search, summaries, formatting, test triage) and keep the expensive model for planning and final review.

Keep the system prompt and tool definitions first and unchanged on each model so caching keeps hitting.
