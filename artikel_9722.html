I built a plugin system for a local-first desktop AI agent — here's what small teams actually automate with it

Tanggal: 2026-11-22

Hi DEV — I'm Peijian Xu, CTO of the aiFetchly team. This is a #showdev post about something we've been building in the open: aiFetchly, an open-source, local-first desktop AI agent for business automation.

Small teams don't lack AI models. They lack a place where an agent can safely use their own business context: past emails, client notes, product docs, and the small tools they already rely on — without sending that context to a shared cloud service by default.

So we built aiFetchly as a desktop app that runs on your own machine, with a local knowledge base (private memory) at its core. Research, document processing, drafting and replying to emails, writing client emails, and scheduled workflows run against knowledge that stays local.

Every small team automates something slightly different. A generic agent prompt isn't enough, so we made the agent extensible:

The point isn't to replace a developer or a support person. It's to take the repetitive middle of a task — gathering context, drafting, checking documents — and hand a person a solid starting point.

This short demo shows the local knowledge base / private memory idea in practice:

In our own use, the pattern is usually: local documents + a plugin for the team's workflow + a scheduled run, then a human reviews the output before anything is sent.

aiFetchly has a Community plan that is free, and paid plans for teams that need more: Go at $5/month, Plus at $10/month, and Pro at $30/month. The AI Content Assistant is a Plus-only feature. The project is open source, so you can inspect how the desktop agent, plugins, and local knowledge base work.
