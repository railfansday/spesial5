Apple releases iPadOS 27.3 public beta and more, here’s what’s new

Tanggal: 2026-11-05

Public beta testers, Apple is now rolling out the first public betas for iPadOS 27.3, tvOS 27.3, and more. Here’s what‘s new.

If you’re part of Apple’s public beta software program (join free at beta.apple.com), your devices will have new updates available to install today.

Apple has just shipped public beta 1 for iPadOS 27.3, tvOS 27.3, HomePod 27.3, and more.

Today’s software releases are the exact same builds that first debuted for developers earlier this week. That means we already know exactly which new features and changes are included.

Notably in watchOS 27.3, Apple adds support for the Siri Recap and Live Rewind features that previously were announced for Apple Watch Series 12 and Ultra 4.

If you’re new to beta software, be aware that Apple’s betas tend to include more bugs and performance issues than its public releases. Those tend to be especially prominent in early betas like this one.
