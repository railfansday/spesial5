Correction to: Nature https://doi.org/10.1038/s41586-026-11162-7Published online 14 October 2026

In the version of the article initially published, in Table 1, the number of BAT– patients with BMI < 25 was “8,826” but should have been “8,626”. In Fig. 2f, “β = 0.077” should have read “β = –0.077”. In the Fig. 2c legend, “(n = 2,680 per tertile)” should have read “(n = 2,903 per tertile)”. In Extended Data Fig. 1c and e, the minus sign was missing from both correlation coefficients and has now been added. In the caption for Fig. j–l, “losartan-treated mice (n = 7) and controls (n = 5)” should have been “losartan-treated mice (n = 5) and controls (n = 7)”. In the Extended Data Fig. 9 legend, “All p values except (g) obtained using unpaired, two tailed t-test” should have been “All p values except (b,g) obtained using unpaired, two tailed t-test”; in the description of panel c, “circles represent mean EE per time point” should have been “circles represent mean RER per time point”; and in the description of panels d–f,h, “Left graph shows representative 24-h period (circles represent mean EE per time point” should have been “Left graph shows representative 24-h period (circles represent mean values per time point”. In the Extended Data Fig. 10 legend, “All p values in this figure obtained using unpaired two tailed t-test” should have been “All p values except (b) obtained using unpaired, two-tailed t-test”; in the description of panel c, “circles represent mean EE per time point” should have been “circles represent mean RER per time point”; and in the description of panels d–f, “Left graph shows representative 24-h period (circles represent mean EE per time point” should have been “Left graph shows representative 24-h period (circles represent mean values per time point”. These mistakes were due to typographical errors introduced during generation of the figure legends and the table; the statistics displayed in the figures and table were carried out using the correct numbers. Thus, the validity of the results and conclusions is unaffected. These corrections have been made to the HTML and PDF versions of the article.
