AntSeed is a peer-to-peer market for AI inference that lets an always-on agent like OpenClaw or Hermes send every model call to the cheapest verified provider on the network. Instead of one company setting the price, independent providers list the same open models at their own prices, and a local proxy sends each request to the cheapest provider that meets the buyer's minimum trust score. AntSeed's own calculation for a coding agent's month of usage puts Claude Opus 5.5 at 93% below list price on its network and Claude Sonnet 5.5 at 89% below, based on advertised prices in mid-November 2026. For an agent that makes hundreds of calls a day, that difference compounds, which is why the model layer decides the cheapest way to run an AI agent 24/7.

Verdict: AntSeed is built for OpenClaw and Hermes users who run open models around the clock and want the model bill to fall through price competition. It asks for a little more setup than a hosted API, and it rewards that setup on every call.

AntSeed is a peer-to-peer network for AI services. Providers announce their models and prices on a distributed hash table, the same kind of discovery system BitTorrent uses. Buyers run a local endpoint that finds those providers and sends requests to them over encrypted peer-to-peer connections. There is no central aggregator between buyer and provider.

AntSeed says the network offers more than 700 models, and its live count in mid-November 2026 was 703 models from 95 providers, including image and video models. The Antseed Foundation has raised $2.4M in a token round led by Spark Capital, with participation from Collider, DCG, North Island Ventures, Reciprocal Ventures, Relayer Capital, and Venice.ai.

The network is in real use. According to AntSeed's on-chain figures, it averaged about 31.7 billion tokens and 434,000 requests a day from 9 to 15 November 2026. In the 30 days to 15 November, 692 paying wallets paid about $76,800 to 104 different providers over that period. AntSeed notes that paid token counts are a lower bound, because they only include usage that buyers report on-chain.

Routing is the reason AntSeed suits a 24/7 agent. According to AntSeed's documentation, the local proxy sends each request to the cheapest provider that meets the buyer's minimum trust score (60 out of 100 by default), unless the buyer pins a specific provider. Providers that are cooling down or have recently failed are moved down the list, so another provider takes the request.

For an always-on agent, this changes the cost model. A single-provider API charges one price for every call. On AntSeed, every call is a fresh choice among competing providers, so the agent pays the lowest price available at that moment for the model it asked for.

The local endpoint speaks both the OpenAI and Anthropic APIs, so an agent connects to it the way it would connect to any compatible provider. The setup has four steps, followed by AntSeed's recommended gateway option.

Install the AntSeed command-line tool on the agent's machine with npm install -g @antseed/cli, which needs Node.js 20 or later. AntSeed also publishes an agent-readable setup skill, so an agent can follow the installation steps itself. On a personal computer, the AntSeed desktop app runs the same local endpoint.

Running antseed buyer start launches the local buyer proxy at http://127.0.0.1:8377/v1, which works only on the same machine as the agent. If your agent runs on a VPS, install AntSeed on the same server so the agent can reach the endpoint on localhost.

For any OpenAI-compatible agent, set the base URL to the local endpoint and use the placeholder API key antseed-p2p, since the local endpoint does not validate one.

For OpenClaw, AntSeed's integration guide adds the antseed provider to ~/.openclaw/openclaw.json, after which a model can be selected with a command such as openclaw models set "antseed/kimi-k2.6", followed by openclaw gateway restart.

For Hermes, AntSeed is registered as a custom provider in ~/.hermes/config.yaml following AntSeed's Hermes integration guide, then Hermes is restarted to load it.

Providers are always paid per request in USDC on Base. The command-line proxy is funded with USDC only, and antseed buyer deposit shows the funding address. The gateway and the desktop app also take card top-ups of $1 to $200 where available, and no AntSeed account is needed for either.

AntSeed now recommends the gateway for agents. Run antseed gateway service install, then antseed gateway key create --label openclaw, and point the agent at http://localhost:8379/v1. Each agent gets its own key and budget. For OpenClaw without funds, the model antseed/@preset/openclaw tries free providers first. Some providers offer free models.

AntSeed has no subscription. The agent pays per request, at the price of the provider that serves it. The total depends on which models the agent uses and how many calls it makes.

Live prices are listed on AntSeedStats, an independent tracker that lists network prices for each model next to its official API price. AntSeed's own calculation for a coding agent's month of 22 million input and 5.5 million output tokens shows the gap:

Across 192 models with a published list price, AntSeedStats showed a median saving of 52% on 12 November 2026. AntSeed's figures use advertised prices and the cheapest provider that passes its default trust minimum, so they are not measured per request. Prices move as providers join and compete, so check the live rates before estimating a budget.

For a 24/7 agent, the per-call saving matters most on background traffic. OpenClaw's default heartbeat runs every 30 minutes, which is 48 model calls a day before the agent does any real work. Each of those calls goes to the cheapest qualifying provider.

It turns price into competition. The same open model can be served by several providers, and the agent pays the lowest qualifying price on each request rather than a fixed list price.

It keeps the agent unchanged. OpenClaw and Hermes keep their configuration, memory and tools. Only the model endpoint changes, and switching back is a matter of pointing the agent at a different base URL.

It adds resilience. Because many providers serve the same model, a provider that fails does not stop the agent. The proxy moves on to another one.

It scales with the network. As more providers join, the price competition for popular models increases.

AntSeed runs locally. The endpoint has to run next to the agent, which is one more process to keep alive on the server. A hosted aggregator such as OpenRouter needs nothing running on your machine.

Prices vary by provider and over time. That is the point of the market, but it means the cost of a given model is a live figure, not a fixed list price.

The model range depends on providers. Popular open models are well covered, while a niche model may have few sellers or none.

The same network also serves teams building AI apps. AntSeed's gateway for apps sits in front of an existing OpenAI- or Anthropic-based app through the Chat Completions, Responses and Messages APIs, so switching means changing the API address, key and model rather than rewriting code. It can run on a developer's computer or on a server.

What the gateway adds is control. Each app gets its own key, and spending limits can be set per key, per team member or per workspace, by day, week, month or lifetime. Keys can allow only certain models, allow or block certain providers, and cap the price per million input, output and cached input tokens, as well as the price per image. Provider ranking and fallback rules are configurable too. With automatic routing, a request that fails with a retryable error can move to another provider before streaming starts. Balances can be topped up by card or USDC, with no AntSeed account needed. For a 24/7 agent that has become part of a product, such as a support agent, this is the layer that shows what each app costs and stops one runaway app from draining the budget for the rest.

AntSeed is the strongest choice for builders running OpenClaw, Hermes or another OpenAI-compatible agent around the clock on open models, who want the lowest per-request price and are comfortable running one local endpoint. Teams shipping AI apps can put the same network behind each app through the gateway, with a key and a budget for every app.

It is less suited to someone who wants a single hosted API key with nothing to install, or who needs a model that few providers serve.

Host the agent on a low-cost or free server and keep the model bill down, since it is usually the bigger cost. Running open models through AntSeed sends each call to the cheapest verified provider on the network. Routing heartbeats to a small or free model and lengthening the heartbeat interval cuts background spend further.
