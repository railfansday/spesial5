Real-Time chat system on a Raspberry Pi

Tanggal: 2026-11-12

🚀 Built my own self-hosted real-time chat system on a Raspberry Pi

I recently deployed a real-time chat application running on my Raspberry Pi using Node.js.

The system includes: • Real-time messaging (WebSockets) • Admin panel for moderation • Process management with PM2 (keeps it running 24/7) • Auto-start on reboot using systemd • Public access via secure tunneling (no port forwarding required)

💬 How people can join the chat: Anyone can access the live chat through this link: Link

Once inside, users can instantly join the room and start chatting in real time. The admin system ensures the environment stays safe and respectful for everyone.

This project helped me understand: • Backend development with Node.js • Linux server management • Hosting and deployment workflows • Real-time networking systems

Still improving it, but it’s already live and functional. If you want to create the same checkout my GitHub page 👉 My Github: Link
