AI found a critical flaw in Java that could let hackers hijack enterprise servers

Tanggal: 2026-11-18

Free daily briefing on global business news.

Oracle included a fix in its November update on Tuesday, and CISA urged organizations to patch immediately; Calif rated the flaw 9.2 out of 10

Security firm Calif disclosed a critical flaw in OpenJDK, the most popular Java runtime, that it says lets an attacker with no credentials overwrite memory and run code on a server. Oracle $ORCL included a fix for the flaw in its November Critical Security Patch Update, which it released Tuesday.

The flaw carries the identifier CVE-2026-114938 and the nickname Java4Shell. It sits in OpenJDK's Base64 decoder, which Calif said uses specialized x86-64 processor instructions to decode data faster. Calif said researcher Quang Luong found the bug in an hour using the AI tool Codex and built the first working exploit in two more hours. The total token cost was less than $200, the firm said.

Java4Shell affects OpenJDK 17.0.6 and newer, Calif said. Distributions built from OpenJDK are also vulnerable, including Amazon $AMZN Corretto, Eclipse Temurin, Microsoft $MSFT Build of OpenJDK and Oracle Java SE. The bug requires an x86-64 processor with AVX-512 VBMI support. ARM64 chips are not affected.

Calif said it demonstrated remote code execution without authentication in Keycloak, Atlassian $TEAM Jira, Atlassian Confluence, JFrog Artifactory, Jenkins and PingFederate. It showed execution that requires a login in Apache Kafka Broker, Apache Solr, Elasticsearch, Gerrit and Spinnaker. The firm said no single exploit works everywhere, and every target demands its own custom approach.

Calif published a proof of concept that triggers the memory corruption. It is not yet releasing product-specific exploits, in order to give users a window to upgrade.

Calif scored the flaw 9.2 on a 10-point scale under CVSS 4.0, calling it critical. Oracle's advisory scores it 8.1 under CVSS 3.1 and lists the attack complexity as high.

The Cybersecurity and Infrastructure Security Agency urged organizations to patch immediately, starting with internet-facing systems. For those that cannot, the agency recommended restricting and validating Base64 input, enforcing input-size limits and limiting unauthenticated access. Calif recommends launching OpenJDK with the -XX:-UseBASE64Intrinsics option as a temporary measure, according to BleepingComputer.

There were no reports of the flaw being exploited in the wild by Tuesday evening, according to CyberScoop.

The Java disclosure follows an AI-assisted discovery of two bugs in PHP, software that runs an estimated 70% of all websites. Sites including 4chan, DeviantArt and the Internet Archive went offline for hours or days after a fix was released. Hackers made millions of attempts in the first day but largely failed because the flaws were difficult to exploit.

Calif said in its write-up that it also used AI to find and weaponize a flaw it calls PHP2Shell.
