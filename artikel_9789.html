MDEdit – fast, minimal WYSIWYG Markdown editor

Tanggal: 2026-11-04

MDEdit is a fast, minimal WYSIWYG Markdown editor written in Rust with egui. It works like Obsidian's live preview: markers are hidden everywhere except on the line with the cursor, so # Title becomes a heading as soon as you move away from it.

examples/example.md (English) and examples/przyklad.md (Polish) show every supported element.

Repository on GitHub: https://github.com/ordigital/mdeditor

Templates let you quickly answer FAQs or store snippets for re-use.
