GPTomics' bioSkills includes 41 MIT-licensed workflow skills, each of which runs a complete bioinformatics pipeline. They take an agent from raw FASTQ, BAM or instrument output to results: differential expression, variant calls, peaks, clusters or trial endpoints. Each one chains the field's standard tools, such as fastp, GATK, PLINK2, xcms, Scanpy and Seurat, and routes each step to a narrower bioSkills skill.

All 41 install with one command from Cuttlefish.MD, HackerNoon's license-checked skills marketplace, along with 521 more bioSkills. They follow the open Agent Skills standard, so they run in Claude Code, Codex CLI and 30+ other tools, and each is indexed in HackerNoon's SKILL.md Library.

All 41 come with the Data & Science plugin, which holds all 562 bioSkills:

For Codex CLI or another agent that supports the standard, clone the repo and copy plugins/data-science/skills/ into your agent's skills folder, such as .agents/skills/. The pipelines call the narrower bioSkills by name, so install the whole set, not just these 41.

Each skill keeps its MIT license and an ATTRIBUTION.md crediting GPTomics and the source commit. Browse the full library at hackernoon.com/skills, and star Cuttlefish.MD on GitHub.
