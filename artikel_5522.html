Equifax cuts database firefighting after moving billing to Oracle on AWS

Tanggal: 2026-11-20

A multicloud strategy once meant deciding which workloads lived with which provider. Now database providers are moving into the clouds customers already use, and AI projects are raising the value of those migrations well beyond the back office.

Equifax Inc. is a case in point. The credit bureau has moved nearly all of its on-premises data centers to the cloud and runs workloads across Amazon Web Services Inc., Google LLC’s Google Cloud and Oracle Corp.’s cloud infrastructure, according to Avinash Singh (pictured), vice president of technology services at Equifax.

“Their performance optimizer is so advanced that we don’t need to tune a single query,” Singh said. “Just think about that. Fifteen to 20 tickets per day turns into one to two tickets per month.”

Singh spoke with theCUBE Research’s Dave Vellante at Oracle AI World, during an exclusive broadcast on theCUBE, SiliconANGLE Media’s livestreaming studio. They discussed how a multicloud strategy is helping Equifax cut billing database tickets. (* Disclosure below.)

Equifax’s global billing system runs on Oracle’s billing and revenue management software, rating and invoicing billions of transactions each month. The database behind it ran on Amazon Relational Database Service for Oracle until it hit a 65-terabyte ceiling. Oracle Autonomous AI Database on AWS, built on Exadata hardware, has room for petabytes of data inside the same cloud, as enterprise adoption accelerates. Because the application stack stayed on AWS, only the database service changed, Singh explained.

“There is zero code writing because it is just about migrating the data from one database to another,” Singh said. “We achieved this migration without any downtime.”

The results showed up quickly after the system went live in April. Gathering database statistics on nearly 100 terabytes of data dropped from three to four days to three to four hours. After some configuration tuning, batch jobs that once handled 100 to 200 rows per transaction now process 15,000 to 30,000, according to Singh.

“Our rating improved almost 200% to 300%,” Singh said. “We are able to close our books way before what we have been closing.”
