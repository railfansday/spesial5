The Java4Shell vulnerability could allow hackers to take over systems without a password.

A newly identified vulnerability in Oracle Java could give hackers unauthorized access to major applications and allow them to run code without logging in. The flaw could affect a sweeping array of big businesses, including tech companies like Google, Amazon, Microsoft, Apple and Netflix, which rely heavily on Java’s server-side software and core products.

“Roughly 90% of Fortune 500 companies run on Java,” Thai Duong, CEO of cybersecurity firm Calif, said.

The flaw, tracked as CVE-2026-114938 (and dubbed Java4Shell), corrupts memory when Java decodes Base64, a standard format used to transmit login credentials and file uploads.

Duong told CNET that his company identified the critical software vulnerability in October and notified Oracle, which has since patched the vulnerability. This week, the US Cybersecurity and Infrastructure Security Agency issued guidance urging organizations to do the same immediately. CISA recommends identifying affected Java installations, reviewing software inventory for JDKs and Java runtimes, and applying vendor patches as soon as they’re available.

Oracle rated the flaw a serious 8.1 out of 10 on the standard vulnerability scale. It can lead to an unauthenticated remote code execution vulnerability in Java, allowing hackers to run their own malicious commands or code over the internet without requiring a username, password or prior access.

Federico Kirschbaum, head of Security Lab, the research arm at cybersecurity company XBOW, told CNET that Java is primarily used at the enterprise level. As a result, the vulnerability could trickle across different sectors, including finance, government, transportation and large corporations.

“Java is a great language for creating solutions, but this vulnerability — it’s a reminder that maybe the languages that we’re using have flaws, and everything built on those might inherit that problem,” Kirschbaum said.

Amid recent technological disruptions, he suggested leaning on AI solutions to address vulnerabilities in AI.

“That new normal is that most of the technology we rely on has flaws, and now that we have resources using LLMs, we can find those problems,” Kirschbaum said.

He pointed out that bad actors and hackers can also find these vulnerabilities.

“We are in a race to find the problems first and help the industry by guiding them on what’s urgent so they patch it,” Kirschbaum said.
