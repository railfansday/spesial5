Microsoft fixes Windows activation as admins pick through Exchange outage wreckage

Tanggal: 2026-11-18

Another unscheduled patch for IT teams already having quite enough fun with Redmond

Microsoft has released an out-of-band update to fix licensing and activation errors introduced by November's Windows security update.

The fix is available from the Microsoft Update Catalog for Windows Server 2025, 2022, and 2019, Windows 10 22H2 ESU, and Windows 10 Enterprise LTSC 2021 and 2019. Windows 11 23H2 users can obtain it from the Catalog or through Windows Update's Optional updates menu.

The "non-security OOB update" targets affected enterprise devices. Microsoft stated: "Certain Windows licensing and activation operations using the Software Licensing Management Tool (SLMGR) might fail with error 0x80041008 (Invalid parameter).

"This primarily affects organizations using slmgr.vbs commands or automated processes to configure Key Management Service (KMS) activation, install product keys, or manage Windows licensing."

Devices that are already activated will remain activated, Microsoft said.

Breaking the machinery customers use to activate paid-for software is a bad look for a Patch Tuesday release. Administrators may wonder how Microsoft's updates are tested when installing one means waiting for another to repair the damage.

Those same administrators may also have been fielding calls about last week's widespread Exchange Online outage, which Microsoft has partly attributed to a defect it introduced in July.

On top of that, Microsoft told administrators just days ago to consider unsupported Exchange Server 2016 and 2019 "permanently vulnerable." Exchange Online avoids that particular support deadline, but the recent outage was a reminder that handing over the servers doesn't make software defects disappear.

Forget "security by obscurity." Last week's approach was more like "security by unavailability."

Between getting Windows activated and keeping Exchange Online online, Microsoft gave administrators plenty to do. None of it was likely to feature in their original plans for the week.

Not all the glitches introduced by November's Patch Tuesday have yet been resolved, as some customers using a Windows device to print will be aware. ®
