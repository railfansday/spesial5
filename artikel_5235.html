Dogecoin Core GitHub Billing Issue Resolved: Top Dev Hints at Uncertainty

In a recent post on social media, Dogecoin engineer Michi Lumin noted that a GitHub billing issue affecting Dogecoin Core has been addressed, although uncertainty remains on how the expenses will be handled in the coming months.

Lumin disclosed that Dogecoin Core's GitHub account ran into billing issues, which she resolved by personally paying the arrears and then switching the billing to herself.

This situation follows major Dogecoin Core developer Patrick Lodder's absence on the 'core' front, with Lumin describing him as missing in action (MIA). However, Lumin clarified that this reflected her own personal experience and speculated that others might have remained in contact with him.

"So @dogecoin , Pat Lodder has gone MIA for months on the Core front (at least to ME. If others have talked to him, great!), and the Core GitHub has run into some billing issues. I've paid the arrears personally and switched billing to myself," Lumin wrote.

@Doge_France @dogecoin as far as i know it was fees for CI workers or actions that they bill/meter. I've been reachable but that's a whole other kettle of bees around here. Either way, it's paid right now, so we'll see how next month goes and i'll address it then if i need to.

The update from Lumin prompted a response from Dogecoin community member 'Doge France', who offered to contribute financially if assistance was needed, saying that keeping the Core GitHub infrastructure operational should be a priority.

Responding to the offer, Lumin explained that the outstanding charges appeared to be related to GitHub Actions or continuous integration (CI) workers, whose usage is billed according to consumption.

Although the immediate payment has been completed, Lumin stopped short of confirming a long-term funding arrangement for the Core GitHub. The developer said the next billing cycle would provide a clearer picture, which will be addressed if necessary.

"As far as i know, it was fees for CI workers or actions that they bill/meter.  I've been reachable but that's a whole other kettle of bees around here. Either way, it's paid right now, so we'll see how next month goes and i'll address it then if i need to," Lumin wrote.

The Dogecoin Foundation, a non-profit organization for which Lumin serves as principal engineer, supports open-source development, advocacy, and community work for Dogecoin and relies primarily on community contributions for its funding.

In the past month, Dogecoin announced a consolidation across its ecosystem with the launch of Dogecoin Labs, which unites Dogecoin’s product teams, technology and applications.
