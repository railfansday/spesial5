macOS 27.3 adds three new Mac features, here’s what’s coming

Tanggal: 2026-11-28

macOS 27.3 is launching next month alongside iOS 27.3 and more, and it includes a variety of new features for Mac users. Here are three macOS 27.3 features coming soon.

macOS already supports running Live Activities from your iPhone via iPhone Mirroring. But in macOS 27.3, Apple is adding native support for Live Activities from Mac apps.

The feature first debuted on the MacBook Pro with PROLED XDR display, which features Live Activities in the new Dynamic Island. But with macOS 27.3, the new feature expands to all Mac models and in a slightly different way.

Live Activities on Macs without a Dynamic Island will display in the menu bar. From there you can click to view full details, as seen above.

Safari introduces several upgrades across macOS 27.3, iOS 27.3, and iPadOS 27.3.

Vertical Tabs are one tentpole addition, providing a new option for how to view your tabs in Apple’s browser. When enabled, your tabs move from the top of the browser to the left side in a new column view.

Adaptive Dark Mode is another new feature. It automatically enables dark mode on many websites that don’t natively support it already. Finally, Siri AI gains support for new Safari actions, including the ability to interact with a full webpage using onscreen awareness, not just the parts that are currently visible.

Do you use Markdown, the popular John Gruber-created plain text syntax? If so, macOS 27.3 has a welcome addition: support for rendering Markdown in Quick Look.

Rather than needing to open Markdown files in apps to preview formatted text, macOS now lets you just use Quick Look and see all of your Markdown syntax rendered properly with links, headings, bold, italics, and more.

You can learn more about Markdown here on John Gruber’s site, Daring Fireball.
