HomeView missing some podcast feeds? Here’s why

Tanggal: 2026-11-18

Apple’s new HomeView features the Podcasts app, but not all feeds appear to be supported for now. Instead, HomeView appears to have the same bug that tvOS 27 introduced to the Apple TV 4K’s Podcasts app.

tvOS 27.0 added playback support for HLS-based video podcasts on Apple TV 4K’s Podcasts app.

The same update introduced a bug that dropped support for syncing shows manually added via URL.

The new Apple HomeView appears to have this same bug. Video podcasts using HLS technology are supported, but shows added via URL do not work.

As of tvOS 27.3 beta 1, the bug is still present on Apple TV 4K 2nd-gen and newer.

Because tvOS 27 doesn’t run on Apple TV 4K 1st-gen, URL-based subscriptions still work in the Podcasts app — just not HLS-based video feeds.

Anyway, if you’re missing certain feeds in the Podcasts app on HomeView, this is likely the reason.
