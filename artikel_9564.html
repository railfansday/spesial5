Network Firewall Automated Internet Firewall: Preview, Unknowns and My View

Tanggal: 2026-11-23

Every multi-VPC AWS network I have looked at has the same awkward piece: firewall endpoints in dedicated subnets, plus route table edits in every VPC, plus someone who has to notice when a new subnet bypasses it. On 20 November AWS put an "automated Internet firewall" mode of Network Firewall into public preview that aims to remove most of that.

This is based on the launch post and pricing page only. The post is short on detail, so I will be clear about what is not stated.

You define Network Firewall rules centrally. AWS enforces them at the internet gateway of every VPC in scope, with built-in NAT for egress-only connectivity. The post says no routing or architectural changes are needed.

Scope can be selected VPCs, a whole account, an organization or an OU. There is an option to extend the policy to future VPCs and subnets automatically at creation. The default policy uses AWS managed rule groups, including active threat defense, and you can add custom rule groups or Marketplace ones. It is available in preview in all Regions except GovCloud and China, and you start from the VPC or Network Security Manager console.

The old model, per the post, was endpoints in dedicated subnets in each VPC's internet path, route updates for every subnet, and monitoring for paths that skip the firewall. The new one is "define rules, AWS enforces at the gateway".

The idea is right. Centralised rules enforced where traffic leaves, rather than rules you hope every route table respects, removes a whole class of bypass mistakes. For organisations with dozens of VPCs the endpoint-and-route-table model is real operational weight.

But this is a preview with no stated price and no stated limits. I would not move production egress onto it. What I would do:

If it ends up priced like today's endpoints and data processing, a lot of the saving will be in engineering time, not the bill. Does your current setup have a bypass path nobody has audited?
