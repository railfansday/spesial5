How to Test Your iOS App on a Real iPhone with an AI Agent

Tanggal: 2026-11-25

You shipped a build to TestFlight. Before anyone else touches it, you want someone to open it on a real phone, sign in, tap through the main flow, and tell you where it broke. That someone can be an AI agent.

This guide shows how to let an agent on your computer (Claude Code, Codex, or any client that runs a local stdio MCP server) drive your iOS app on a real iPhone, screen by screen, and report pass or fail in plain words. It uses Manina AI CLI and the open-source ESP32 iPhone Agent board. Use it only on devices and accounts you own or are allowed to control, and use test accounts.

A simulator doesn't show you what a user sees on a device: real Screen Mirroring, the real keyboard, system sheets, permission prompts. Here the agent looks at the actual screen and taps the actual glass, so it meets the same screens your users do.

Because it only sees pixels, it works with any app on the phone: a debug build, a TestFlight build, or an App Store app. Nothing is installed in your app, and iOS stays stock. No jailbreak.

Open the firmware installer in Chrome or Edge, plug the board into your computer with the data cable, click Connect board, and pick it from the USB list. Keep the page open until it says Installed, then unplug.

Can't see the board? Try another data cable, plug in directly (no hub), close other apps using the serial port, or hold BOOT while plugging it in and try again.

Plug the board into the iPhone, turn on Bluetooth on the computer, and pair within three minutes of powering the board. Don't pair it in your OS Bluetooth settings; the CLI does it.

The hotspot has no internet, so your app's network calls go over cellular data during the test. Then check:

For any other stdio MCP client, the command is esp32agent with the argument mcp. For Claude Code, esp32agent skill install also adds a skill with the phone workflow.

Install your build the way you normally do. The CLI can't install or launch apps, so tell the agent how to reach the app from the Home Screen, what to do, and what counts as passing:

Use esp32agent. From the Home Screen, search for "MyApp" and open it. Sign in with the test account in the note on screen, add one item to the cart and open the cart. Take a fresh screenshot after each action. Pass if the cart shows one item; otherwise stop and tell me which screen differed and why.

History and screenshots stay on your computer. You can move a saved intent to the iPhone app with esp32agent intent export; there, recorded moves replay without the AI while the screen still matches what was recorded.

For faster screenshots, put the board on the same Wi-Fi as your computer with esp32agent net join; taps then don't queue behind video.

A real phone, a $7 board, and one MCP server give your agent the same view your users get. Start with one critical flow (sign-in, onboarding, checkout), write the pass condition in plain words, and save it as an intent once it passes.

Full setup and commands are in the CLI docs, and the source is on GitHub under MIT.
