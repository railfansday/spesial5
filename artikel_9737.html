Claude Code on GitHub Codespaces vs Machines, tested

Tanggal: 2026-11-10

Posted on Nov 10 • Originally published at quicksilverpro.io • Fully Autonomous

Originally published on the QuickSilver Pro blog.

GitHub Codespaces and QuickSilver Machines both give you a Linux box in the browser that a coding agent can treat as its own. We already compared their list prices and features. This time we ran the same Claude Code task on both, three times each, on 2026-11-05, and timed everything from creating the box to deleting it.

Both boxes sent their AI requests to the same QuickSilver Pro API with the same model, so any difference in task time comes from the box, not the model. The Codespace first came up in Singapore, the default for our location. We deleted it and created it again in West US 2, so that both boxes were on the US west coast.

The task is the refactoring task from our coding agent benchmark: a long, copy-pasted build_report function has to be split into small helpers without changing its output for any input. A hidden suite of 317 tests, which the agent never sees, compares the result with the original function. One script ran it 3 times on each box, each time on a fresh copy of the repository:

The script also timed a fixed single-threaded Python loop, to compare raw CPU speed.

Codespaces. gh codespace create returned in 6 seconds, and the shell answered over SSH 14 seconds later, 19 seconds in total (17 for the first attempt in Singapore). Claude Code is not in the default image, so we installed it with the official installer, which took 32 seconds. Claude Code then needs a model provider. We created a QuickSilver Pro API key in the dashboard and wrote it to ~/.claude/settings.json:

With an Anthropic account you would sign in instead of using a key. Either way, it is a step you do once per Codespace, or once in a dev container that you maintain. One thing to watch: our first check, claude -p "Reply with ok", went to Claude Opus 5.5, Claude Code's default, and cost $0.030 for a one-word reply. Pass --model or set a default model if you do not want Opus.

Machines. We clicked Create Machine, and 35 seconds later the machine was Running with the terminal open. Claude Code, Codex, OpenCode and Hermes were already installed and signed in with the machine's own key, so we went straight to the task. The setup steps are in our Machines walkthrough.

The box is not the bottleneck. On Codespaces, Claude Code's own timing put 21 to 22.5 seconds of each 23 to 25-second run in API calls, and the hidden tests ran in a third of a second on both boxes. A faster box would not have made the agent noticeably faster. This holds for agent tasks like this one: a large build or test suite would feel the difference in CPU and RAM, and Codespaces has twice the RAM.

AI cost is a property of the model, not the box. All six runs cost 2 to 3 cents on Claude Sonnet 5.5. The two dearer Codespaces runs differ from the rest in their first request ($0.016 against $0.005 to $0.006), which looks like a prompt-cache write rather than anything the box did.

Setup is the real difference. On Codespaces we had to install the agent, get a key and configure it. A dev container can do this for you on every new Codespace, but someone has to write and maintain it, and the key or sign-in is still yours to manage. On Machines, the agents and the key come with the box, and machine time and AI usage come from one QuickSilver balance.

Pause behaves differently. Stopping a Codespace shuts the container down: your files survive, running processes do not. Pausing a Machine saves a checkpoint, so a long-running agent or dev server is still there when you come back. In our test the background job's log simply had a gap for the paused minute.

Machines charges $0.02 per running hour, per minute, from your QuickSilver Pro balance, and nothing while paused. Our Machine was billed $0.0013 for about 4 minutes of running time.

Codespaces charges $0.18 per hour for a 2-core machine and $0.07 per GB-month of storage, but personal accounts get a monthly quota first: 120 core-hours and 15 GB-month on GitHub Free, 180 core-hours and 20 GB-month on GitHub Pro. A 2-core Codespace uses 2 core-hours per hour, so GitHub Free covers 60 hours a month of it. Our Codespace ran about 15 minutes, half a core-hour of the quota, and cost us nothing. Organizations get no free quota.

For an agent box used 2 hours a day on 22 working days (44 hours a month):

AI usage is extra in every case. With Machines it comes from the same balance; with Codespaces it goes to whichever provider your agent uses.

The task is described in our coding agent benchmark; any task from your own repository works the same way with the claude -p command above. To try the Machine side, open Machines, create one and type claude in the terminal. To run Claude Code on your own computer or in a Codespace instead, follow our Claude Code setup guide.
