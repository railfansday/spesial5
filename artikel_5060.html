Bitcoin Core fixes a bug that can stall nodes, leaving 29.x users to upgrade

Tanggal: 2026-11-23

Versions 30.5 and 31.3 patch the flaw, and 32.1 already includes the fix. Support for the affected 29.x releases ended in October.

Bitcoin Core released versions 30.5 and 31.3 on Nov. 20 with a fix for a flaw that can temporarily stop a Bitcoin node from processing blocks and transactions. Operators on affected 30.x and 31.x releases can patch within their current release lines. Operators on affected 29.x releases need to move to a newer line.

Bitcoin Core rated the flaw medium severity in its security advisory, which identifies it as CVE-2026-117348. The project says a peer can trigger a temporary interruption in block and transaction processing on an affected node.

For operators running versions 30.0 through 30.4, the maintenance update is 30.5. Operators running 31.0 through 31.2 can update to 31.3.

Bitcoin Core 32.1 shipped with the fix on Oct. 27. The project calls the flaw easy to discover and says in its 32.1 release notes that it would disclose easily discoverable vulnerabilities fixed in that release once patches were available for all maintained major versions. The two maintenance updates and the public advisory came out on the same day.

The affected 29.x versions run from 29.0 through 29.5. The project’s software lifecycle schedule dates the end of 29.x support to Oct. 27, the day 32.1 shipped. Bitcoin Core says 29.x will receive no fix for this flaw. An operator on that line can move to one of the three releases the advisory identifies as fixed, including either of the November maintenance releases.

Bitcoin Core maintains its three newest major release lines. When a new major line enters that window, the oldest drops out. The project recommends running the latest maintenance release of the newest major version an operator can move to.

The 32.1 release notes say operators can upgrade directly from an end-of-life version. They instruct operators to let the older version shut down completely before installing the update. The move can take extra time if the node’s data directory needs to be migrated, a practical consideration for operators still running 29.x.

Operators planning that move can check the system requirements in the 32.1 notes. The project lists Linux kernel 3.17, macOS 14, and Windows 10 version 1903 as the minimum versions it supports and tests for that release.
