My Hero Ultra Rumble coming to iOS, Android

Tanggal: 2026-11-07

Bandai Namco will release free-to-play battle royale game My Hero Ultra Rumble for iOS and Android, the latest issue of Weekly Jump reveals. A release date was not announced.

The mobile version will operate independently from the existing PlayStation 4, Xbox One, Switch, and PC versions. While it will include the same number of players per match, the battle duration is shorter and it will not feature cross-play.

The source of the early magazine information describes it as looking like a different game compared to the console and PC versions.
