Feature: We Travelled Across GTA 6's Map Using Only Public Transport

Tanggal: 2026-11-26

Is GTA 6’s public transport any good? We decided to put it to the test for the Push Square YouTube channel:

Rockstar has talked extensively about how Leonida will have its own fully functioning public transport system, allowing you to take the bus and train to wherever you want to go.

But the reality is, you probably haven’t used it, have you?

The challenge? Simple. We wanted to get from Southwind to Wellsprings using only public transport. No RydeMes and no maps allowed – in-game signage only for this challenge.

We won’t spoil the journey, but you can see everything we got up to in the video above.

I actually think it’s a real flex that all of this is possible in GTA 6, and it really illustrates the role playing possibilities of what Rockstar has crafted.

Hopefully you enjoyed the video, and if you like this one, there’s plenty more on the Push Square YouTube channel for you to enjoy.
