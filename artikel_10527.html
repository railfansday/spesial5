Microsoft Authenticator is ditching its own password backup for Google One

Tanggal: 2026-11-06

Microsoft is ditching its own password backup option for the Microsoft Authenticator app for Android and instead using Google One for that service.

Microsoft Authenticator is a one-time password / two-factor authentication app that works more or less like Google Authenticator. The app on your phone spits out a one-time code that you’ll use for logging into various online accounts.

Starting in January, though, Microsoft Authenticator is doing away with Microsoft Account backup for your one-time password connections. Microsoft detailed the change on a support page, explaining that backup on Android will now run through Google One backup. Users will need to toggle on Microsoft Authenticator in Google One’s backup settings on their device.

Starting January 2027, you will no longer use your Microsoft personal account to enable backup. You will need to enable “Microsoft Authenticator” from Google One backup.

It’s an interesting change, to say the least, but it’s not unprecedented. Microsoft Authenticator already relied on iCloud Backup on iOS to back up one-time passwords and accounts.

The change kicks in starting in January of next year, which is mere weeks away at this point.
