Meta launches iPad version of Edits

Tanggal: 2026-11-26

Let Social Media Today's free newsletter keep you informed, straight from your inbox.

The larger screen layout is intended to make it easier for users to manage video projects.

Meta has launched an iPad version of its Edits video editing app, while it's also added new tools and effects, as it continues to expand its video creation options.

The iPad launch will enable tablet users to edit their video clips on a larger screen.

As shown in this example screen, Edits for iPad has a bigger composition screen, which will make it easier to hone in on specific elements and access more editing options at one time.

It could be a valuable update for video creators. A MacOS version of Edits, which is the first desktop version of the app, launched earlier this month.

Edits also added a trim-upon-import option, which should make it easier to place clips into a project at the exact right time.

While it also added new filters and 1,600 new stickers. It's also experimenting with LUT file import options.

LUT files enable color conversion within video files, and this addition will provide more options in maintaining video style and format in the app.

Meta also expanded Edits’ artificial intelligence assistant capacity, with users now able to upload images and video into the chat and get recommendations on how to create a video from these sources.

Finally, there’s a new copyright check option in Edits on iOS, which will examine video projects for potential copyright concerns before they’re uploaded.

As shown in this image posted on X by app researcher Radu Oncescu, users will have five copyright checks available per day, which should help to avoid any restrictions or penalties.

These new tools expand the functionality of Edits and should provide more ways to build creative projects in the app.
