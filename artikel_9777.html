Claude 2.0 คืออะไร? แอปเดสก์ท็อปที่ถูกสร้างใหม่ให้ AI ทำงานขนานกัน

Tanggal: 2026-11-04

ชื่อ Claude 2.0 ที่คนพูดกันช่วงนี้ไม่ได้หมายถึงโมเดลใหม่

มันคือชื่อที่คนเรียกแอป Claude บนเดสก์ท็อปเวอร์ชันที่ถูกสร้างใหม่ [2][5]

ชื่อนี้ยังไปซ้ำกับชื่อโมเดลรุ่นเก่าของ Anthropic ที่ปลดระวางไปตั้งแต่ 21 กรกฎาคม 2025 แล้ว [6][7]

คนที่ค้นคำนี้จึงมีโอกาสเจอสองเรื่องต่างกัน และทั้งสองเรื่องไม่ได้เป็นเรื่องเดียวกัน

คำถามที่ควรถามจึงไม่ใช่ "โมเดลเก่งขึ้นแค่ไหน" แต่เป็น "แอปนี้เปลี่ยนวิธีทำงานของคนใช้อย่างไร"

คู่มือของผู้ใช้ที่ทดลองแอปใหม่เล่าว่า แท็บ Cowork หายไป เหลือสองแท็บคือ Chat กับ Code และฟีเจอร์ใหม่ทั้งหมดถูกวางไว้ในแท็บ Code [2]

เอกสารทางการระบุว่าในแอป Claude เดสก์ท็อป แท็บ Code คือ Claude Code นั่นเอง [1]

นัยก็คือ ผู้ใช้ข้ามขั้นเลือกโหมดไปเลย แล้วเลือกโฟลเดอร์ที่อยากให้ AI ทำงานข้างในแทน

จุดที่ผมคิดว่าสำคัญที่สุดคือแผงข้อมูลด้านขวา

ผู้เขียนคู่มือเล่าว่าแผงนี้บอกว่าบทสนทนารันอยู่บนเครื่องหรือบนคลาวด์ และมีการ์ดบริบทที่บอกว่าไฟล์ความจำ สกิล และคอนเนกเตอร์กินพื้นที่ไปเท่าไรก่อนที่ผู้ใช้จะพิมพ์อะไรเลย [2]

เขาระบุด้วยว่าของเขาเอง เครื่องมือ ไฟล์ความจำกับสกิลกินที่มากกว่าข้อความจริงทั้งหมดที่คุยกัน

นี่คือรายละเอียดที่โฆษณาไม่ค่อยพูด แต่คนใช้จริงเจอทุกวัน

ในเอกสารทางการของ Claude Code บนเดสก์ท็อประบุว่า มีแผงสำหรับงานเบื้องหลังและแผงสำหรับแผนงาน ซึ่งจะปรากฏขึ้นเมื่อเซสชันมีอะไรให้แสดง [1]

ผู้ใช้ยังลากแผงออกไปเป็นหน้าต่างแยกได้ และเอากลับมาวางในหน้าต่างหลักได้ตามต้องการ [1]

ส่วนตัวผมมองว่ารายละเอียดแบบนี้คือส่วนที่ทำให้แอปหนึ่งใช้ได้จริงหรือไม่ได้จริง เพราะงานที่รันนานต้องมีที่ให้ดูว่ามันไปถึงไหน

แอปออกแบบมาให้รันหลายเซสชันพร้อมกัน โดยมีแถบด้านข้างที่รวมเซสชันของผู้ใช้ไว้ในที่เดียว [1]

จัดกลุ่มและเรียงลำดับรายการเซสชันได้จากไอคอนในแถบด้านข้าง ส่วนเซสชันที่เก็บถาวรแล้วดูได้จากไอคอนเดียวกัน ซึ่งในเลย์เอาต์เดิมต้องเลือกสถานะแล้วจึงเข้าถึงรายการเก็บถาวร [1]

มีการตั้งค่า Auto-archive after PR merge or close อยู่ใน Settings > Code ซึ่งเมื่อเปิดแล้ว เซสชันจะย้ายไปยังคลังเมื่อ pull request ถูก merge หรือปิด โดยเซสชันบนคลาวด์และเซสชันที่ยังรันอยู่จะไม่ถูกเก็บอัตโนมัติ [1]

มี side chat ที่แยกบทสนทนาย่อยออกไปโดยดึงบริบทจากเธรดหลัก แต่ไม่เขียนอะไรกลับเข้าไปในเธรดหลัก [1]

รายละเอียดสุดท้ายนี้สำคัญ เพราะมันกันปัญหาเซสชันหลักถูกทำให้เขวด้วยคำถามข้างเคียง

อีกชิ้นที่มาพร้อมกันคือ Projects แบบใหม่ ซึ่ง Anthropic เปิดตัวในสถานะเบต้าเมื่อเดือนกันยายน 2026 [3]

แนวคิดคือผู้ใช้บอกงานที่ต้องทำ แล้ว Claude เป็นคนแบ่งงานเอง จัดการเธรดคู่ขนาน ตรวจผล และประกอบกลับเป็นชิ้นเดียว [3]

ในโปรเจกต์หนึ่งมีเธรดทำงานหลายเส้น และมีตัวประสานงานคอยสั่ง [3]

ผู้ใช้กำหนดสภาพแวดล้อมคลาวด์ คอนเนกเตอร์ ปลั๊กอิน คำสั่ง และโมเดลได้ตั้งแต่ต้น [3]

เอกสารของ Claude อธิบายความต่างของสามคำนี้สั้น ๆ ว่า คอนเนกเตอร์แบบ MCP ให้ AI เข้าถึงเครื่องมือหรือแหล่งข้อมูล สกิลสอนวิธีทำงานตามแบบที่ทีมทำ และปลั๊กอินรวมทั้งสองอย่างไว้เป็นชุดเดียวที่ติดตั้งครั้งเดียวแล้วแชร์ได้ [4]

ทั้งสามอย่างถูกเพิ่มจากหน้าตั้งค่าใน claude.ai หรือในแอปเดสก์ท็อป [4]

พูดง่าย ๆ คือปลั๊กอินเป็นตัวห่อที่รวมสกิล คอนเนกเตอร์ คำสั่ง และเอเจนต์ไว้ด้วยกัน ติดตั้งครั้งเดียวแล้วแชร์ให้ทีมได้ [4]

ช่อง Jedi Trinupab ทำคลิปสรุปฟีเจอร์ชุดนี้ไว้ โดยไล่เมนูสกิล คอนเนกเตอร์ และปลั๊กอิน พร้อมส่วน Artifacts และ Projects ที่ซิงก์จากคลาวด์ [5]

คลิปยังพูดถึงการจัดแชตให้เป็นเซสชัน และแผงงานเบื้องหลังที่แสดงความคืบหน้า [5]

จุดที่ต้องระวังคือคำว่าเซสชันในคลิปหมายถึงการแบ่งแชตเป็นโฟลเดอร์หรือ section ในแถบด้านข้าง ซึ่งคนละอย่างกับเซสชันที่รันขนานกันในหัวข้อก่อนหน้า [5]

ผมแยกส่วนนี้ออกมาเพราะเป็นมุมที่คนใช้เห็นในคลิป ส่วนเอกสารทางการอธิบายคนละลำดับ

ข้อแรก เปิดแผงบริบทดูว่าอะไรกินโควตาก่อนที่คุณจะพิมพ์ และตัดไฟล์ความจำที่ไม่ได้ใช้จริงออกบ้าง

ข้อที่สอง ถ้าคุณทำงานหลายโปรเจกต์พร้อมกัน ลองใช้เซสชันแยกแทนการคุยในเธรดเดียวยาว ๆ เพราะแอปออกแบบมาเพื่อทางนั้นแล้ว [1]

ส่วนคนที่ยังไม่เคยใช้ Claude Code บนเดสก์ท็อป ข่าวนี้ยังไม่จำเป็นต้องรีบ เพราะทั้ง [2] และ [5] พูดถึงตัวแอป ไม่ได้ประกาศโมเดลใหม่

Claude 2.0 คือการเปลี่ยนแอปจากที่คุยกับ AI ทีละเรื่อง เป็นที่ที่สั่งงานหลายอย่างพร้อมกันและดูผลได้จากที่เดียว

คำถามที่ผมสนใจมากกว่าคือ ผู้ใช้ทั่วไปจะรับรูปแบบการทำงานแบบนี้ได้ไหม หรือมันจะยังเป็นเครื่องมือของนักพัฒนาอยู่ดี
