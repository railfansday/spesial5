New Windows 11 update fixes File Explorer menu mess – and patches an exploited flaw

With the November Patch Tuesday rollout, you can finally customize your right-click menu in Windows 11. It fixes 1,094 security flaws, too.

Windows 11 users who’ve struggled to navigate and use the right-click menu in File Explorer now finally have some relief. With the November Patch Tuesday Windows update, you’re now able to customize the menu to add and remove specific commands and apps so that only your favorites appear.

As usual, the monthly update is mandatory, which means it should automatically download and install on your PC. To check, head to Settings and select Windows Update. If the latest update — labeled “2026-11 Security Update (KB5132061) (26300.9974)” -– pops up as installed with a pending restart, just reboot your computer. Otherwise, click the button to check for updates and allow it to download and install.

One caveat: Microsoft’s monthly updates fully support Windows 11 26H2 and 25H2. But support for 24H2 ended last month, at least for the Home and Pro editions. Windows 11 24H2 Enterprise and Education will continue to get monthly security updates, though not regular non-security preview updates, while Windows 11 23H2 Enterprise and Education will receive no more updates after this month.

If you use Windows 11 Home or Pro, be sure you upgrade your system to 26H2 to continue receiving the necessary support and updates.

First and foremost in the latest update is the new customizable right-click menu.

The context-sensitive right-click menu is a handy way to quickly access key settings, features, and apps, both in File Explorer and on the desktop. But there’s always been a flaw in its basic design. The more apps you install, the more cluttered and disorganized the menu becomes. That was especially problematic in previous versions of Windows. The old-style, classic menu would grow so long that it would be difficult to navigate and let you find the item you wanted.

With Windows 11, Microsoft introduced a more modern and pared-down menu. But this version can also get crowded. Plus, it may not display every command you need, so you often have to revert to the older classic menu. You’re then stuck dealing with two separate versions of the same menu, leading to an even more confusing and cumbersome experience.

The ideal solution is a menu that you can customize yourself, and that’s what we now have, at least that’s what is now rolling out. Microsoft calls this one a gradual rollout, which means you may or may not get it right away.

To see if and how this is available, open File Explorer and right-click on a folder or file. If the new menu has reached your PC, you’ll see an entry for Customize menu. Select that to view all the available options for tweaking it. Alternatively, head to Settings, select Personalization, and then click the entry for Context menu.

There, you’re able to turn certain file actions on or off, such as Send to, Print, Create shortcut, Copy as path, and Rotate image. You can also choose which apps appear all the time, either in the main menu or in a submenu. Plus, additional options let you decide where certain commands and actions appear and whether you can still access the old-style menu.

Though the customizable right-click menu is the star of the update, Microsoft has added other surprises as it strives to make Windows more reliable and user-friendly.

Also gradually rolling out, Cloud rebuild is a new recovery option that lets you reinstall Windows 11 via cloud-based system images and drivers downloaded from Windows Update. This tool can help you recover Windows when it won’t load and you don’t have a USB drive or your own custom image. The downside is that your files won’t survive. But if you regularly back them up as you should, you can restore them after Windows is back in business.

To start Cloud rebuild, go to Settings, select System, click Recovery, and then select Rebuild PC. Your PC will then restart into the Windows Recovery Environment (WinRE) to kick off the cloud rebuild. If Windows can load, your computer should automatically enter WinRE mode, where you can then choose the cloud rebuild. You should need to make sure your PC is online via a wired or wireless connection.

The November update also enhances or fixes other Windows features and apps.

And that then brings us to the security fixes.

This month’s update resolves 1,094 security vulnerabilities, according to Microsoft, with 63 of them rated critical and one already exploited in the wild. That’s fewer than October’s record of 1,400 patches. But it still represents a hefty number as Microsoft and other vendors continue to rely on AI to find and fix security holes.

The exploited flaw points to a spoofing vulnerability in Microsoft Outlook. Here, a remote attacker who sends you a malicious email and convinces you to open it could cause Outlook to connect to a network controlled by that attacker. In this case, though, you would not receive any warning. Further, the exploit might reveal your username and password to the sender, potentially allowing them to impersonate you.
