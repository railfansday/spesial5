Threads tests new Q&A option in live chats

Tanggal: 2026-11-22

The format would allow chat hosts to solicit questions and have chat participants vote on what to ask.

Threads is testing a new Q&A option in live chats as it looks for more ways to drive active engagement and interaction among like-interested users.

As shown in these examples, Threads is experimenting with a custom format for live chat Q&A sessions, which would enable chat hosts to gather questions from participants. The proposed questions then get put to a vote in the chat, leading to a more structured interview approach.

That this could ensure more relevant questions and enhance the value of live conversations.

In some ways, it’s similar to the approach Reddit takes with its AMA sessions, where users can upvote questions in order to give them more priority, enabling the community to guide the discussion.

This move could also make live chats on Threads a more viable option for brand promotion, with brands able to participate in curated chats and answer audience questions.

Threads added live chat in April as part of its expanded effort to drive more discussion around live events in the app.

It added more live chat functionality in September, with additional tools to encourage user contribution.

Upvoted Q&A sessions are another step in that direction, driving more community engagement, and more focus in live discussion sessions.

Which, ideally, will help to make Threads a bigger focus for real-time engagement during major events. X is arguably still the go-to platform on this front, but Threads is making inroads and could soon become a bigger focus for more communities.

Threads said it’s testing the new Q&A option with a selection of live chat sessions, but all participants can read live chat responses.
