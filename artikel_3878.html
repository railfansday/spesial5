Pokopia Dazzling Decorations update release date and all new features

Tanggal: 2026-11-05

Pokopia’s first-ever expansion pass launched on Aug. 5, introducing a massive underwater region to explore. This pass has two more parts to it, though, and the next one is Dazzling Decorations, which finally has an official release date.

This massive update promises some exciting additions unlike anything we’ve seen before, so if you’re eager to dive in as soon as it’s possible to do so, you may want to learn about it ahead of time to prepare. Here’s when the Dazzling Decorations update will be released and all the new features it’s bringing to Pokopia.

The Dazzling Decorations update for Pokopia officially launches on Dec. 9. This is a paid add-on for the game that is the second part of the expansion pass that started with Bubbly Basin, so if you previously bought this DLC, you’ll get this update.

If you don’t have the expansion pass, though, you will not get the content featured in the Dazzling Decorations update. All parts of this specific update are locked behind the paid DLC, as it’s the second part of it.

A precise launch time for this update hasn’t been shared, and likely won’t be ahead of release. Most Nintendo releases tend to go live at 9am JST, though, and Bubbly Basin did, so there’s a decent chance Dazzling Decorations may launch around 6pm on Aug. 4 if this DLC goes live at 9am JST on Aug. 5. We’ll likely know more closer to release, though.
