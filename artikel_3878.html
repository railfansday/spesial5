A Bizarre Run codes usually offer a decent amount of cash, which can be used at the in-game merchant in exchange for Rokakaka Fruit. These handy items are necessary if you want to use a Stand Arrow and roll for a new Stand. Meanwhile, promos also grant the likes of spins and Stand Arrows themselves.

To redeem A Bizarre Run codes, you'll first need to complete the brief tutorial, then you can click on the Codes button at the button of the screen, indicated by a pink present icon. This opens the Enter Code Here... box, which is also found at the bottom of the Shop. Enter a code into the box and hit Redeem to claim your rewards.

A Bizarre Run codes aren't case-sensitive, so you only have to worry about getting the spelling right.
