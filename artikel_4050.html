It looks like players were right about the action RPG's storage issue

When you purchase through links on our site, we may earn an affiliate commission. Here’s how it works.

A minor Nier: Automata update inexplicably increased the game's Steam install size from 50GB to a stonking 366GB, and the official Nier series account has now confirmed that something's gone horribly, hilariously wrong.

"We have identified an issue following the latest update for NieR:Automata on Steam, released on November 6, 2026 (JST), where installation requires significantly more storage space than intended," a recent Twitter post from the account reads.

"We are currently investigating the cause and working to resolve the issue. We apologize for the inconvenience. As a temporary workaround, you can download the base game using the intended amount of storage space by going to 'Properties' → 'DLC' in Steam and unchecking each DLC item."

This solution aligns with player speculation that a bug with Nier: Automata's DLCs was behind the surprise hard drive gluttony. It appears that the entire 50GB game was repeatedly attached to DLC files, causing players to download it seven times. I like crossover champion 2B as much as the next Nier fan, but seven seems like too many.

At the time of writing, the Nier: Automata economy has yet to address this hyperinflation: Steam still tells us that we need 366.56GB of space to install this thing. The good news is that the game seems to be perfectly playable, assuming you can spare the space or sever those DLCs. An incredible display of video game spaghetti all around.
