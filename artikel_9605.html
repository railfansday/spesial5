Building a Poople Solver: The Search Was Easy, the Word List Was Not

Tanggal: 2026-11-24

Poople is a daily word puzzle. You get a four-letter start word and change one letter at a time until you reach POOP. Every guess has to be a real word, and fewer steps is better.

I built a Poople solver that finds the shortest path from any start word. The search code is short. Getting the word list right was the hard part.

Think of every four-letter word as a stop on a map. Two words are connected when they differ by exactly one letter in the same spot. JUGS connects to BUGS. BUGS connects to BOGS.

Solving a puzzle means finding the shortest route on this map to POOP.

Every puzzle ends at POOP. So instead of searching from each start word, I search once, outward from POOP. First all words one step away, then all words two steps away, and so on. This is called a breadth-first search.

When it finishes, I know how far every word is from POOP. Solving any start word is then just a lookup.

To get the actual path, start at your word and keep stepping to any neighbor that is one step closer to POOP.

The word list is sorted by how often each word shows up in movie subtitles, which works well as a "would a normal person know this word" score.

The code above only works if the word list matches the game. That turned out to be the real problem.

A big list is too loose. ENABLE, a free word list used by many word games, has 3,903 four-letter words. Many of them are words almost nobody uses. When I tried some in the game, it rejected AITS, ANTA, ARES and SIMS.

A small list is too strict. So I kept only the 2,303 words that are in both ENABLE and a standard-size English dictionary. That removed the junk, but it also removed words the game does accept.

Puzzle #465 showed the problem. The start word was ANTI. My solver said the best path was 10 steps. The game said 8.

Playing it in the game found the gap: it accepts ANDS and BODS, and my list had dropped both. With those two words back in, the solver finds the same 8-step path:

ANTI → ANTS → ANDS → AIDS → BIDS → BODS → BOOS → BOOP → POOP

The next day the game showed this exact path as its own answer.

Each day I compare my answer with the game's best score. If the game wins, I find the missing word and add it. Each fix makes the next day a bit more accurate.

2,300 short words is a small file, so the whole solver runs in the page. Nothing is sent to a server, and the word you type never leaves your device.

That also made a hint mode easy. "Next step only" shows just the next word and how many steps are left, for people who want a nudge rather than the full answer.

The Poople solver is free and needs no sign-up. If you want to know how we check each day's answer against the game, it is written up in How we work out Poople answers.
